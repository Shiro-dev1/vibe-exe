Hello, world

In Java all code lives inside a class. The program starts in the main method. System.out.println prints a line.

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, world!");
    }
}
Output
Hello, world!

This first program has many words, but you'll write them in every Java program, so they quickly become a habit. public class Main is the class; the file must be called Main.java.

public static void main(String[] args) is the starting point. Java code is compiled with javac and run with java. Online you can try it at onlinegdb.com or jdoodle.com.

Line by line

public class Main {a class called Main; the file name must match.
public static void main(String[] args) {the method where the program starts.
System.out.println("Hello, world!");print the text and a line break.

Common mistakes

  • The file name doesn't match the class: class Main in Hello.java — error.
  • system.out.println in small letters — it must be System.

Try it yourself

Print your name and on the next line 2026.

Show answer 
public class Main {
    public static void main(String[] args) {
        System.out.println("Shiro");
        System.out.println(2026);
    }
}
Output
Shiro
2026

Variables

Every variable has a type: String for text, int for whole numbers. + glues text and values together. From here on, short examples go inside main.

String name = "Shiro";
int age = 18;
age = age + 1;
System.out.println("Hi, I'm " + name + " and I'm " + age);
Output
Hi, I'm Shiro and I'm 19

String starts with a capital letter because it is a class, while int is a simple (primitive) type. Since Java 10 you may also write var: var age = 18; — Java figures out the type.

final int max = 10; makes a constant that can't change.

Line by line

String name = "Shiro";a text variable.
int age = 18;a whole number.
"Hi, I'm " + name + ...+ joins text and values into one string.

Common mistakes

  • string in small letters — Java only knows String.

Try it yourself

Create String city = "Kyiv" and int year = 2020, print: I live in Kyiv since 2020.

Show answer 
String city = "Kyiv";
int year = 2020;
System.out.println("I live in " + city + " since " + year);
Output
I live in Kyiv since 2020

Data types

Main types: int, double, boolean, char and String. Text has a length() method.

int count = 10;          // whole number
double price = 9.99;     // number with a dot
boolean online = true;   // true or false
char letter = 'S';       // one character
String title = "VIBE";   // text
System.out.println(title.length());
Output
4

Primitive types (int, double, boolean, char) are written in small letters and hold just a value. String is an object with many methods: toUpperCase(), contains(), charAt(0).

Text to number: Integer.parseInt("5"). Number to text: String.valueOf(5) or just "" + 5.

Line by line

boolean online = true;true or false (the word is boolean, not bool).
char letter = 'S';one character in single quotes.
title.length()a method — with brackets.

Common mistakes

  • Comparing strings with ==. In Java use a.equals(b).

Try it yourself

You have String a = "7". Print a as a number plus 3 (10).

Show answer 
String a = "7";
System.out.println(Integer.parseInt(a) + 3);
Output
10

Conditions

if, else if and else — the same as in C, C# and JavaScript.

int age = 18;

if (age >= 18) {
    System.out.println("Adult");
} else if (age >= 13) {
    System.out.println("Teen");
} else {
    System.out.println("Kid");
}
Output
Adult

The condition must be a boolean. Combine with &&, ||, !. For many fixed values there is switch.

The short form condition ? a : b also exists: String label = age >= 18 ? "Adult" : "Kid";.

Line by line

if (age >= 18) {the first check.
} else if (age >= 13) {the next one.

Common mistakes

  • if (name == "Shiro") may be false even when the text is the same — use name.equals("Shiro").

Try it yourself

Show answer

    System.out.println("Hot");

    System.out.println("OK");
}
Output

Loops

for with a counter, while while the condition is true. For lists there is the "for-each" loop: for (String s : list).

for (int i = 0; i < 3; i++) {
    System.out.println("Step " + i);
}

int count = 3;
while (count > 0) {
    System.out.println(count);
    count--;
}
Output
Step 0
Step 1
Step 2
3
2
1

Java loops are the same as in C and C#, so once you know them you know them in three languages.

break leaves the loop early, continue skips to the next round.

Line by line

for (int i = 0; i < 3; i++)i = 0, 1, 2.
count--;take 1 away.

Common mistakes

  • A while loop where the variable never changes — the program hangs.

Methods

Functions in Java are called methods and live inside a class. static means you can call it without creating an object.

public class Main {
    static int add(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {
        System.out.println(add(2, 3));
    }
}
Output
5

A method has a return type (int, String, or void for nothing), a name and typed parameters. Names usually start with a small letter: add, sayHello.

The method can be written above or below main — Java reads the whole class first.

Line by line

static int add(int a, int b)returns an int, takes two ints.
return a + b;give back the sum.
add(2, 3)call it from main.

Common mistakes

  • Calling a non-static method from main without an object — error: non-static method cannot be referenced from a static context.

Try it yourself

Write static int square(int n) and print square(7).

Show answer 
public class Main {
    static int square(int n) {
        return n * n;
    }

    public static void main(String[] args) {
        System.out.println(square(7));
    }
}
Output
49

Lists

ArrayList is a list that grows. You import it from java.util, and in angle brackets say what it holds.

import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<String> langs = new ArrayList<>();
        langs.add("Java");
        langs.add("Kotlin");
        langs.add("Go");
        System.out.println(langs.size());
        for (String lang : langs) {
            System.out.println("I like " + lang);
        }
    }
}
Output
3
I like Java
I like Kotlin
I like Go

Java also has plain arrays: int[] a = {1, 2, 3}; — fixed size, length via a.length. ArrayList is more flexible: add, get(i), remove(i), size().

Lists can't hold primitives directly, so for numbers write ArrayList<Integer>, not <int>.

Line by line

import java.util.ArrayList;connect the ArrayList class.
new ArrayList<>()create an empty list.
langs.size()how many items.
for (String lang : langs)for every item.

Common mistakes

  • ArrayList<int> — error. Use ArrayList<Integer>.

Try it yourself

Make an ArrayList<Integer> with 1, 2, 3, 4 and print the sum.

Show answer

public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> nums = new ArrayList<>();
        nums.add(1);
        nums.add(2);
        nums.add(3);
        nums.add(4);
        int sum = 0;
        for (int n : nums) {
            sum += n;
        }
        System.out.println(sum);
    }
}

Mini project: a game hero

Java is built around classes and objects. Here a Player class has data (name, hp) and an action (hit).

public class Main {
    static class Player {
        String name;
        int hp = 100;

        Player(String name) {
            this.name = name;
        }

        void hit(int damage) {
            hp -= damage;
            System.out.println(name + " has " + hp + " HP");
        }
    }

    public static void main(String[] args) {
        Player p = new Player("Shiro");
        p.hit(30);
        p.hit(25);
    }
}
Output
Shiro has 70 HP
Shiro has 45 HP

Player(String name) is the constructor: it runs when you write new Player("Shiro"). this.name means "the name of this object", to tell it apart from the parameter name.

In real projects each class usually has its own file. Here we put it inside Main as static class so everything fits in one file.

Line by line

static class Player {the blueprint for players.
Player(String name) {the constructor.
this.name = name;save the parameter into the object.
Player p = new Player("Shiro");build one real player.

Common mistakes

  • Forgetting new: Player p = Player("Shiro"); — error.

Try it yourself

Add a heal(int amount) method and heal the player by 10 after the hits.

Show answer 
public class Main {
    static class Player {
        String name;
        int hp = 100;

        Player(String name) {
            this.name = name;
        }

        void hit(int damage) {
            hp -= damage;
            System.out.println(name + " has " + hp + " HP");
        }

        void heal(int amount) {
            hp += amount;
            System.out.println(name + " has " + hp + " HP");
        }
    }

    public static void main(String[] args) {
        Player p = new Player("Shiro");
        p.hit(30);
        p.hit(25);
        p.heal(10);
    }
}
Output
Shiro has 70 HP
Shiro has 45 HP
Shiro has 55 HP

Quiz

5 questions. Pick an answer to see if it is right.

1. Where does a Java program start?

The method public static void main.

2. What will this code print?

int x = 7;
System.out.println(x / 2);

Both are int, so the part after the dot is dropped.

3. How do you compare two strings correctly?

== compares objects, equals() compares the text.

4. What will this code print?

String s = "Java";
System.out.println(s.length() + 1);

length() is 4, plus 1 is 5.

5. Which type is right for a list of whole numbers?

Lists need the object type Integer, not the primitive int.
