Linux basics

Linux is a free operating system kernel, started in 1991 by Linus Torvalds. It runs most servers on the internet, every Android phone and the world's supercomputers. ChromeOS is built on Linux too.

What is a terminal

A terminal is a window where you control the computer with text commands instead of the mouse. You type a command, press Enter, and the computer answers. A command usually looks like this:

$ command  options  target
$ ls -la /home

Files and folders

pwd
Show the folder you are in now.
ls
List files in the folder.ls -la — also show hidden files and details
cd folder
Go into a folder.cd .. — go one folder up; cd ~ — go home
mkdir name
Create a new folder.
touch file.txt
Create an empty file.
cp a b
Copy file a to b.
mv a b
Move or rename a file.
rm file
Delete a file.careful: there is no trash bin, it is gone for good

Reading and searching

cat file.txt
Print the whole file.
less file.txt
Read a long file page by page.q — quit
grep "word" file
Find lines that contain a word.
man ls
Open the manual for any command.

System

sudo command
Run a command as administrator.asks for your password
chmod +x script.sh
Make a file executable.
top
See running programs and how much they load the computer.
clear
Clear the terminal screen.

Handy keys

Tab
Finish a file or command name for you.
↑ / ↓
Scroll through commands you typed before.
Ctrl + C
Stop the running command.
