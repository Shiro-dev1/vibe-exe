# VIBE.EXE

Black and white pixel experiment: two hands made of dots reach for each other.

- Hands assemble from scattered dots, slowly "breathe" toward each other and spark with a glitch when the fingers almost touch.
- Dots scatter away from the cursor or finger.
- The VIBE.EXE window can be dragged, minimized and closed.

Files: `index.html` (everything in one file), `favicon.svg`.
