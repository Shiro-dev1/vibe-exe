Hello, world

C++ is C with many extras. std::cout << sends text to the screen, std::endl ends the line.

#include <iostream>

int main() {
    std::cout << "Hello, world!" << std::endl;
    return 0;
}
Output
Hello, world!

C++ grew out of C, so a lot looks familiar, but it adds a powerful standard library. #include <iostream> connects the input/output part. std:: means "from the standard library".

std::cout is the screen ("character output"), and << pushes values into it, one after another.

Line by line

#include <iostream>connect input/output.
std::cout << "Hello, world!"send the text to the screen.
<< std::endl;end the line.

Common mistakes

  • Writing cout without std:: — the compiler doesn't know it. (Some code uses using namespace std; to skip it.)

Try it yourself

Print your name and on the next line 2026.

Show answer 
#include <iostream>

int main() {
    std::cout << "Shiro" << "\n";
    std::cout << 2026 << "\n";
}
Output
Shiro
2026

Variables

Like in C, every variable has a type. std::string stores text. You can chain many values with <<.

#include <iostream>
#include <string>

int main() {
    std::string name = "Shiro";
    int age = 18;
    std::cout << "Hi, I'm " << name << " and I'm " << age << "\n";
}
Output
Hi, I'm Shiro and I'm 18

Variables in C++ have types, like in C. The big helper is std::string: real text that knows its length, can be glued with + and compared with ==.

"\n" and std::endl both end a line; "\n" is a little faster.

Line by line

#include <string>connect std::string.
std::string name = "Shiro";a text variable.
std::cout << "Hi, I'm " << name << ...several values in one line, one after another.

Common mistakes

  • Using std::string without #include <string> — sometimes works by luck, sometimes not. Always include it.

Try it yourself

Create std::string city = "Kyiv" and int year = 2020, print: I live in Kyiv since 2020.

Show answer 
std::string city = "Kyiv";
int year = 2020;
std::cout << "I live in " << city << " since " << year << "\n";
Output
I live in Kyiv since 2020

Data types

auto lets the compiler pick the type for you. From here on, short examples go inside main.

int count = 10;              // whole number
double price = 9.99;         // number with a dot
bool online = true;          // true or false
char letter = 'S';           // one character
std::string title = "VIBE";  // text
auto half = 3.5;             // the compiler picks double

std::cout << title.length() << "\n";
Output
4

Main types: int, double, bool (true/false), char, std::string. auto lets the compiler figure out the type from the value — handy for long type names.

Convert text to a number with std::stoi("5") and a number to text with std::to_string(5).

Line by line

bool online = true;true or false.
auto half = 3.5;the compiler sees 3.5 and makes it a double.
title.length()how many characters are in the text.

Common mistakes

  • auto x; without a value — the compiler can't guess the type.

Try it yourself

You have std::string a = "7". Print a as a number plus 3 (10).

Show answer 
std::string a = "7";
std::cout << std::stoi(a) + 3 << "\n";
Output
10

Conditions

if runs code only when the condition in brackets is true.

int age = 18;

if (age >= 18) {
    std::cout << "Adult\n";
} else if (age >= 13) {
    std::cout << "Teen\n";
} else {
    std::cout << "Kid\n";
}
Output
Adult

Conditions in C++ are the same as in C, but there is a real bool type. You can also write and, or, not instead of &&, ||, !, though most people use the symbols.

For many fixed choices there is switch, but if / else if is enough most of the time.

Line by line

if (age >= 18) {the condition in brackets.
std::cout << "Adult\n";runs only if the condition is true.

Common mistakes

  • A semicolon right after if: if (x > 5); — the block below then always runs.

Try it yourself

int t = 30. Print "Hot" if t > 25, otherwise "OK".

Show answer 
int t = 30;
if (t > 25) {
    std::cout << "Hot\n";
} else {
    std::cout << "OK\n";
}
Output
Hot

Loops

for has three parts: start, condition, step. while repeats while the condition is true.

for (int i = 0; i < 3; i++) {
    std::cout << "Step " << i << "\n";
}

int count = 3;
while (count > 0) {
    std::cout << count << "\n";
    count--;
}
Output
Step 0
Step 1
Step 2
3
2
1

for and while work as in C. C++ adds the range-based for: for (int x : numbers) — "for every x in numbers". It is shorter and you can't go out of bounds by mistake.

Line by line

for (int i = 0; i < 3; i++)a counter from 0 to 2.
while (count > 0)repeat while count is positive.

Common mistakes

  • Changing the counter inside a for loop by accident — the loop jumps or never ends.

Try it yourself

Print the numbers from 1 to 5.

Show answer 
for (int i = 1; i <= 5; i++) {
    std::cout << i << "\n";
}
Output
1
2
3
4
5

Functions

A function has a return type, a name and parameters. const std::string& means "read this text without copying it".

#include <iostream>
#include <string>

std::string greet(const std::string& name) {
    return "Hello, " + name + "!";
}

int main() {
    std::cout << greet("Shiro") << "\n";
}
Output
Hello, Shiro!

A C++ function looks like a C function. When you pass a big object like a string, write const std::string&: & means "don't copy, use the original", const means "and don't change it". It is faster and safe.

Functions can have the same name with different parameters — that is called overloading.

Line by line

std::string greet(const std::string& name)returns text, reads name without copying it.
return "Hello, " + name + "!";glue the pieces into a new string.

Common mistakes

  • Forgetting to return a value in a non-void function — the result is unpredictable.

Try it yourself

Write int square(int n) and print square(7).

Show answer 
#include <iostream>

int square(int n) {
    return n * n;
}

int main() {
    std::cout << square(7) << "\n";
}
Output
49

Vectors

std::vector is a list that can grow. push_back adds an item, size() is how many there are. for (... : langs) goes through every item.

#include <iostream>
#include <string>
#include <vector>

int main() {
    std::vector<std::string> langs = {"Python", "C++", "Rust"};
    langs.push_back("C#");
    std::cout << langs.size() << "\n";

    for (const auto& lang : langs) {
        std::cout << "I like " << lang << "\n";
    }
}
Output
4
I like Python
I like C++
I like Rust
I like C#

std::vector is the most used container in C++: an array that grows by itself. push_back adds to the end, pop_back removes the last item, size() tells how many items there are, v[i] gives an item.

In angle brackets you say what is stored: std::vector<int> holds whole numbers, std::vector<std::string> holds text.

Line by line

std::vector<std::string> langs = {...};a vector of texts with 3 items.
langs.push_back("C#");add one more.
for (const auto& lang : langs)go through every item without copying.

Common mistakes

  • Forgetting #include <vector>.

Try it yourself

Make a vector of {1, 2, 3}, add 4 and print the sum of all items.

Show answer 
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {1, 2, 3};
    v.push_back(4);
    int sum = 0;
    for (int x : v) sum += x;
    std::cout << sum << "\n";
}
Output
10

Mini project: a game hero

A class joins data and functions into one thing. This is how games describe players, enemies and items.

#include <iostream>
#include <string>

class Player {
public:
    std::string name;
    int hp = 100;

    void hit(int damage) {
        hp -= damage;
        std::cout << name << " has " << hp << " HP\n";
    }
};

int main() {
    Player p;
    p.name = "Shiro";
    p.hit(30);
    p.hit(25);
}
Output
Shiro has 70 HP
Shiro has 45 HP

A class is a blueprint, and objects are things built from it. Player describes what every player has (name, hp) and can do (hit). Player p; builds one real player.

public: means these parts can be used from outside the class. This idea — putting data and actions together — is called object-oriented programming.

Line by line

class Player {start of the blueprint.
int hp = 100;every new player starts with 100 HP.
void hit(int damage)an action of the player; void = returns nothing.
p.hit(30);call the action on this player.

Common mistakes

  • Forgetting the ; after the closing brace of a class: };.

Try it yourself

Add a heal(int amount) method that adds HP and prints it. Heal the player by 10 after the hits.

Show answer 
#include <iostream>
#include <string>

class Player {
public:
    std::string name;
    int hp = 100;

    void hit(int damage) {
        hp -= damage;
        std::cout << name << " has " << hp << " HP\n";
    }
    void heal(int amount) {
        hp += amount;
        std::cout << name << " has " << hp << " HP\n";
    }
};

int main() {
    Player p;
    p.name = "Shiro";
    p.hit(30);
    p.hit(25);
    p.heal(10);
}
Output
Shiro has 70 HP
Shiro has 45 HP
Shiro has 55 HP

Quiz

5 questions. Pick an answer to see if it is right.

1. What will this code print?

std::string s = "VIBE";
std::cout << s.length() << "\n";

"VIBE" has 4 letters.

2. Which one sends text to the screen?

cout << is output, cin >> is input.

3. What will this code print?

std::vector<int> v = {1, 2};
v.push_back(3);
std::cout << v.size() << "\n";

push_back added one more item: now there are 3.

4. What will this code print?

int hp = 100;
hp -= 30;
hp -= 25;
std::cout << hp << "\n";

100 - 30 = 70, then 70 - 25 = 45.

5. What joins data and functions into one thing?

A class has data (name, hp) and functions (hit).
