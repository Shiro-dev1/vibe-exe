01_HELLO_WORLD01/08

C has to be compiled: turned into a program before it runs. Every program starts in main. \n means a new line.

#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}
OUTPUT
Hello, world!
02_VARIABLES02/08

In C you must say the type of every variable. printf inserts values with codes: %d whole number, %.2f number with 2 digits after the dot, %c one character. From here on, short examples go inside main.

int age = 18;
float price = 9.99f;
char letter = 'S';

printf("Age: %d\n", age);
printf("Price: %.2f\n", price);
printf("Letter: %c\n", letter);
OUTPUT
Age: 18
Price: 9.99
Letter: S
03_DATA_TYPES03/08

Text in C is an array of characters. %s prints text, sizeof tells how many bytes something takes (text has one hidden extra byte at the end).

int whole = 42;           // whole number
double precise = 3.14159; // number with a dot
char symbol = '#';        // one character
char word[] = "VIBE";     // text

printf("%s has %zu letters\n", word, sizeof(word) - 1);
OUTPUT
VIBE has 4 letters
04_CONDITIONS04/08

if runs code only when the condition in brackets is true.

int age = 18;

if (age >= 18) {
    printf("Adult\n");
} else if (age >= 13) {
    printf("Teen\n");
} else {
    printf("Kid\n");
}
OUTPUT
Adult
05_LOOPS05/08

for has three parts: start, condition, step. i++ adds 1, count-- takes 1 away.

for (int i = 0; i < 3; i++) {
    printf("Step %d\n", i);
}

int count = 3;
while (count > 0) {
    printf("%d\n", count);
    count--;
}
OUTPUT
Step 0
Step 1
Step 2
3
2
1
06_FUNCTIONS06/08

A function has a return type, a name and parameters with types. It must be written before it is used.

#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main(void) {
    printf("%d\n", add(2, 3));
    return 0;
}
OUTPUT
5
07_ARRAYS07/08

An array stores many values of one type. Counting starts from 0. C doesn't store the length, so we calculate it with sizeof.

int scores[] = {10, 20, 30, 40};
int size = sizeof(scores) / sizeof(scores[0]);
int sum = 0;

for (int i = 0; i < size; i++) {
    sum += scores[i];
}
printf("Sum: %d\n", sum);
OUTPUT
Sum: 100
08_MINI_PROJECT_GUESS_THE_NUMBER08/08

Everything together. rand() gives a random number, scanf reads what the player types. The output below is an example game.

#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void) {
    srand(time(NULL));
    int secret = rand() % 10 + 1;
    int guess = 0;

    while (guess != secret) {
        printf("Guess a number from 1 to 10: ");
        scanf("%d", &guess);
        if (guess < secret) printf("Bigger!\n");
        else if (guess > secret) printf("Smaller!\n");
    }
    printf("You got it!\n");
    return 0;
}
OUTPUT
Guess a number from 1 to 10: 5
Bigger!
Guess a number from 1 to 10: 8
Smaller!
Guess a number from 1 to 10: 7
You got it!
