Hello, world

C has to be compiled: turned into a program before it runs. Every program starts in main. \n means a new line.

#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}
Output
Hello, world!

C programs are written in a text file and then compiled — turned into an executable file the computer understands. Online, you can do it in one click on sites like onlinegdb.com.

#include <stdio.h> connects the standard input/output library, where printf lives. int main(void) is where the program starts. return 0; tells the system "everything went fine".

Line by line

#include <stdio.h>connect the library with printf.
int main(void) {the main function; int means it returns a whole number.
printf("Hello, world!\n");print the text; \n moves to a new line.
return 0;finish the program successfully.

Common mistakes

  • Forgetting ; at the end of a line — the compiler stops with an error.
  • Forgetting \n — the next text sticks to the same line.

Try it yourself

Print two lines: your name and the number 2026.

Show answer 
#include <stdio.h>

int main(void) {
    printf("Shiro\n");
    printf("%d\n", 2026);
    return 0;
}
Output
Shiro
2026

Variables

In C you must say the type of every variable. printf inserts values with codes: %d whole number, %.2f number with 2 digits after the dot, %c one character. From here on, short examples go inside main.

int age = 18;
float price = 9.99f;
char letter = 'S';

printf("Age: %d\n", age);
printf("Price: %.2f\n", price);
printf("Letter: %c\n", letter);
Output
Age: 18
Price: 9.99
Letter: S

In C every variable has a fixed type that you write before its name. The compiler uses it to know how much memory to reserve.

printf doesn't know types by itself, so you tell it with format codes: %d for int, %f for float/double, %c for a char, %s for text. The values go after the text, in the same order.

Line by line

int age = 18;a whole number.
float price = 9.99f;a number with a dot; f at the end marks a float.
char letter = 'S';one character, in single quotes.
printf("Price: %.2f\n", price);%.2f — a number with exactly 2 digits after the dot.

Common mistakes

  • Wrong format code: printf("%d", price) for a float prints garbage.
  • Double quotes for a char: char c = "S"; is an error — use 'S'.

Try it yourself

Create int year = 2026 and print "Year: 2026".

Show answer 
int year = 2026;
printf("Year: %d\n", year);
Output
Year: 2026

Data types

Text in C is an array of characters. %s prints text, sizeof tells how many bytes something takes (text has one hidden extra byte at the end).

int whole = 42;           // whole number
double precise = 3.14159; // number with a dot
char symbol = '#';        // one character
char word[] = "VIBE";     // text

printf("%s has %zu letters\n", word, sizeof(word) - 1);
Output
VIBE has 4 letters

C has no special string type: text is an array of char that ends with a hidden zero character '\0'. That's why sizeof("VIBE") is 5, not 4.

double is like float but more precise — use it by default for numbers with a dot. For text length there is strlen() from <string.h>.

Line by line

double precise = 3.14159;a precise number with a dot.
char word[] = "VIBE";text: an array of 5 chars (4 letters + hidden \0).
sizeof(word) - 1size in bytes minus the hidden end character.

Common mistakes

  • Comparing texts with ==. In C use strcmp(a, b) == 0.

Try it yourself

Create char name[] = "Shiro" and print "Shiro has 5 letters" using sizeof.

Show answer 
char name[] = "Shiro";
printf("%s has %zu letters\n", name, sizeof(name) - 1);
Output
Shiro has 5 letters

Conditions

if runs code only when the condition in brackets is true.

int age = 18;

if (age >= 18) {
    printf("Adult\n");
} else if (age >= 13) {
    printf("Teen\n");
} else {
    printf("Kid\n");
}
Output
Adult

if in C works like in most languages: a condition in brackets and a block in curly braces. In C, true is any number except 0, and false is 0.

Combine conditions with && (and), || (or) and ! (not). For example: if (age >= 13 && age < 18).

Line by line

if (age >= 18) {check: age is 18 or more.
} else if (age >= 13) {otherwise check the next condition.
} else {if nothing fits.

Common mistakes

  • if (x = 5) assigns 5 and is always true. Compare with ==.

Try it yourself

    printf("OK\n");
}
Output

Loops

for has three parts: start, condition, step. i++ adds 1, count-- takes 1 away.

for (int i = 0; i < 3; i++) {
    printf("Step %d\n", i);
}

int count = 3;
while (count > 0) {
    printf("%d\n", count);
    count--;
}
Output
Step 0
Step 1
Step 2
3
2
1

C loops: for (start; condition; step), while (repeat while true) and do ... while, which runs at least once. They are the same as in JavaScript, C++, Java and C# — learn them once, use them everywhere.

break leaves a loop early, continue skips to the next round.

Line by line

for (int i = 0; i < 3; i++)i = 0, 1, 2; after each round i grows by 1.
while (count > 0)repeat while count is positive.
count--;take 1 away.

Common mistakes

  • for (int i = 0; i <= 3; i++) runs 4 times, not 3 — watch < vs <=.

Try it yourself

Print the numbers from 1 to 5.

Show answer 
for (int i = 1; i <= 5; i++) {
    printf("%d\n", i);
}
Output
1
2
3
4

Functions

A function has a return type, a name and parameters with types. It must be written before it is used.

#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main(void) {
    printf("%d\n", add(2, 3));
    return 0;
}
Output
5

A C function says what type it returns, its name and the types of its parameters: int add(int a, int b). A function that returns nothing has the type void.

The compiler reads from top to bottom, so a function must be written (or announced) above the place where you call it.

Line by line

int add(int a, int b) {returns an int, takes two ints.
return a + b;give back the sum.
add(2, 3)call the function: a = 2, b = 3.

Common mistakes

  • Writing the function below main without a declaration — the compiler complains.

Arrays

An array stores many values of one type. Counting starts from 0. C doesn't store the length, so we calculate it with sizeof.

int scores[] = {10, 20, 30, 40};
int size = sizeof(scores) / sizeof(scores[0]);
int sum = 0;

for (int i = 0; i < size; i++) {
    sum += scores[i];
}
printf("Sum: %d\n", sum);
Output
Sum: 100

An array in C is a fixed number of values of one type standing next to each other in memory. Its size can't change after creation.

C doesn't check if the index is valid: scores[10] in an array of 4 reads someone else's memory. This is a classic source of bugs, so always keep track of the size.

Line by line

int scores[] = {10, 20, 30, 40};an array of 4 ints; the size is counted from the list.
sizeof(scores) / sizeof(scores[0])total bytes divided by bytes of one item = number of items.
sum += scores[i];add each item to sum.

Common mistakes

  • Going one step too far: i <= size instead of i < size.

Try it yourself

Show answer

for (int i = 1; i < 4; i++) {
    if (a[i] > max) max = a[i];
}
printf("%d\n", max);
Output
9

Mini project: guess the number

Everything together. rand() gives a random number, scanf reads what the player types. The output below is an example game.

#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void) {
    srand(time(NULL));
    int secret = rand() % 10 + 1;
    int guess = 0;

    while (guess != secret) {
        printf("Guess a number from 1 to 10: ");
        scanf("%d", &guess);
        if (guess < secret) printf("Bigger!\n");
        else if (guess > secret) printf("Smaller!\n");
    }
    printf("You got it!\n");
    return 0;
}
Output
Guess a number from 1 to 10: 5
Bigger!
Guess a number from 1 to 10: 8
Smaller!
Guess a number from 1 to 10: 7
You got it!

rand() gives a pseudo-random number; % 10 keeps the remainder from 0 to 9, and + 1 makes it 1 to 10. srand(time(NULL)) mixes the generator with the current time so each game is different.

scanf("%d", &guess) reads a number from the keyboard. The & means "the address of guess": scanf needs to know where to put the value.

Line by line

srand(time(NULL));start the random generator from the current time.
rand() % 10 + 1a random number from 1 to 10.
scanf("%d", &guess);read a whole number into guess.

Common mistakes

  • Forgetting & in scanf — the program may crash.

Try it yourself

Add a tries counter and print it at the end.

Show answer 
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void) {
    srand(time(NULL));
    int secret = rand() % 10 + 1;
    int guess = 0, tries = 0;

    while (guess != secret) {
        printf("Guess a number from 1 to 10: ");
        scanf("%d", &guess);
        tries++;
        if (guess < secret) printf("Bigger!\n");
        else if (guess > secret) printf("Smaller!\n");
    }
    printf("You got it in %d tries!\n", tries);
    return 0;
}

Quiz

5 questions. Pick an answer to see if it is right.

1. What will this code print?

int x = 7;
printf("%d\n", x / 2);

Both are whole numbers, so C drops the part after the dot.

2. Which code prints a whole number in printf?

%d is a whole number, %s text, %c one character, %f a number with a dot.

3. What will this code print?

int a[] = {4, 8, 15};
printf("%d\n", a[2]);

Counting starts from 0: a[0]=4, a[1]=8, a[2]=15.

4. What will this code print?

for (int i = 0; i < 3; i++) {
    printf("%d", i);
}

i goes 0, 1, 2 and stops when it reaches 3.

5. Where does every C program start?

The program always starts running from main().
