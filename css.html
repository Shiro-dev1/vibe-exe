CSS.LESSONS

HTML says what is on the page, CSS says how it looks: colors, fonts, sizes, layout and animations.

01 CONNECT CSS 02 SELECTORS 03 COLORS AND FONTS 04 SPACING AND BORDERS 05 FLEXBOX 06 GRID 07 ANIMATIONS 08 PHONES
01_CONNECT_CSS01/08

Put styles in a file style.css and connect it inside <head>. A rule is: who to style, then { property: value; }.

<!-- index.html, inside <head> -->
<link rel="stylesheet" href="style.css">

/* style.css */
body {
  background: black;
  color: white;
}
02_SELECTORS02/08

A selector picks which elements to style. A class (.) can be used many times, an id (#) only once on a page.

p { color: gray; }            /* every <p> */
.card { border: 2px solid; }  /* class="card" */
#logo { font-size: 32px; }    /* id="logo" */
a:hover { color: white; }     /* link under the mouse */
03_COLORS_AND_FONTS03/08

Colors can be names, #hex codes or rgb(). Fonts are listed in order: if the first is missing, the next one is used.

h1 {
  color: #ffffff;
  background: rgb(0, 0, 0);
  font-family: Arial, sans-serif;
  font-size: 48px;
  font-weight: bold;
  text-align: center;
}
04_SPACING_AND_BORDERS04/08

Every element is a box. padding is space inside the border, margin is space outside it.

.card {
  width: 300px;
  padding: 16px;          /* inside */
  border: 2px solid white;
  margin: 24px;           /* outside */
  border-radius: 8px;     /* round corners */
}
05_FLEXBOX05/08

Flexbox puts elements in a row (or column) and spaces them out. Great for menus and headers.

.menu {
  display: flex;
  justify-content: space-between; /* along the row */
  align-items: center;            /* across the row */
  gap: 16px;
}
06_GRID06/08

Grid places elements in rows and columns. 1fr means "one equal part", so this makes 3 equal columns.

.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}
07_ANIMATIONS07/08

transition makes a change smooth. @keyframes describes an animation step by step. This is how the blinking cursor on this site works.

.button {
  transition: transform 0.2s;
}
.button:hover {
  transform: scale(1.1);
}

.cursor {
  animation: blink 1s infinite;
}
@keyframes blink {
  50% { opacity: 0; }
}
08_PHONES08/08

@media applies styles only on some screens. Here the gallery becomes one column on narrow phones.

@media (max-width: 600px) {
  .gallery {
    grid-template-columns: 1fr;
  }
}
