Connect CSS

Put styles in a file style.css and connect it inside <head>. A rule is: who to style, then { property: value; }.

<!-- index.html, inside <head> -->
<link rel="stylesheet" href="style.css">

/* style.css */
body {
  background: black;
  color: white;
}

CSS stands for Cascading Style Sheets. One CSS file can style the whole site, so you change a color once and every page updates.

A rule has a selector (who) and declarations (what): body { color: white; }. Each declaration is property: value; — don't forget the colon and the semicolon.

Line by line

<link rel="stylesheet" href="style.css">connect the file style.css to the page.
body {the selector: style the whole page body.
background: black;the background color.
color: white;the text color.

Common mistakes

  • A wrong path in href — the styles silently don't load. Check the file name and folder.

Try it yourself

Make the whole page dark blue with yellow text.

Show answer 
body {
  background: navy;
  color: yellow;
}
02 / 08

Selectors

A selector picks which elements to style. A class (.) can be used many times, an id (#) only once on a page.

p { color: gray; }            /* every <p> */
.card { border: 2px solid; }  /* class="card" */
#logo { font-size: 32px; }    /* id="logo" */
a:hover { color: white; }     /* link under the mouse */

Selectors are how CSS finds elements. A tag selector (p) styles all such tags. A class (.card) styles any element with class="card". An id (#logo) styles one unique element.

If two rules disagree, the more specific one wins: id is stronger than class, class is stronger than tag. If they are equal, the later rule wins — that is the "cascade".

Line by line

p { ... }all paragraphs.
.card { ... }every element with class="card".
#logo { ... }the one element with id="logo".
a:hover { ... }:hover is a state — the link while the mouse is over it.

Common mistakes

  • Forgetting the dot: card { } looks for a <card> tag, not the class.

Try it yourself

Make all buttons with class "big" have font size 24px.

Show answer 
.big {
  font-size: 24px;
}
03 / 08

Colors and fonts

Colors can be names, #hex codes or rgb(). Fonts are listed in order: if the first is missing, the next one is used.

h1 {
  color: #ffffff;
  background: rgb(0, 0, 0);
  font-family: Arial, sans-serif;
  font-size: 48px;
  font-weight: bold;
  text-align: center;
}

Colors can be written in several ways: names (white), hex codes (#ff8800 — red, green, blue from 00 to ff) or rgb(255, 136, 0). Add transparency with rgba(0, 0, 0, 0.5).

font-family lists fonts by priority; always end with a general family like sans-serif. font-size is the size, font-weight the thickness (400 normal, 700 bold).

Line by line

color: #ffffff;white text in hex.
font-family: Arial, sans-serif;use Arial; if it is missing, any sans-serif font.
text-align: center;center the text inside the element.

Common mistakes

  • Missing # in hex: color: ffffff; doesn't work.

Try it yourself

Make h2 headings orange (#ff8800), bold and 32px.

Show answer 
h2 {
  color: #ff8800;
  font-weight: bold;
  font-size: 32px;
}
04 / 08

Spacing and borders

Every element is a box. padding is space inside the border, margin is space outside it.

.card {
  width: 300px;
  padding: 16px;          /* inside */
  border: 2px solid white;
  margin: 24px;           /* outside */
  border-radius: 8px;     /* round corners */
}

Every element is a rectangle (a "box"). From inside out: the content, then padding, then border, then margin. Background color fills content and padding, but not margin.

Tip: add box-sizing: border-box; so that width includes padding and border. Then a 300px card stays 300px wide.

Line by line

width: 300px;the width of the box.
padding: 16px;space between the content and the border.
border: 2px solid white;thickness, style and color of the border.
margin: 24px;space outside, between this box and others.

Common mistakes

  • Confusing padding and margin. Remember: padding is inside, margin is outside.

Try it yourself

Make a .note box: 20px padding, a 1px grey dashed border and round corners of 12px.

Show answer 
.note {
  padding: 20px;
  border: 1px dashed grey;
  border-radius: 12px;
}
05 / 08

Flexbox

Flexbox puts elements in a row (or column) and spaces them out. Great for menus and headers.

.menu {
  display: flex;
  justify-content: space-between; /* along the row */
  align-items: center;            /* across the row */
  gap: 16px;
}

Flexbox arranges the children of an element in one line. You put display: flex on the parent, and the children line up.

justify-content moves items along the line (start, center, space-between), align-items across it (top, center, bottom). gap adds space between items. flex-direction: column turns the row into a column.

Line by line

display: flex;turn on flexbox for this element's children.
justify-content: space-between;first item at the start, last at the end, the rest spread out.
align-items: center;center items vertically.
gap: 16px;16px between items.

Common mistakes

  • Putting display: flex on the children instead of the parent.

Try it yourself

Center a single element inside .box both ways using flexbox.

Show answer 
.box {
  display: flex;
  justify-content: center;
  align-items: center;
}
06 / 08

Grid

Grid places elements in rows and columns. 1fr means "one equal part", so this makes 3 equal columns.

.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}

Grid is for two dimensions: rows and columns at once, like a table for layout. You describe the columns on the parent, and children fill the cells in order.

repeat(3, 1fr) = three equal columns. 200px 1fr = a fixed sidebar and the rest of the space. gap works here too.

Line by line

display: grid;turn on grid.
grid-template-columns: repeat(3, 1fr);three columns of equal width.
gap: 12px;space between cells.

Common mistakes

  • Using grid for a single row of buttons — flexbox is simpler for one line.

Try it yourself

Make a layout with a 250px sidebar and a main area taking the rest.

Show answer 
.layout {
  display: grid;
  grid-template-columns: 250px 1fr;
}
07 / 08

Animations

transition makes a change smooth. @keyframes describes an animation step by step. This is how the blinking cursor on this site works.

.button {
  transition: transform 0.2s;
}
.button:hover {
  transform: scale(1.1);
}

.cursor {
  animation: blink 1s infinite;
}
@keyframes blink {
  50% { opacity: 0; }
}

transition animates a change between two states, for example when you hover. You say which property and how long: transition: transform 0.2s.

@keyframes describes a full animation by percent of time. Then animation: name 1s infinite plays it: the name, the length and how many times.

Line by line

transition: transform 0.2s;changes of transform take 0.2 seconds.
transform: scale(1.1);make the element 10% bigger.
@keyframes blink { 50% { opacity: 0; } }at half the time the element is invisible.
animation: blink 1s infinite;play blink for 1 second, forever.

Common mistakes

  • Different names in @keyframes and animation — nothing moves.

Try it yourself

Make a .card lift 4px up smoothly when hovered.

Show answer 
.card {
  transition: transform 0.2s;
}
.card:hover {
  transform: translateY(-4px);
}
08 / 08

Phones

@media applies styles only on some screens. Here the gallery becomes one column on narrow phones.

@media (max-width: 600px) {
  .gallery {
    grid-template-columns: 1fr;
  }
}

Most visitors use phones, so a site must work on narrow screens. @media applies rules only when a condition is true, usually a screen width.

For this to work, the page needs <meta name="viewport" content="width=device-width, initial-scale=1"> in head. Without it, phones pretend to be wide and shrink the page.

Line by line

@media (max-width: 600px) {the rules inside work only on screens up to 600px wide.
grid-template-columns: 1fr;one column instead of three.

Common mistakes

  • Forgetting the viewport meta tag — media queries seem not to work on phones.

Try it yourself

Hide the .sidebar on screens narrower than 700px.

Show answer 
@media (max-width: 700px) {
  .sidebar {
    display: none;
  }
}

Quiz

5 questions. Pick an answer to see if it is right.

1. Which selector picks elements with class="card"?

A dot means class, # means id.

2. Which property is the space INSIDE the border?

padding is inside, margin is outside.

3. What does this make?

.box {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

1fr is one equal part, repeated 3 times: three equal columns.

4. Which property changes the text color?

color is the text color, background is the color behind it.

5. When will these styles work?

@media (max-width: 600px) {
  .menu { display: none; }
}

max-width: 600px means "up to 600 pixels wide": phones.
