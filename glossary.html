Glossary

The main programming words in plain language. Don't get a word in a lesson? Look it up here.

API

A way for one program to ask another to do something or give data. For example, a bot asks Telegram for new messages.

A café menu: you don't go to the kitchen, you order from the menu and get the dish.

Array / list

Many values stored in order in one variable. Counting starts from 0.

Like a numbered shelf: item 0, item 1, item 2…
langs = ["Python", "Go"]
In lessons: Python, JavaScript, Go

Backend

The part that works on the server: data, accounts, payments.

The warehouse and office behind the shop.
In lessons: PHP, Go, Java

Boolean

A value that is only true or false. Conditions work with it.

Like a light switch: on or off, nothing in between.
online = True
In lessons: Python, Java, C#

Browser

A program that opens websites: Chrome, Firefox, Safari. It also runs JavaScript.

A window into the internet.
In lessons: JavaScript, HTML

Bug

A mistake in a program that makes it work wrong.

The word comes from a real moth found inside a computer in 1947.

Class

A blueprint for objects. It describes what every object of this kind has and can do.

A cookie cutter: one shape, many cookies.
class Player:
In lessons: C++, C#, Java

Client

The side that asks a server for something — usually your browser or app.

The guest at a restaurant who makes the order.

Comment

A note in the code for people. The computer skips it.

A sticky note on a recipe: "less salt next time".
# this is a comment
In lessons: Python, C

Commit

One saved step in Git with a short note about what changed.

A photo of your work at one moment.

Compiler

A program that turns your code into a language the computer understands before it runs, and finds mistakes on the way.

A translator who translates the whole book before anyone reads it.
In lessons: C, C++, Rust, Go, Java

Condition

A check that decides which code runs: if something is true, do this, otherwise do that.

"If it's raining, take an umbrella, otherwise — sunglasses."
if age >= 18:
    print("Adult")
In lessons: Python, JavaScript, Go

Console

A text window where a program prints messages and errors.

The program's diary: it writes down what it's doing.
console.log("hi")
In lessons: JavaScript

CSS

The language that says how a page looks: colors, fonts, layout, animations.

The paint and furniture in the house.
h1 { color: white; }
In lessons: CSS

Data type

What kind of value it is: whole number, number with a dot, text, true/false. The type decides what you can do with it.

Numbers can be added, words can't — just like you can't add "cat" and 5.
In lessons: Python, TypeScript, Java

Database

An organized place to store data so it's easy to find, add and change: users, orders, messages.

A huge, perfectly sorted card catalog.

Debugging

Finding and fixing bugs: reading errors, printing values, checking step by step.

Like a detective looking for clues.

Domain

The name of a site in the address bar, like github.io.

A street address, but for a website.

Framework

A big set of ready code and rules for building a certain kind of app, like websites or games.

A house kit: walls and rooms are already planned, you add the rest.

Frontend

The part of an app people see and click: the page in the browser.

The shop window and the shop floor.
In lessons: HTML, CSS, JavaScript

Function

A named piece of code that does one job. Write it once — call it as many times as you want.

Like a coffee machine button: press "latte" and get a latte without thinking how it's made.
def greet(name):
    return "Hello, " + name
In lessons: Python, JavaScript, Rust

Git

A program that remembers every version of your code, so you can go back and work together.

"Save game" for code.
git commit -m "fix"

Hosting

A service that keeps your site on a server so people can open it online. This site uses GitHub Pages.

Renting a spot for your shop on a busy street.

HTML

The markup language that says what is on a web page: headings, text, links, images.

The skeleton of a house.
<h1>Hello</h1>
In lessons: HTML

Interpreter

A program that reads your code and runs it line by line, without a separate compile step.

A live interpreter who translates a speech sentence by sentence.
In lessons: Python, JavaScript, PHP

Library

Ready-made code written by other people that you can use in your program.

A box of ready-made LEGO parts instead of carving each brick yourself.
import random
In lessons: Python

Loop

Repeating the same code several times or while a condition stays true.

Like "do 10 squats": one move repeated 10 times.
for i in range(10):
In lessons: Python, C, Go

Method

A function that belongs to an object or a class.

The player's "jump" button — an action of exactly this player.
player.hit(30)
In lessons: Java, C#, Go

Object

A thing in a program that holds data (fields) and actions (methods) together.

A player in a game: has a name and health, and can jump and attack.
In lessons: JavaScript, TypeScript

Open source

Code anyone can read, use and improve for free.

A recipe shared publicly that anyone can cook and improve.

Parameter

A value you give to a function so it can do its job. It goes in the brackets.

Like telling a barista "large, no sugar" — the order details.
greet("Shiro")
In lessons: Python, TypeScript

Repository

A project folder tracked by Git, often stored on GitHub.

A project's home with its whole history inside.

Return value

The result a function gives back with return.

The finished coffee the machine hands you.
return a + b
In lessons: Python, Rust

Server

A computer that is always on and answers requests: sends pages, stores data.

A kitchen that takes orders and cooks them.
In lessons: PHP, Go

String

Text in a program. It is written in quotes.

Like a line of letters on a necklace: each letter is a bead.
"Hello, world!"
In lessons: Python, JavaScript

Syntax

The writing rules of a language: where brackets, colons and quotes go.

Like grammar and punctuation in a normal language.

Terminal

A window where you control the computer with text commands instead of the mouse.

Talking to the computer by typing instead of pointing.
ls -la

Variable

A named box that stores a value: a number, text or a list. You can read it by name or replace it.

Like a label on a jar: "sugar". You can change what's inside, the label stays.
age = 18
In lessons: Python, JavaScript, C
