Programming languages

A language is how you talk to a computer. Each one is good at something different. Here are twelve you will meet most often, each with the classic first program: printing "Hello, world!".

Python

Born
1991
Author
Guido van Rossum
Used for
bots, scripts, automation, data, AI

Simple and readable, almost like English. A great first language. Most Telegram bots are written in Python.

Open lessons →
print("Hello, world!")

JavaScript

Born
1995
Author
Brendan Eich (Netscape)
Used for
interactive websites, servers (Node.js)

The language of the web: it runs in every browser. The eye on the home page is JavaScript.

Open lessons →
console.log("Hello, world!");

TypeScript

Born
2012
Author
Anders Hejlsberg (Microsoft)
Used for
big websites and web apps

JavaScript with types. The same author created C#. Used by VS Code, Slack and many large sites.

Open lessons →
console.log("Hello, world!");

HTML

Born
1991
Author
Tim Berners-Lee
Used for
the structure of every web page

Not a programming language but a markup language: it says what is on the page — headings, text, buttons, images.

Open lessons →
<h1>Hello, world!</h1>

CSS

Born
1996
Author
Håkon Wium Lie
Used for
colors, fonts, layout, animations

HTML says what is on the page, CSS says how it looks. This black and white style is CSS.

Open lessons →
h1 { color: white; background: black; }

PHP

Born
1995
Author
Rasmus Lerdorf
Used for
websites, blogs, online shops

Runs on the server and builds pages. WordPress, Wikipedia and Facebook's first version were made with PHP.

Open lessons →
<?php
echo "Hello, world!";

Java

Born
1995
Author
James Gosling (Sun Microsystems)
Used for
Android apps, servers, big company systems

Strict and reliable, runs on almost any device. Android apps and Minecraft are written in Java.

Open lessons →
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, world!");
    }
}

C

Born
1972
Author
Dennis Ritchie (Bell Labs)
Used for
operating systems, drivers, fast programs

Old, fast and close to the hardware. The Linux kernel is written in C.

Open lessons →
#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}

C++

Born
1985
Author
Bjarne Stroustrup (Bell Labs)
Used for
games, game engines, browsers, fast apps

C with classes and many tools on top. Unreal Engine and Chrome are written in C++.

Open lessons →
#include <iostream>

int main() {
    std::cout << "Hello, world!" << std::endl;
    return 0;
}

C#

Born
2000
Author
Anders Hejlsberg (Microsoft)
Used for
Unity games, Windows apps, websites

A language from Microsoft, similar to Java and C++ but easier. Most Unity games are written in C#.

Open lessons →
Console.WriteLine("Hello, world!");

Go

Born
2009
Author
Robert Griesemer, Rob Pike, Ken Thompson (Google)
Used for
servers, cloud services, command line tools

Simple, fast and great at doing many things at once. Docker and Kubernetes are written in Go.

Open lessons →
package main

import "fmt"

func main() {
	fmt.Println("Hello, world!")
}

Rust

Born
2015 (version 1.0)
Author
Graydon Hoare, Mozilla
Used for
fast and safe system software

As fast as C, but the compiler catches many memory mistakes before the program even runs.

Open lessons →
fn main() {
    println!("Hello, world!");
}
