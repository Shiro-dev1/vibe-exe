Hello, world

Every program starts in fn main(). The ! in println! means it is a macro: a special helper that writes code for you.

fn main() {
    println!("Hello, world!");
}
Output
Hello, world!

Rust programs are built with cargo or rustc, and you can try Rust in the browser at play.rust-lang.org. Every program starts in fn main().

println! prints a line. The exclamation mark shows it is a macro, not a normal function: it checks the text template while compiling.

Line by line

fn main() {fn = function; main is where the program starts.
println!("Hello, world!");print the text and a line break.

Common mistakes

  • Forgetting the !: println("...") — Rust can't find such a function.

Try it yourself

Print your name and on the next line 2026.

Show answer 
fn main() {
    println!("Shiro");
    println!("{}", 2026);
}
Output
Shiro
2026

Variables

let creates a variable. By default it can't change; add mut to allow it. Variables go into text with { }.

fn main() {
    let name = "Shiro";
    let mut age = 18; // mut = can change
    age += 1;
    println!("Hi, I'm {name} and I'm {age}");
}
Output
Hi, I'm Shiro and I'm 19

In Rust variables can't change by default. This protects you from changing something by accident. If a value must change, you say so with mut.

Inside println!, {name} inserts a variable directly; {} takes the next value after the text: println!("{} + {}", a, b).

Line by line

let name = "Shiro";a variable that can't change.
let mut age = 18;mut allows changes.
age += 1;age becomes 19.

Common mistakes

  • Changing a variable without mut — error: cannot assign twice to immutable variable.

Try it yourself

Create city = "Kyiv" and year = 2020, print: I live in Kyiv since 2020.

Show answer 
fn main() {
    let city = "Kyiv";
    let year = 2020;
    println!("I live in {city} since {year}");
}
Output
I live in Kyiv since 2020

Data types

Rust usually guesses the type, but you can write it after :. From here on, short examples go inside fn main().

let count: i32 = 10;      // whole number
let price: f64 = 9.99;    // number with a dot
let online: bool = true;  // true or false
let letter: char = 'S';   // one character
let title: &str = "VIBE"; // text

println!("{}", title.len());
Output
4

Number types say their size: i32 is a whole number of 32 bits (with sign), u8 is from 0 to 255, f64 is a number with a dot. &str is a piece of text, String is text you own and can change.

Turn text into a number with "5".parse::<i32>().unwrap() — unwrap means "I'm sure it worked".

Line by line

let count: i32 = 10;the type after a colon.
let title: &str = "VIBE";a text slice.
title.len()length in bytes (for English letters = number of letters).

Common mistakes

  • Mixing types: i32 + f64 doesn't compile. Convert: count as f64 + price.

Try it yourself

You have let a = "7". Print a as a number plus 3 (10).

Show answer 
let a = "7";
let n: i32 = a.parse().unwrap();
println!("{}", n + 3);
Output
10

Conditions

if works without brackets around the condition, but the { } are required.

let age = 18;

if age >= 18 {
    println!("Adult");
} else if age >= 13 {
    println!("Teen");
} else {
    println!("Kid");
}
Output
Adult

if in Rust doesn't need brackets around the condition, but the braces are required. The condition must be a bool.

if can also give back a value: let label = if age >= 18 { "Adult" } else { "Kid" };.

Line by line

if age >= 18 {no brackets, but braces.
} else if age >= 13 {next check.

Common mistakes

  • if count { } with a number — Rust wants a real bool: if count > 0.

Try it yourself

Show answer

} else {
    println!("OK");
}
Output

Loops

0..3 means 0, 1, 2. while repeats while the condition is true.

for i in 0..3 {
    println!("Step {i}");
}

let mut count = 3;
while count > 0 {
    println!("{count}");
    count -= 1;
}
Output
Step 0
Step 1
Step 2
3
2
1

for i in 0..3 goes through a range: 0, 1, 2. 0..=3 includes the end: 0, 1, 2, 3. while repeats while true, and loop repeats forever until you break.

Line by line

for i in 0..3 {i = 0, 1, 2.
let mut count = 3;mut, because count will change.
count -= 1;take 1 away.

Common mistakes

  • Forgetting mut on a loop counter you change.

Try it yourself

Print the numbers from 1 to 5.

Show answer 
for i in 1..=5 {
    println!("{i}");
}
Output
1
2
3
4
5

Functions

Parameters need types, -> shows the return type. The last line without ; is the value the function returns.

fn add(a: i32, b: i32) -> i32 {
    a + b // no ; = this is returned
}

fn main() {
    println!("{}", add(2, 3));
}
Output
5

Every parameter needs a type, and -> shows what the function returns. Rust has a nice rule: the last expression without ; is the result, so you often don't need return.

If you put ; at the end of that last line, it becomes a statement and the function returns nothing — a common mistake.

Line by line

fn add(a: i32, b: i32) -> i32 {two i32 in, one i32 out.
a + bno semicolon: this is the result.

Common mistakes

  • a + b; with a semicolon — error: mismatched types, expected i32, found ().

Try it yourself

Write fn square(n: i32) -> i32 and print square(7).

Show answer 
fn square(n: i32) -> i32 {
    n * n
}

fn main() {
    println!("{}", square(7));
}
Output
49

Vectors

vec! makes a list that can grow. It needs mut to change. &langs lets the loop read the list without taking it away.

let mut langs = vec!["Python", "C", "Rust"];
langs.push("C#");
println!("{}", langs.len());

for lang in &langs {
    println!("I like {lang}");
}
Output
4
I like Python
I like C
I like Rust
I like C#

Vec is a growable list; vec![...] creates one quickly. It needs mut to add items.

Rust is careful about who owns data. for lang in &langs borrows the vector just to read it, so you can still use langs after the loop. Without & the loop would take the vector away.

Line by line

let mut langs = vec![...];a vector you can change.
langs.push("C#");add to the end.
for lang in &langs {read every item without taking the vector.

Common mistakes

  • Using a vector after for x in v (without &) — error: value used after move.

Try it yourself

Make vec![1, 2, 3], push 4 and print the sum using .iter().sum::<i32>().

Show answer 
let mut v = vec![1, 2, 3];
v.push(4);
println!("{}", v.iter().sum::<i32>());
Output
10

Mini project: a game hero

A struct stores data, impl adds functions to it. &mut self means the function can change the player.

struct Player {
    name: String,
    hp: i32,
}

impl Player {
    fn hit(&mut self, damage: i32) {
        self.hp -= damage;
        println!("{} has {} HP", self.name, self.hp);
    }
}

fn main() {
    let mut p = Player { name: String::from("Shiro"), hp: 100 };
    p.hit(30);
    p.hit(25);
}
Output
Shiro has 70 HP
Shiro has 45 HP

Rust has no classes; instead a struct holds data and an impl block adds methods to it. &mut self in a method means "this method may change the object", &self means it only reads.

The player must be declared let mut p, because hit changes it.

Line by line

struct Player { name: String, hp: i32 }what every player has.
impl Player {methods of Player.
fn hit(&mut self, damage: i32)can change the player.
String::from("Shiro")make an owned String from text.

Common mistakes

  • let p = ... without mut, then p.hit(30) — error: cannot borrow as mutable.

Try it yourself

Add a heal(&mut self, amount: i32) method and heal the player by 10 after the hits.

Show answer 
struct Player {
    name: String,
    hp: i32,
}

impl Player {
    fn hit(&mut self, damage: i32) {
        self.hp -= damage;
        println!("{} has {} HP", self.name, self.hp);
    }
    fn heal(&mut self, amount: i32) {
        self.hp += amount;
        println!("{} has {} HP", self.name, self.hp);
    }
}

fn main() {
    let mut p = Player { name: String::from("Shiro"), hp: 100 };
    p.hit(30);
    p.hit(25);
    p.heal(10);
}
Output
Shiro has 70 HP
Shiro has 45 HP
Shiro has 55 HP

Quiz

5 questions. Pick an answer to see if it is right.

1. What will this code print?

let mut x = 5;
x += 3;
println!("{x}");

x is mut, so it can change: 5 + 3 = 8.

2. What happens here?

let x = 5;
x = 6;

Without mut a variable can't change, and Rust won't compile it.

3. How many times will the loop run?

for i in 0..3 {
    println!("{i}");
}

0..3 is 0, 1, 2: the end number is not included.

4. What will this code print?

fn double(n: i32) -> i32 {
    n * 2
}

fn main() {
    println!("{}", double(21));
}

The last line without ; is returned: 21 * 2 = 42.

5. What will this code print?

let v = vec![1, 2, 3];
println!("{}", v.len());

len() is how many items are in the vector: 3.
