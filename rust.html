RUST LESSONS

Rust is as fast as C, but its compiler catches many mistakes before the program even runs. It is loved for safe system software and command line tools.

01_HELLO_WORLD01/08

Every program starts in fn main(). The ! in println! means it is a macro: a special helper that writes code for you.

fn main() {
    println!("Hello, world!");
}
OUTPUT
Hello, world!
02_VARIABLES02/08

let creates a variable. By default it can't change; add mut to allow it. Variables go into text with { }.

fn main() {
    let name = "Shiro";
    let mut age = 18; // mut = can change
    age += 1;
    println!("Hi, I'm {name} and I'm {age}");
}
OUTPUT
Hi, I'm Shiro and I'm 19
03_DATA_TYPES03/08

Rust usually guesses the type, but you can write it after :. From here on, short examples go inside fn main().

let count: i32 = 10;      // whole number
let price: f64 = 9.99;    // number with a dot
let online: bool = true;  // true or false
let letter: char = 'S';   // one character
let title: &str = "VIBE"; // text

println!("{}", title.len());
OUTPUT
4
04_CONDITIONS04/08

if works without brackets around the condition, but the { } are required.

let age = 18;

if age >= 18 {
    println!("Adult");
} else if age >= 13 {
    println!("Teen");
} else {
    println!("Kid");
}
OUTPUT
Adult
05_LOOPS05/08

0..3 means 0, 1, 2. while repeats while the condition is true.

for i in 0..3 {
    println!("Step {i}");
}

let mut count = 3;
while count > 0 {
    println!("{count}");
    count -= 1;
}
OUTPUT
Step 0
Step 1
Step 2
3
2
1
06_FUNCTIONS06/08

Parameters need types, -> shows the return type. The last line without ; is the value the function returns.

fn add(a: i32, b: i32) -> i32 {
    a + b // no ; = this is returned
}

fn main() {
    println!("{}", add(2, 3));
}
OUTPUT
5
07_VECTORS07/08

vec! makes a list that can grow. It needs mut to change. &langs lets the loop read the list without taking it away.

let mut langs = vec!["Python", "C", "Rust"];
langs.push("C#");
println!("{}", langs.len());

for lang in &langs {
    println!("I like {lang}");
}
OUTPUT
4
I like Python
I like C
I like Rust
I like C#
08_MINI_PROJECT_A_GAME_HERO08/08

A struct stores data, impl adds functions to it. &mut self means the function can change the player.

struct Player {
    name: String,
    hp: i32,
}

impl Player {
    fn hit(&mut self, damage: i32) {
        self.hp -= damage;
        println!("{} has {} HP", self.name, self.hp);
    }
}

fn main() {
    let mut p = Player { name: String::from("Shiro"), hp: 100 };
    p.hit(30);
    p.hit(25);
}
OUTPUT
Shiro has 70 HP
Shiro has 45 HP
QUIZ.EXE5 QUESTIONS

01. What will this code print?

let mut x = 5;
x += 3;
println!("{x}");

x is mut, so it can change: 5 + 3 = 8.

02. What happens here?

let x = 5;
x = 6;

Without mut a variable can't change, and Rust won't compile it.

03. How many times will the loop run?

for i in 0..3 {
    println!("{i}");
}

0..3 is 0, 1, 2: the end number is not included.

04. What will this code print?

fn double(n: i32) -> i32 {
    n * 2
}

fn main() {
    println!("{}", double(21));
}

The last line without ; is returned: 21 * 2 = 42.

05. What will this code print?

let v = vec![1, 2, 3];
println!("{}", v.len());

len() is how many items are in the vector: 3.
