02 / 08

Variables

Every variable has a type. var lets C# guess it. Put $ before quotes to insert variables with { }.

string name = "Shiro";
int age = 18;
var lang = "C#";   // C# guesses: string

Console.WriteLine($"Hi, I'm {name}, {age}, I learn {lang}");
Output
Hi, I'm Shiro, 18, I learn C#

Conditions

if runs code only when the condition in brackets is true.

int age = 18;

if (age >= 18)
{
    Console.WriteLine("Adult");
}
else if (age >= 13)
{
    Console.WriteLine("Teen");
}
else
{
    Console.WriteLine("Kid");
}
Output
Adult
05 / 08

Loops

for has three parts: start, condition, step. while repeats while the condition is true.

for (int i = 0; i < 3; i++)
{
    Console.WriteLine($"Step {i}");
}

int count = 3;
while (count > 0)
{
    Console.WriteLine(count);
    count--;
}
Output
Step 0
Step 1
Step 2
3
2
1
06 / 08

Functions

In C# functions are called methods. You write the return type, the name and the parameters with types.

string Greet(string name)
{
    return $"Hello, {name}!";
}

Console.WriteLine(Greet("Shiro"));
Output
Hello, Shiro!
07 / 08

Lists

List is a list that can grow. Add puts an item at the end, Count is how many there are, foreach goes through every item.

var langs = new List<string> { "Python", "C#", "Rust" };
langs.Add("C++");
Console.WriteLine(langs.Count);

foreach (var lang in langs)
{
    Console.WriteLine($"I like {lang}");
}
Output
4
I like Python
I like C#
I like Rust
I like C++

Mini project: a game hero

A class joins data and methods into one thing. Games made in Unity are written exactly like this.

var p = new Player("Shiro");
p.Hit(30);
p.Hit(25);

class Player
{
    public string Name;
    public int Hp = 100;

    public Player(string name)
    {
        Name = name;
    }

    public void Hit(int damage)
    {
        Hp -= damage;
        Console.WriteLine($"{Name} has {Hp} HP");
    }
}
Output
Shiro has 70 HP
Shiro has 45 HP

Quiz

5 questions. Pick an answer to see if it is right.

1. What will this code print?

string name = "Shiro";
Console.WriteLine($"Hi, {name}!");

$ before the quotes puts the value of name into the text.

2. How do you add an item to a List?

var langs = new List<string>();

List uses Add. push is JavaScript, append is Python.

3. What will this code print?

int x = 10;
x--;
Console.WriteLine(x);

x-- takes 1 away: 10 becomes 9.

4. Which type stores true or false?

bool (boolean) is only true or false.

5. Which game engine mostly uses C#?

Unity games are written in C#. Unreal uses C++.
