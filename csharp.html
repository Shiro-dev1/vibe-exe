Hello, world

In modern C# (.NET 6 and newer) this one line is a whole program. In older code you will see it wrapped in class Program and static void Main().

Console.WriteLine("Hello, world!");
Output
Hello, world!

C# programs run on .NET, a free platform from Microsoft. Modern C# lets you write a program as a list of lines at the top of a file ("top-level statements") — that's why one line is enough.

Console is the text window, WriteLine writes a line and moves to the next one. Write (without Line) stays on the same line.

Line by line

Consolethe console window.
.WriteLine("Hello, world!");write the text and a line break.

Common mistakes

  • console.writeline in small letters — C# is case-sensitive: Console.WriteLine.

Try it yourself

Print your name and on the next line 2026.

Show answer 
Console.WriteLine("Shiro");
Console.WriteLine(2026);
Output
Shiro
2026

Variables

Every variable has a type. var lets C# guess it. Put $ before quotes to insert variables with { }.

string name = "Shiro";
int age = 18;
var lang = "C#";   // C# guesses: string

Console.WriteLine($"Hi, I'm {name}, {age}, I learn {lang}");
Output
Hi, I'm Shiro, 18, I learn C#

C# is strict about types: a string variable can only hold text, an int only whole numbers. var doesn't remove the type — C# just figures it out from the value and then keeps it.

Interpolated strings start with $: $"Hi, {name}". Any expression can go inside the braces, even {age + 1}.

Line by line

string name = "Shiro";a text variable.
var lang = "C#";C# sees text and makes lang a string.
$"Hi, I'm {name}, ..."$ turns on {} substitution.

Common mistakes

  • Putting a number into a string variable: string s = 5; — error. Use "5" or 5.ToString().

Try it yourself

Create city = "Kyiv" and year = 2020, print: I live in Kyiv since 2020.

Show answer 
string city = "Kyiv";
int year = 2020;
Console.WriteLine($"I live in {city} since {year}");
Output
I live in Kyiv since 2020

Data types

// starts a comment. Text has a Length.

double price = 9.99;    // number with a dot
bool online = true;     // true or false
char letter = 'S';      // one character
string title = "VIBE";  // text

Main types: int, double, bool, char, string. Strings have useful properties and methods: Length, ToUpper(), Contains("x").

To turn text into a number use int.Parse("5"); to turn anything into text use .ToString().

Line by line

title.Lengthhow many characters (a property, no brackets).

Common mistakes

  • title.Length() with brackets — Length is a property, write it without ().

Try it yourself

Conditions

if runs code only when the condition in brackets is true.

int age = 18;

if (age >= 18)
{
    Console.WriteLine("Adult");
}
else if (age >= 13)
{
    Console.WriteLine("Teen");
}
else
{
    Console.WriteLine("Kid");
}
Output
Adult

In C# the braces usually go on their own line — that's just the common style, the code works either way. The condition must be a real bool: if (count) with a number is an error, write if (count > 0).

And / or / not: &&, ||, !.

Line by line

else if (age >= 13)the next check.

Common mistakes

  • if (age = 18) — in C# this doesn't compile, which saves you from a classic bug. Use ==.

Loops

for has three parts: start, condition, step. while repeats while the condition is true.

for (int i = 0; i < 3; i++)
{
    Console.WriteLine($"Step {i}");
}

int count = 3;
while (count > 0)
{
    Console.WriteLine(count);
    count--;
}
Output
Step 0
Step 1
Step 2
3
2
1

C# has for, while, do ... while and foreach. Use foreach (var x in list) to go through every item of a list or array — it is the most common loop in real code.

Line by line

for (int i = 0; i < 3; i++)counter 0, 1, 2.
$"Step {i}"insert i into the text.
count--;take 1 away.

Common mistakes

  • Changing a list inside foreach (adding or removing items) — C# throws an error.

Try it yourself

Print the numbers from 1 to 5.

Show answer 
for (int i = 1; i <= 5; i++)
{
    Console.WriteLine(i);
}
Output
1
2
3
4

Functions

In C# functions are called methods. You write the return type, the name and the parameters with types.

string Greet(string name)
{
    return $"Hello, {name}!";
}

Console.WriteLine(Greet("Shiro"));
Output
Hello, Shiro!

A method has a return type, a name and typed parameters. If it returns nothing, the type is void. In bigger programs methods live inside classes, and names usually start with a capital letter: Greet, Hit.

Short methods can be written with an arrow: int Square(int n) => n * n;.

Line by line

string Greet(string name)returns a string, takes a string.
return $"Hello, {name}!";give back the finished text.

Common mistakes

  • Returning the wrong type: a method declared int can't return text.

Try it yourself

Write int Square(int n) and print Square(7).

Show answer 
int Square(int n) => n * n;

Console.WriteLine(Square(7));
Output
49

Lists

List is a list that can grow. Add puts an item at the end, Count is how many there are, foreach goes through every item.

var langs = new List<string> { "Python", "C#", "Rust" };
langs.Add("C++");
Console.WriteLine(langs.Count);

foreach (var lang in langs)
{
    Console.WriteLine($"I like {lang}");
}
Output
4
I like Python
I like C#
I like Rust
I like C++

List<T> is a list that grows; T is the type of items, for example List<string>. It has Add, Remove, Contains, Count and works with foreach.

There are also arrays: int[] a = {1, 2, 3}; — they have a fixed size and use Length instead of Count.

Line by line

new List<string> { ... }create a list of texts with starting items.
langs.Add("C++");add to the end.
langs.Counthow many items.

Common mistakes

  • Count for lists, Length for arrays and strings — easy to mix up.

Try it yourself

Make a List<int> with 1, 2, 3, add 4 and print the sum with .Sum().

Show answer 
var nums = new List<int> { 1, 2, 3 };
nums.Add(4);
Console.WriteLine(nums.Sum());
Output
10

Mini project: a game hero

A class joins data and methods into one thing. Games made in Unity are written exactly like this.

var p = new Player("Shiro");
p.Hit(30);
p.Hit(25);

class Player
{
    public string Name;
    public int Hp = 100;

    public Player(string name)
    {
        Name = name;
    }

    public void Hit(int damage)
    {
        Hp -= damage;
        Console.WriteLine($"{Name} has {Hp} HP");
    }
}
Output
Shiro has 70 HP
Shiro has 45 HP

A class is a blueprint for objects. new Player("Shiro") creates an object and calls the constructor — the special method with the same name as the class that sets the starting values.

public means the field or method can be used from outside. In Unity, every script is a class like this, and its methods react to the game.

Line by line

var p = new Player("Shiro");create a player; the constructor sets Name.
public int Hp = 100;every player starts with 100 HP.
public void Hit(int damage)an action that changes HP.

Common mistakes

  • Using an object before new: Player p; p.Hit(5); — error, p is not created.

Try it yourself

Add a Heal(int amount) method and heal the player by 10 after the hits.

Show answer 
var p = new Player("Shiro");
p.Hit(30);
p.Hit(25);
p.Heal(10);

class Player
{
    public string Name;
    public int Hp = 100;

    public Player(string name)
    {
        Name = name;
    }

    public void Hit(int damage)
    {
        Hp -= damage;
        Console.WriteLine($"{Name} has {Hp} HP");
    }

    public void Heal(int amount)
    {
        Hp += amount;
        Console.WriteLine($"{Name} has {Hp} HP");
    }
}
Output
Shiro has 70 HP
Shiro has 45 HP
Shiro has 55 HP

Quiz

5 questions. Pick an answer to see if it is right.

1. What will this code print?

string name = "Shiro";
Console.WriteLine($"Hi, {name}!");

$ before the quotes puts the value of name into the text.

2. How do you add an item to a List?

var langs = new List<string>();

List uses Add. push is JavaScript, append is Python.

3. What will this code print?

int x = 10;
x--;
Console.WriteLine(x);

x-- takes 1 away: 10 becomes 9.

4. Which type stores true or false?

bool (boolean) is only true or false.

5. Which game engine mostly uses C#?

Unity games are written in C#. Unreal uses C++.
