01 / 06

Каркас страницы

Любая страница начинается так. В <head> настройки и название вкладки, в <body> то, что видно на экране. Теги идут парами: <tag> открывает, </tag> закрывает.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My first page</title>
</head>
<body>
  Hello, world!
</body>
</html>
Вывод
Вкладка «My first page» и текст: Hello, world!

HTML — не язык программирования, он описывает, что есть на странице. Он состоит из тегов: слов в угловых скобках. Большинство тегов идут парами и обнимают содержимое: <title>Моя страница</title>.

<!DOCTYPE html> говорит браузеру «это современный HTML». <meta charset="UTF-8"> нужен, чтобы любые буквы, включая русские, отображались правильно.

Разбор кода

<html lang="en">корень страницы; lang говорит, на каком языке текст.
<head>настройки: заголовок вкладки, кодировка, стили. На странице не видно.
<title>текст на вкладке браузера.
<body>всё, что видит посетитель.

Частые ошибки

  • Забыть закрыть тег: <body> без </body>. Браузер часто прощает, но страница может сломаться странным образом.

Попробуй сам

Сделай страницу с названием вкладки "Shiro" и текстом "My first site".

Показать ответ 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Shiro</title>
</head>
<body>
  My first site
</body>
</html>

Заголовки и текст

<h1> — самый большой заголовок, <h6> — самый маленький. <p> — абзац.

<h1>Big heading</h1>
<h2>Smaller heading</h2>
<p>A paragraph of text with <b>bold</b> and <i>italic</i> words.</p>

Заголовки помогают быстро понять страницу. <h1> используй один раз — для главного заголовка, <h2> — для разделов, <h3> — для частей поменьше. На этот порядок опираются поисковики и программы для незрячих.

<b> делает текст жирным, <i> — курсивом. Для важных слов есть ещё <strong> и <em>.

Разбор кода

<h1>Big heading</h1>главный заголовок страницы.
<p>...</p>абзац: блок текста с отступами.
<b>bold</b>тег внутри тега: жирное только это слово.

Частые ошибки

  • Выбирать заголовки по размеру («h4 смотрится лучше»). Выбирай по смыслу, а размер меняй через CSS.

Попробуй сам

Сделай заголовок "About me" и абзац с одним жирным словом.

Показать ответ 
<h2>About me</h2>
<p>I am learning <b>HTML</b> right now.</p>
03 / 06

Ссылки и картинки

href — куда ведёт ссылка. src — файл картинки. alt описывает картинку для тех, кто её не видит.

<a href="https://shiro-dev1.github.io">My portfolio</a>
<a href="page2.html">Go to page 2</a>

<img src="cat.jpg" alt="A sleeping cat" width="300">

Ссылки связывают страницы: <a href="...">. Адрес — это другой сайт (https://...) или файл рядом с твоим (page2.html). Добавь target="_blank", чтобы ссылка открылась в новой вкладке.

У <img> нет закрывающего тега. src — файл, alt — описание. Задавай только ширину или только высоту, иначе картинка может растянуться.

Разбор кода

<a href="https://...">My portfolio</a>посетитель видит «My portfolio»; по клику открывается адрес.
<img src="cat.jpg" ...>показать файл cat.jpg из той же папки.
alt="A sleeping cat"текст для программ чтения с экрана и на случай, если картинка не загрузилась.

Частые ошибки

  • Неверное имя файла или папки в src — вместо картинки значок «сломано». На серверах регистр важен: Cat.jpg ≠ cat.jpg.

Попробуй сам

Сделай ссылку на github.com, которая открывается в новой вкладке.

Показать ответ 
<a href="https://github.com" target="_blank">My GitHub</a>
04 / 06

Списки

<ul> — список с точками, <ol> — с номерами. Каждый пункт — <li>.

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<ol>
  <li>Learn HTML</li>
  <li>Learn CSS</li>
  <li>Build a site</li>
</ol>
Вывод
• HTML
• CSS

1. Learn HTML
2. Learn CSS
3. Build a site

Списки повсюду: меню, шаги рецепта, возможности товара. Список — это родительский тег (ul или ol) и пункты li внутри.

Списки можно вкладывать: новый ul внутри li даёт подсписок. Большинство меню на сайтах — это на самом деле списки, оформленные через CSS.

Разбор кода

<ul>неупорядоченный список: точки.
<ol>упорядоченный список: номера ставятся сами.
<li>...</li>один пункт списка.

Частые ошибки

  • Писать текст прямо в ul без li — каждый пункт должен быть внутри <li>.

Попробуй сам

Сделай нумерованный список из 3 вещей, которые хочешь выучить.

Показать ответ 
<ol>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ol>
05 / 06

Кнопки и формы

Форма собирает то, что вводит пользователь. <label> — подпись, for связывает её с полем, у которого такой же id.

<form>
  <label for="name">Your name</label>
  <input id="name" type="text" placeholder="Shiro">

  <label for="email">Email</label>
  <input id="email" type="email">

  <button type="submit">Send</button>
</form>

Формы — это способ получить информацию от людей: регистрация, поиск, комментарии. <input> — поле; его type меняет поведение: text, email, password, number, checkbox.

<label>, связанный через for, делает подпись кликабельной и помогает программам для незрячих. placeholder — серая подсказка, которая исчезает, когда начинаешь печатать.

Разбор кода

<label for="name">подпись для поля с id="name".
<input id="name" type="text">однострочное текстовое поле.
type="email"браузер проверит, похоже ли это на почту.
<button type="submit">кнопка, которая отправляет форму.

Частые ошибки

  • Разные значения в for и id — тогда клик по подписи ничего не делает.

Попробуй сам

Добавь в форму поле для пароля с подписью.

Показать ответ 
<label for="pass">Password</label>
<input id="pass" type="password">

Разметка страницы

Эти теги называют части страницы: верх, основное содержимое, низ. Ссылка на #about прыгает к элементу с id="about".

<header>
  <nav><a href="#about">About</a></nav>
</header>

<main>
  <section id="about">
    <h2>About me</h2>
    <p>I build websites.</p>
  </section>
</main>

<footer>(c) 2026</footer>

Семантические теги называют части страницы: header (верх), nav (меню), main (основное содержимое, один на страницу), section (раздел со своим заголовком), footer (низ).

Выглядят они так же, как обычный div, но сообщают браузерам, поисковикам и программам для незрячих, что это за часть. Так сайтом удобнее пользоваться и его проще найти.

Разбор кода

<header>верх страницы, обычно логотип и меню.
<nav>блок навигационных ссылок.
<section id="about">раздел; id позволяет ссылке прыгнуть к нему.
<footer>низ: контакты, копирайт.

Частые ошибки

  • Два элемента с одинаковым id. id должен быть уникальным на странице.

Попробуй сам

Добавь второй раздел "Contacts" и ссылку на него в nav.

Показать ответ 
<nav>
  <a href="#about">About</a>
  <a href="#contacts">Contacts</a>
</nav>

<section id="contacts">
  <h2>Contacts</h2>
  <p>github.com/Shiro-dev1</p>
</section>

Тест

5 вопросов. Выбери ответ — сразу увидишь, верно ли.

1. Какой тег — самый большой заголовок?

<h1> — самый большой, <h6> — самый маленький.

2. Где пишется то, что видно на странице?

В <head> — настройки, в <body> — то, что видно.

3. Какой атрибут говорит, куда ведёт ссылка?

<a ___="page2.html">Next</a>

У ссылок href, у картинок src.

4. Какой тег делает нумерованный список?

<ol> — нумерованный список, <ul> — с точками.

5. Зачем нужен атрибут alt?

<img src="cat.jpg" alt="A sleeping cat">

alt описывает картинку для тех, кто её не видит, и на случай, если она не загрузилась.
