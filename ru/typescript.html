Уроки TypeScript

TypeScript — это JavaScript с типами. Ты указываешь тип каждого значения, и компилятор находит ошибки ещё до запуска. Его используют большие сайты и приложения, потому что он защищает большой код от ошибок.

Привет, мир

Код на TypeScript компилятор tsc превращает в обычный JavaScript, и уже он работает в браузере или Node.js. Hello, world выглядит так же, как в JavaScript.

console.log("Hello, world!");
Вывод
Hello, world!

Любая программа на JavaScript — это и программа на TypeScript. TypeScript только добавляет сверху: типы, интерфейсы и проверки. Файлы заканчиваются на .ts.

Браузер не понимает TypeScript напрямую. Запускаешь tsc file.ts, он проверяет типы и пишет file.js, который ты уже запускаешь. Попробовать в браузере можно на typescriptlang.org/play.

Разбор кода

console.log(...)вывод в консоль, как в JavaScript.

Частые ошибки

  • Пытаться открыть .ts-файл прямо в браузере — сначала его нужно скомпилировать в .js.

Попробуй сам

Выведи своё имя, а на следующей строке 2026.

Показать ответ 
console.log("Shiro");
console.log(2026);
Вывод
Shiro
2026

Переменные с типами

После имени переменной пишут двоеточие и тип: let age: number. Тогда TypeScript не даст случайно положить туда текст.

let userName: string = "Shiro";
let age: number = 18;
age = age + 1;
console.log(`${userName} is ${age}`);
Вывод
Shiro is 19

Три основных типа: string (текст), number (любое число) и boolean (true/false). Пишутся маленькими буквами.

Тип не всегда нужно писать: let age = 18 для TypeScript уже число. Это называется выводом типов. Пиши типы там, где они помогают читать код, например в параметрах функций.

Разбор кода

let userName: string = "Shiro";переменная, в которой может быть только текст.
let age: number = 18;можно только числа.
`${userName} is ${age}`шаблонная строка, как в JavaScript.

Частые ошибки

  • age = "nineteen" — ошибка: Type 'string' is not assignable to type 'number'. Это TypeScript тебя защищает.
  • Назвать переменную верхнего уровня name: в браузере уже есть глобальная name, и TypeScript скажет Cannot redeclare block-scoped variable. Возьми другое имя, например userName.

Попробуй сам

Создай city: string и year: number и выведи: I live in Kyiv since 2020.

Показать ответ 
const city: string = "Kyiv";
const year: number = 2020;
console.log(`I live in ${city} since ${year}`);
Вывод
I live in Kyiv since 2020

Типы данных

Типы можно комбинировать. number | string значит «число или строка» — это объединение типов. string[] — массив строк.

let id: number | string = 42;   // union: number OR string
id = "A-42";
let tags: string[] = ["web", "ts"];
let done: boolean = false;
console.log(id, tags.length, done);
Вывод
A-42 2 false

Объединение типов полезно, когда значение действительно может быть разным, например id, который иногда число, а иногда текст.

Есть ещё any — «что угодно». Он отключает проверку типов, поэтому используй его, только если очень нужно. Безопаснее для неизвестных данных unknown: перед использованием придётся проверить тип.

Разбор кода

let id: number | string = 42;id может быть числом или текстом.
let tags: string[] = [...]массив, где каждый элемент — текст.
tags.lengthколичество элементов: 2.

Частые ошибки

  • tags.push(5) — ошибка: число нельзя положить в string[].

Попробуй сам

Сделай массив scores: number[] из 3 чисел и выведи, сколько их.

Показать ответ 
const scores: number[] = [5, 8, 10];
console.log(scores.length);
Вывод
3

Условия

Условия работают как в JavaScript. Бонус: после typeof x === "number" TypeScript знает, что внутри этого блока x — число.

function describe(x: number | string): string {
  if (typeof x === "number") {
    return "number " + x.toFixed(1);
  } else {
    return "text " + x.toUpperCase();
  }
}

console.log(describe(3));
console.log(describe("hi"));
Вывод
number 3.0
text HI

Этот приём называется сужением типа. До if переменная x могла быть числом или строкой, и методы числа на ней вызвать нельзя. Внутри if TypeScript сузил её до числа, а в else это точно строка.

Для сравнения используй === и !==, как в JavaScript.

Разбор кода

typeof x === "number"проверка типа во время работы программы.
x.toFixed(1)метод числа: 1 знак после точки.
x.toUpperCase()метод строки: заглавные буквы.

Частые ошибки

  • Вызвать x.toUpperCase() до проверки типа — ошибка, ведь x может быть числом.

Попробуй сам

const t: number = 30. Выведи "Hot", если t > 25, иначе "OK".

Показать ответ 
const t: number = 30;
if (t > 25) {
  console.log("Hot");
} else {
  console.log("OK");
}
Вывод
Hot

Циклы

for ... of проходит по каждому элементу массива. Классический for со счётчиком тоже работает.

const langs: string[] = ["TS", "JS", "Go"];
for (const lang of langs) {
  console.log(lang);
}

for (let i = 0; i < 3; i++) {
  console.log("Step", i);
}
Вывод
TS
JS
Go
Step 0
Step 1
Step 2

Внутри for (const lang of langs) TypeScript знает, что lang — строка, ведь langs это string[]. Подсказки и проверки получаешь бесплатно.

Не путай for ... of (значения) и for ... in (ключи/индексы) — для массивов почти всегда нужен of.

Разбор кода

for (const lang of langs)lang по очереди — каждый элемент.
for (let i = 0; i < 3; i++)счётчик от 0 до 2.

Частые ошибки

  • Использовать for (const x in arr) и получить "0", "1", "2" вместо значений.

Попробуй сам

Выведи числа от 1 до 5.

Показать ответ 
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
Вывод
1
2
3
4
5

Функции

В TypeScript указывают типы параметров и результата. Тогда никто не сможет вызвать функцию с неправильными значениями.

function add(a: number, b: number): number {
  return a + b;
}

const greet = (name: string): string => `Hello, ${name}!`;

console.log(add(2, 3));
console.log(greet("Shiro"));
Вывод
5
Hello, Shiro!

Тип после скобок ): number — это тип результата. Если функция ничего не возвращает, пиши : void.

Параметр можно сделать необязательным через ?: function hi(name?: string), или дать ему значение по умолчанию: function hi(name = "friend").

Разбор кода

function add(a: number, b: number): numberна входе два числа, на выходе число.
(name: string): string => ...стрелочная функция с типами.

Частые ошибки

  • add("2", 3) — ошибка: строка не число. В обычном JavaScript это молча дало бы "23".

Попробуй сам

Напиши square(n: number): number и выведи square(7).

Показать ответ 
function square(n: number): number {
  return n * n;
}
console.log(square(7));
Вывод
49

Интерфейсы

interface описывает форму объекта: какие у него поля и какого они типа. ? отмечает поле, которого может не быть.

interface User {
  name: string;
  age: number;
  email?: string;   // ? = optional
}

const user: User = { name: "Shiro", age: 18 };
console.log(user.name, user.age);
console.log(user.email ?? "no email");
Вывод
Shiro 18
no email

Объекты повсюду в веб-приложениях: пользователи, товары, сообщения. Интерфейс — это договор: у каждого User должны быть name и age. Если забудешь поле или опечатаешься, TypeScript сразу скажет.

?? значит «если слева ничего нет (null или undefined), возьми то, что справа».

Разбор кода

interface User { ... }описываем, как выглядит пользователь.
email?: string;email может отсутствовать.
user.email ?? "no email"взять текст, если email нет.

Частые ошибки

  • { name: "Shiro" } без age — ошибка: Property 'age' is missing.

Попробуй сам

Сделай интерфейс Product с title: string и price: number, создай товар и выведи его title.

Показать ответ 
interface Product {
  title: string;
  price: number;
}
const p: Product = { title: "Book", price: 12 };
console.log(p.title);
Вывод
Book

Мини-проект: список дел

Всё вместе: интерфейс для задачи, типизированный массив, функция, которая добавляет задачи, и цикл, который их выводит.

interface Task {
  title: string;
  done: boolean;
}

const tasks: Task[] = [];

function addTask(title: string): void {
  tasks.push({ title, done: false });
}

addTask("Learn TypeScript");
addTask("Build a site");
tasks[0].done = true;

for (const t of tasks) {
  console.log((t.done ? "[x] " : "[ ] ") + t.title);
}
Вывод
[x] Learn TypeScript
[ ] Build a site

Это сердце любого приложения со списком дел. Task[] — «массив задач». { title, done: false } — короткая запись { title: title, done: false }.

условие ? a : b — короткий if: если done, берём "[x] ", иначе "[ ] ". В настоящем приложении тот же код рисовал бы список на странице.

Разбор кода

const tasks: Task[] = [];пустой массив, в котором будут только задачи.
function addTask(title: string): voidдобавляет задачу, ничего не возвращает.
t.done ? "[x] " : "[ ] "выбрать отметку по done.

Частые ошибки

  • tasks.push({ title }) без done — ошибка: Property 'done' is missing.

Попробуй сам

Добавь функцию countDone(): number, которая возвращает, сколько задач выполнено, и выведи результат.

Показать ответ 
interface Task {
  title: string;
  done: boolean;
}

const tasks: Task[] = [
  { title: "Learn TypeScript", done: true },
  { title: "Build a site", done: false },
];

function countDone(): number {
  return tasks.filter((t) => t.done).length;
}

console.log(countDone());
Вывод
1

Тест

5 вопросов. Выбери ответ — сразу увидишь, верно ли.

1. Что выведет этот код?

let a: number = 5;
a = a * 2;
console.log(a);

a было 5, потом умножили на 2.

2. Что тут случится?

let age: number = 18;
age = "18";

В числовую переменную нельзя положить текст — компилятор остановит.

3. Что значит number | string?

| — объединение: значение одного из этих типов.

4. Какой знак делает поле интерфейса необязательным?

interface User {
  email___: string;
}

email?: string значит, что поля может не быть.

5. Что выведет этот код?

const nums: number[] = [1, 2, 3];
nums.push(4);
console.log(nums.length);

push добавил ещё один элемент.
