Переменные

Переменная — это коробка с названием, в которой лежит значение. Если поставить f перед кавычками, переменные можно вставлять в текст через { }.

name = "Shiro"
age = 18

print(name, age)
print(f"Hi, I'm {name} and I'm {age}")
Вывод
Shiro 18
Hi, I'm Shiro and I'm 18

Типы данных

У каждого значения есть тип. # начинает комментарий: всё после него Python пропускает. type() показывает тип.

count = 10          # int: целое число
price = 9.99        # float: дробное число
title = "VIBE.EXE"  # str: текст
online = True       # bool: True или False

print(type(price))
Вывод
<class 'float'>

Условия

if выполняет код, только если условие верно. elif значит «иначе если». Отступы в начале строки в Python важны: они показывают, какой код относится к if.

age = 18

if age >= 18:
    print("Adult")
elif age >= 13:
    print("Teen")
else:
    print("Kid")
Вывод
Adult
05 / 08

Циклы

for повторяет код заданное число раз. while повторяет, пока условие верно. range(3) даёт 0, 1, 2.

for i in range(3):
    print("Step", i)

count = 3
while count > 0:
    print(count)
    count -= 1
Вывод
Step 0
Step 1
Step 2
3
2
1

Функции

Функция — это кусок кода с названием, который можно запускать много раз. def создаёт её, return возвращает результат.

def greet(name):
    return "Hello, " + name + "!"

print(greet("Shiro"))
print(greet("world"))
Вывод
Hello, Shiro!
Hello, world!

Списки

Список хранит много значений по порядку. Счёт идёт с 0, поэтому langs[0] — первый элемент. len() даёт длину.

langs = ["Python", "JavaScript", "C"]
langs.append("Rust")

print(langs[0])
print(len(langs))

for lang in langs:
    print("I like", lang)
Вывод
Python
4
I like Python
I like JavaScript
I like C
I like Rust

Мини-проект: угадай число

Всё вместе: случайное число, цикл, условия и input(), который читает то, что вводит игрок. Ниже — пример одной игры.

import random

secret = random.randint(1, 10)
guess = 0

while guess != secret:
    guess = int(input("Guess a number from 1 to 10: "))
    if guess < secret:
        print("Bigger!")
    elif guess > secret:
        print("Smaller!")

print("You got it!")
Вывод
Guess a number from 1 to 10: 5
Bigger!
Guess a number from 1 to 10: 8
Smaller!
Guess a number from 1 to 10: 7
You got it!
