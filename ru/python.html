Привет, мир

print() выводит текст на экран. Текст в кавычках называется строкой.

print("Hello, world!")
Вывод
Hello, world!

Программа — это список команд, которые компьютер выполняет сверху вниз. Самая первая команда, которую учат все, — «покажи текст». В Python это print().

Всё, что внутри скобок, появится на экране. Текст пишут в кавычках, одинарных '...' или двойных "..." — работают обе. Числа кавычки не нужны.

Разбор кода

printназвание команды: print — «напечатай», «покажи».
( ... )в скобках то, что мы передаём команде.
"Hello, world!"сам текст. Кавычки на экран не выводятся.

Частые ошибки

  • Забыть кавычки: print(Hello) — Python решит, что Hello это переменная, и выдаст ошибку.
  • Написать Print с большой буквы. Python различает большие и маленькие буквы.

Попробуй сам

Выведи две строки: своё имя, а потом число 2026.

Показать ответ 
print("Shiro")
print(2026)
Вывод
Shiro
2026

Переменные

Переменная — это коробка с названием, в которой лежит значение. Если поставить f перед кавычками, переменные можно вставлять в текст через { }.

name = "Shiro"
age = 18

print(name, age)
print(f"Hi, I'm {name} and I'm {age}")
Вывод
Shiro 18
Hi, I'm Shiro and I'm 18

Переменная — это имя для значения. Вместо того чтобы писать одно и то же значение много раз, ты сохраняешь его один раз и пользуешься именем. Если значение поменяется, менять придётся в одном месте.

Знак = значит «положи значение справа в имя слева». Это не «равно» из математики. f-строка (f"...") позволяет вставлять переменные прямо в текст.

Разбор кода

name = "Shiro"создаём переменную name и кладём в неё текст Shiro.
age = 18переменная с числом. Без кавычек — это число, а не текст.
print(name, age)print умеет выводить несколько значений и ставит между ними пробел.
f"... {name} ..."внутри f-строки {name} заменяется значением переменной.

Частые ошибки

  • Использовать переменную до того, как её создали, — Python скажет NameError.
  • Забыть f перед кавычками: тогда {name} так и выведется буквами.

Попробуй сам

Создай переменные city и year и выведи: I live in city since year.

Показать ответ 
city = "Kyiv"
year = 2020
print(f"I live in {city} since {year}")
Вывод
I live in Kyiv since 2020

Типы данных

У каждого значения есть тип. # начинает комментарий: всё после него Python пропускает. type() показывает тип.

count = 10          # int: целое число
price = 9.99        # float: дробное число
title = "VIBE.EXE"  # str: текст
online = True       # bool: True или False

print(type(price))
Вывод
<class 'float'>

Тип говорит Python, что это за значение и что с ним можно делать. Числа можно складывать, текст — склеивать, True/False используют в условиях.

Тип можно менять: int("5") превращает текст в число, str(5) — число в текст. Это нужно часто: например, когда пользователь вводит число, Python получает его как текст.

Разбор кода

count = 10int — целое число.
price = 9.99float — дробное число. В коде всегда точка, а не запятая.
online = Truebool — только True или False, всегда с большой буквы.
type(price)спрашивает у Python: какого типа это значение?

Частые ошибки

  • "5" + 5 — текст и число складывать нельзя. Сначала преобразуй: int("5") + 5.
  • Писать true с маленькой буквы — в Python нужно True.

Попробуй сам

Есть a = "7" (текст). Выведи a + 3 так, чтобы получилось 10.

Показать ответ 
a = "7"
print(int(a) + 3)
Вывод
10

Условия

if выполняет код, только если условие верно. elif значит «иначе если». Отступы в начале строки в Python важны: они показывают, какой код относится к if.

age = 18

if age >= 18:
    print("Adult")
elif age >= 13:
    print("Teen")
else:
    print("Kid")
Вывод
Adult

Условия позволяют программе принимать решения: сделать одно, если что-то верно, и другое, если нет. Компьютер проверяет условия сверху вниз и выполняет только первый подходящий блок.

Сравнения: == равно, != не равно, > < >= <=. Их можно соединять: and (оба верны) и or (хотя бы одно верно).

Разбор кода

if age >= 18:если age 18 или больше… Двоеточие в конце обязательно.
print("Adult")4 пробела в начале: эта строка относится к if.
elif age >= 13:проверяется, только если первое условие не сработало.
else:срабатывает, если ничего выше не подошло.

Частые ошибки

  • Писать = вместо == в сравнении: if age = 18 — ошибка.
  • Забыть двоеточие или отступ — Python покажет SyntaxError или IndentationError.

Попробуй сам

Переменная t = 30. Выведи "Hot", если t больше 25, иначе "OK".

Показать ответ 
t = 30
if t > 25:
    print("Hot")

    print("OK")

Циклы

for повторяет код заданное число раз. while повторяет, пока условие верно. range(3) даёт 0, 1, 2.

for i in range(3):
    print("Step", i)

count = 3
while count > 0:
    print(count)
    count -= 1
Вывод
Step 0
Step 1
Step 2
3
2
1

Цикл повторяет код, чтобы его не копировать. for используют, когда известно, сколько раз повторить, или нужно пройти по каждому элементу. while повторяет, пока условие верно.

range(3) даёт числа 0, 1, 2 — начинает с 0 и останавливается перед 3. range(1, 4) даёт 1, 2, 3.

Разбор кода

for i in range(3):i по очереди становится 0, 1, 2.
while count > 0:повторять, пока count больше 0.
count -= 1то же, что count = count - 1. Без этого цикл никогда не закончится.

Частые ошибки

  • Бесконечный цикл while: условие никогда не становится ложным. Всегда меняй переменную внутри цикла.
  • Думать, что range(5) включает 5. Он заканчивается на 4.

Попробуй сам

Показать ответ 
for i in range(1, 6):
    print(i)
Вывод

Функции

Функция — это кусок кода с названием, который можно запускать много раз. def создаёт её, return возвращает результат.

def greet(name):
    return "Hello, " + name + "!"

print(greet("Shiro"))
print(greet("world"))
Вывод
Hello, Shiro!
Hello, world!

Функция — это маленькая машинка: ты даёшь ей значения (параметры), она делает работу и возвращает результат (return). Пишешь её один раз и используешь сколько угодно.

Функции делают код короче и понятнее: вместо 10 строк в пяти местах — одно название. Код внутри функции выполняется только тогда, когда её вызывают: greet("Shiro").

Разбор кода

def greet(name):def создаёт функцию greet с одним параметром name.
return "Hello, " + name + "!"+ склеивает текст; return возвращает результат.
print(greet("Shiro"))вызываем функцию со значением "Shiro" и выводим то, что она вернула.

Частые ошибки

  • Забыть return: тогда функция вернёт None.
  • Вызывать функцию выше, чем она написана. Сначала def, потом вызов.

Попробуй сам

Показать ответ 
def square(n):
    return n * n

Вывод

Списки

Список хранит много значений по порядку. Счёт идёт с 0, поэтому langs[0] — первый элемент. len() даёт длину.

langs = ["Python", "JavaScript", "C"]
langs.append("Rust")

print(langs[0])
print(len(langs))

for lang in langs:
    print("I like", lang)
Вывод
Python
4
I like Python
I like JavaScript
I like C
I like Rust

Список хранит много значений в одной переменной по порядку. Это как полка с номерами: можно взять элемент по номеру, добавить новый, удалить и пройти по всем циклом.

Полезные команды: append(x) добавляет в конец, remove(x) удаляет элемент, len(список) считает элементы, список[-1] — последний элемент.

Разбор кода

langs = ["Python", "JavaScript", "C"]список в квадратных скобках, элементы через запятую.
langs.append("Rust")добавляем Rust в конец. Теперь элементов 4.
langs[0]первый элемент. Счёт идёт с 0.
for lang in langs:lang по очереди становится каждым элементом.

Частые ошибки

  • langs[4], когда элементов 4, — последний это langs[3]. Ошибка: IndexError.

Мини-проект: угадай число

Всё вместе: случайное число, цикл, условия и input(), который читает то, что вводит игрок. Ниже — пример одной игры.

import random

secret = random.randint(1, 10)
guess = 0

while guess != secret:
    guess = int(input("Guess a number from 1 to 10: "))
    if guess < secret:
        print("Bigger!")
    elif guess > secret:
        print("Smaller!")

print("You got it!")
Вывод
Guess a number from 1 to 10: 5
Bigger!
Guess a number from 1 to 10: 8
Smaller!
Guess a number from 1 to 10: 7
You got it!

Мини-проект соединяет всё, что ты выучил. Читай его сверху вниз: сначала готовим данные (секретное число), потом цикл снова и снова спрашивает игрока, условия дают подсказки, а когда число угадано, цикл заканчивается.

import random подключает готовый модуль со случайными числами. input() ждёт, пока игрок что-то напишет и нажмёт Enter; int() превращает этот текст в число.

Разбор кода

secret = random.randint(1, 10)случайное целое число от 1 до 10.
while guess != secret:повторяем, пока не угадали.
int(input("..."))показать вопрос, прочитать ответ, превратить в число.

Частые ошибки

  • Забыть int(): тогда ответ — текст и никогда не будет равен числу.

Попробуй сам

Добавь счётчик: после игры выведи, за сколько попыток игрок угадал.

Показать ответ 
import random

secret = random.randint(1, 10)
guess = 0
tries = 0

while guess != secret:
    guess = int(input("Guess a number from 1 to 10: "))
    tries += 1
    if guess < secret:
        print("Bigger!")
    elif guess > secret:
        print("Smaller!")

print("You got it in", tries, "tries!")
