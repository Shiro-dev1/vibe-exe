Привет, мир

В современном C# (.NET 6 и новее) эта одна строка — целая программа. В старом коде ты увидишь её внутри class Program и static void Main().

Console.WriteLine("Hello, world!");
Вывод
Hello, world!

Программы на C# работают на .NET — бесплатной платформе от Microsoft. Современный C# разрешает писать программу просто строками в начале файла («операторы верхнего уровня») — поэтому хватает одной строки.

Console — текстовое окно, WriteLine пишет строку и переходит на следующую. Write (без Line) остаётся на той же строке.

Разбор кода

Consoleокно консоли.
.WriteLine("Hello, world!");написать текст и перенос строки.

Частые ошибки

  • console.writeline маленькими буквами — C# различает регистр: Console.WriteLine.

Попробуй сам

Выведи своё имя, а на следующей строке 2026.

Показать ответ 
Console.WriteLine("Shiro");
Console.WriteLine(2026);
Вывод
Shiro
2026

Переменные

У каждой переменной есть тип. var позволяет C# угадать его самому. Поставь $ перед кавычками, и переменные можно вставлять через { }.

string name = "Shiro";
int age = 18;
var lang = "C#";   // C# угадает: string

Console.WriteLine($"Hi, I'm {name}, {age}, I learn {lang}");
Вывод
Hi, I'm Shiro, 18, I learn C#

C# строг к типам: переменная string хранит только текст, int — только целые числа. var не отменяет тип: C# просто понимает его по значению и дальше держится за него.

Строки с подстановкой начинаются с $: $"Hi, {name}". В скобки можно писать любое выражение, даже {age + 1}.

Разбор кода

string name = "Shiro";текстовая переменная.
var lang = "C#";C# видит текст и делает lang строкой.
$"Hi, I'm {name}, ..."$ включает подстановку через {}.

Частые ошибки

  • Класть число в строковую переменную: string s = 5; — ошибка. Используй "5" или 5.ToString().

Попробуй сам

Создай city = "Kyiv" и year = 2020, выведи: I live in Kyiv since 2020.

Показать ответ 
string city = "Kyiv";
int year = 2020;
Console.WriteLine($"I live in {city} since {year}");
Вывод
I live in Kyiv since 2020

Чтобы превратить текст в число, используй int.Parse("5"); чтобы что угодно превратить в текст — .ToString().

Условия

if выполняет код, только если условие в скобках верно.

int age = 18;

if (age >= 18)
{
    Console.WriteLine("Adult");
}
else if (age >= 13)
{
    Console.WriteLine("Teen");
}
else
{
    Console.WriteLine("Kid");
}
Вывод
Adult

В C# фигурные скобки обычно ставят на отдельной строке — это просто привычный стиль, код работает в любом случае. Условие должно быть настоящим bool: if (count) с числом — ошибка, пиши if (count > 0).

И / или / не: &&, ||, !.

Разбор кода

if (age >= 18)условие.
else if (age >= 13)следующая проверка.
elseвсё остальное.

Частые ошибки

  • if (age = 18) — в C# это не скомпилируется, и это спасает от классической ошибки. Используй ==.

Попробуй сам

int t = 30. Выведи "Hot", если t > 25, иначе "OK".

Показать ответ 
int t = 30;
if (t > 25)
{
    Console.WriteLine("Hot");
}
else
{
    Console.WriteLine("OK");
}
Вывод
Hot

Циклы

У for три части: начало, условие, шаг. while повторяет, пока условие верно.

for (int i = 0; i < 3; i++)
{
    Console.WriteLine($"Step {i}");
}

int count = 3;
while (count > 0)
{
    Console.WriteLine(count);
    count--;
}
Вывод
Step 0
Step 1
Step 2
3
2
1

В C# есть for, while, do ... while и foreach. foreach (var x in list) проходит по каждому элементу списка или массива — это самый частый цикл в реальном коде.

Разбор кода

for (int i = 0; i < 3; i++)счётчик 0, 1, 2.
$"Step {i}"вставить i в текст.
count--;отнять 1.

Частые ошибки

  • Менять список внутри foreach (добавлять или удалять) — C# выдаст ошибку.

Попробуй сам

Выведи числа от 1 до 5.

Показать ответ 
for (int i = 1; i <= 5; i++)
{
    Console.WriteLine(i);
}
Вывод
1
2
3
4
5

Функции

В C# функции называются методами. Пишешь тип результата, название и параметры с типами.

string Greet(string name)
{
    return $"Hello, {name}!";
}

Console.WriteLine(Greet("Shiro"));
Вывод
Hello, Shiro!

У метода есть тип результата, имя и параметры с типами. Если он ничего не возвращает, тип — void. В больших программах методы живут внутри классов, а их имена обычно начинаются с большой буквы: Greet, Hit.

Короткие методы можно писать через стрелку: int Square(int n) => n * n;.

Разбор кода

string Greet(string name)возвращает string, принимает string.
return $"Hello, {name}!";вернуть готовый текст.

Частые ошибки

  • Вернуть не тот тип: метод, объявленный как int, не может вернуть текст.

Попробуй сам

Напиши int Square(int n) и выведи Square(7).

Показать ответ 
int Square(int n) => n * n;

Console.WriteLine(Square(7));
Вывод

Списки

List — список, который может расти. Add добавляет элемент в конец, Count — сколько их, foreach проходит по каждому.

var langs = new List<string> { "Python", "C#", "Rust" };
langs.Add("C++");
Console.WriteLine(langs.Count);

foreach (var lang in langs)
{
    Console.WriteLine($"I like {lang}");
}
Вывод
4
I like Python
I like C#
I like Rust
I like C++

List<T> — список, который растёт; T — тип элементов, например List<string>. У него есть Add, Remove, Contains, Count, и он работает с foreach.

Есть и массивы: int[] a = {1, 2, 3}; — у них фиксированный размер, и вместо Count у них Length.

Разбор кода

new List<string> { ... }создать список текстов с начальными элементами.
langs.Add("C++");добавить в конец.
langs.Countсколько элементов.

Частые ошибки

  • Count у списков, Length у массивов и строк — их легко перепутать.

Попробуй сам

Создай List<int> с 1, 2, 3, добавь 4 и выведи сумму через .Sum().

Показать ответ 
var nums = new List<int> { 1, 2, 3 };
nums.Add(4);
Console.WriteLine(nums.Sum());
Вывод
10

Мини-проект: герой игры

Класс объединяет данные и методы в одно целое. Игры в Unity пишутся именно так.

var p = new Player("Shiro");
p.Hit(30);
p.Hit(25);

class Player
{
    public string Name;
    public int Hp = 100;

    public Player(string name)
    {
        Name = name;
    }

    public void Hit(int damage)
    {
        Hp -= damage;
        Console.WriteLine($"{Name} has {Hp} HP");
    }
}
Вывод
Shiro has 70 HP
Shiro has 45 HP

Класс — это чертёж для объектов. new Player("Shiro") создаёт объект и вызывает конструктор — особый метод с тем же именем, что и класс, который задаёт начальные значения.

public значит, что поле или метод доступны снаружи. В Unity каждый скрипт — это такой класс, а его методы реагируют на игру.

Разбор кода

var p = new Player("Shiro");создаём игрока; конструктор задаёт Name.
public int Hp = 100;каждый игрок начинает со 100 HP.
public void Hit(int damage)действие, которое меняет HP.

Частые ошибки

  • Использовать объект до new: Player p; p.Hit(5); — ошибка, p не создан.

Попробуй сам

Добавь метод Heal(int amount) и вылечи игрока на 10 после ударов.

Показать ответ 
var p = new Player("Shiro");
p.Hit(30);
p.Hit(25);
p.Heal(10);

class Player
{
    public string Name;
    public int Hp = 100;

    public Player(string name)
    {
        Name = name;
    }

    public void Hit(int damage)
    {
        Hp -= damage;
        Console.WriteLine($"{Name} has {Hp} HP");
    }

    public void Heal(int amount)
    {
        Hp += amount;
        Console.WriteLine($"{Name} has {Hp} HP");
    }
}
Вывод
Shiro has 70 HP
Shiro has 45 HP
Shiro has 55 HP

У List метод Add. push — это JavaScript, append — Python.

int x = 10;
x--;
Console.WriteLine(x);

x-- отнимает 1: было 10, стало 9.

4. Какой тип хранит true или false?

bool — это только true или false.
