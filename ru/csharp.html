У каждой переменной есть тип. var позволяет C# угадать его самому. Поставь $ перед кавычками, и переменные можно вставлять через { }.

У for три части: начало, условие, шаг. while повторяет, пока условие верно.

{

07_СПИСКИ07/08

List — список, который может расти. Add добавляет элемент в конец, Count — сколько их, foreach проходит по каждому.

var langs = new List<string> { "Python", "C#", "Rust" };
langs.Add("C++");
Console.WriteLine(langs.Count);

foreach (var lang in langs)
{
    Console.WriteLine($"I like {lang}");
}

08_МИНИ-ПРОЕКТ_ГЕРОЙ_ИГРЫ08/08

Класс объединяет данные и методы в одно целое. Игры в Unity пишутся именно так.

var p = new Player("Shiro");
p.Hit(30);
p.Hit(25);

class Player
{
    public string Name;
    public int Hp = 100;

    public Player(string name)
    {
        Name = name;
    }

    public void Hit(int damage)
    {
        Hp -= damage;
        Console.WriteLine($"{Name} has {Hp} HP");
    }
}
ВЫВОД
Shiro has 70 HP
Shiro has 45 HP
