Привет, мир

В Java весь код живёт внутри класса. Программа начинается в методе main. System.out.println выводит строку.

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, world!");
    }
}
Вывод
Hello, world!

В первой программе много слов, но их пишут в каждой программе на Java, поэтому они быстро становятся привычкой. public class Main — это класс; файл должен называться Main.java.

public static void main(String[] args) — точка старта. Код на Java компилируют через javac и запускают через java. В браузере можно попробовать на onlinegdb.com или jdoodle.com.

Разбор кода

public class Main {класс Main; имя файла должно совпадать.
public static void main(String[] args) {метод, с которого начинается программа.
System.out.println("Hello, world!");вывести текст и перенос строки.

Частые ошибки

  • Имя файла не совпадает с классом: класс Main в файле Hello.java — ошибка.
  • system.out.println маленькими буквами — нужно System.

Попробуй сам

Выведи своё имя, а на следующей строке 2026.

Показать ответ 
public class Main {
    public static void main(String[] args) {
        System.out.println("Shiro");
        System.out.println(2026);
    }
}
Вывод
Shiro
2026

Переменные

У каждой переменной есть тип: String для текста, int для целых чисел. + склеивает текст и значения. Дальше короткие примеры пишутся внутри main.

String name = "Shiro";
int age = 18;
age = age + 1;
System.out.println("Hi, I'm " + name + " and I'm " + age);
Вывод
Hi, I'm Shiro and I'm 19

String пишется с большой буквы, потому что это класс, а int — простой (примитивный) тип. Начиная с Java 10 можно писать var: var age = 18; — Java сама поймёт тип.

final int max = 10; делает константу, которую нельзя менять.

Разбор кода

String name = "Shiro";текстовая переменная.
int age = 18;целое число.
"Hi, I'm " + name + ...+ соединяет текст и значения в одну строку.

Частые ошибки

  • string маленькими буквами — Java знает только String.

Попробуй сам

Создай String city = "Kyiv" и int year = 2020, выведи: I live in Kyiv since 2020.

Показать ответ 
String city = "Kyiv";
int year = 2020;
System.out.println("I live in " + city + " since " + year);
Вывод
I live in Kyiv since 2020

Типы данных

Основные типы: int, double, boolean, char и String. У текста есть метод length().

int count = 10;          // whole number
double price = 9.99;     // number with a dot
boolean online = true;   // true or false
char letter = 'S';       // one character
String title = "VIBE";   // text
System.out.println(title.length());
Вывод
4

Примитивные типы (int, double, boolean, char) пишутся маленькими буквами и хранят просто значение. String — объект с множеством методов: toUpperCase(), contains(), charAt(0).

Текст в число: Integer.parseInt("5"). Число в текст: String.valueOf(5) или просто "" + 5.

Разбор кода

boolean online = true;true или false (слово boolean, а не bool).
char letter = 'S';один символ в одинарных кавычках.
title.length()это метод — со скобками.

Частые ошибки

  • Сравнивать строки через ==. В Java нужно a.equals(b).

Попробуй сам

Есть String a = "7". Выведи a как число плюс 3 (10).

Показать ответ 
String a = "7";
System.out.println(Integer.parseInt(a) + 3);
Вывод

Условия

if, else if и else — так же, как в C, C# и JavaScript.

int age = 18;

if (age >= 18) {
    System.out.println("Adult");
} else if (age >= 13) {
    System.out.println("Teen");
} else {
    System.out.println("Kid");
}
Вывод
Adult

Условие должно быть boolean. Соединяй через &&, ||, !. Для множества фиксированных значений есть switch.

Есть и короткая форма условие ? a : b: String label = age >= 18 ? "Adult" : "Kid";.

Разбор кода

if (age >= 18) {первая проверка.
} else if (age >= 13) {следующая.

Частые ошибки

  • if (name == "Shiro") может быть false даже при одинаковом тексте — используй name.equals("Shiro").

Попробуй сам

int t = 30. Выведи "Hot", если t > 25, иначе "OK".

Показать ответ 
int t = 30;
if (t > 25) {
    System.out.println("Hot");
} else {
    System.out.println("OK");
}
Вывод
Hot

Циклы

for со счётчиком, while — пока условие верно. Для списков есть цикл «для каждого»: for (String s : list).

for (int i = 0; i < 3; i++) {
    System.out.println("Step " + i);
}

int count = 3;
while (count > 0) {
    System.out.println(count);
    count--;
}
Вывод
Step 0
Step 1
Step 2
3
2
1

Циклы в Java такие же, как в C и C#: выучил — знаешь в трёх языках сразу.

break досрочно выходит из цикла, continue переходит к следующему кругу.

Разбор кода

count--;отнять 1.

Частые ошибки

  • Цикл while, в котором переменная не меняется, — программа зависнет.

Попробуй сам

Показать ответ

Методы

Функции в Java называются методами и живут внутри класса. static значит, что его можно вызвать без создания объекта.

public class Main {
    static int add(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {
        System.out.println(add(2, 3));
    }
}
Вывод
5

У метода есть тип результата (int, String или void, если ничего), имя и параметры с типами. Имена обычно начинаются с маленькой буквы: add, sayHello.

Метод можно написать выше или ниже main — Java сначала читает весь класс.

Разбор кода

static int add(int a, int b)возвращает int, принимает два int.
return a + b;вернуть сумму.
add(2, 3)вызов из main.

Частые ошибки

  • Вызвать нестатический метод из main без объекта — ошибка: non-static method cannot be referenced from a static context.

Попробуй сам

Напиши static int square(int n) и выведи square(7).

Показать ответ 
public class Main {
    static int square(int n) {
        return n * n;
    }

    public static void main(String[] args) {
        System.out.println(square(7));
    }
}
Вывод
49

Списки

ArrayList — список, который растёт. Его импортируют из java.util, а в угловых скобках указывают, что он хранит.

import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<String> langs = new ArrayList<>();
        langs.add("Java");
        langs.add("Kotlin");
        langs.add("Go");
        System.out.println(langs.size());
        for (String lang : langs) {
            System.out.println("I like " + lang);
        }
    }
}
Вывод
3
I like Java
I like Kotlin
I like Go

В Java есть и обычные массивы: int[] a = {1, 2, 3}; — фиксированный размер, длина через a.length. ArrayList гибче: add, get(i), remove(i), size().

Списки не хранят примитивы напрямую, поэтому для чисел пиши ArrayList<Integer>, а не <int>.

Разбор кода

import java.util.ArrayList;подключить класс ArrayList.
new ArrayList<>()создать пустой список.
langs.size()сколько элементов.
for (String lang : langs)для каждого элемента.

Частые ошибки

  • ArrayList<int> — ошибка. Используй ArrayList<Integer>.

Попробуй сам

Создай ArrayList<Integer> с 1, 2, 3, 4 и выведи сумму.

Показать ответ 
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> nums = new ArrayList<>();
        nums.add(1);
        nums.add(2);
        nums.add(3);
        nums.add(4);
        int sum = 0;
        for (int n : nums) {
            sum += n;
        }
        System.out.println(sum);
    }
}
Вывод
10

Мини-проект: герой игры

Java построена вокруг классов и объектов. Здесь у класса Player есть данные (name, hp) и действие (hit).

public class Main {
    static class Player {
        String name;
        int hp = 100;

        Player(String name) {
            this.name = name;
        }

        void hit(int damage) {
            hp -= damage;
            System.out.println(name + " has " + hp + " HP");
        }
    }

    public static void main(String[] args) {
        Player p = new Player("Shiro");
        p.hit(30);
        p.hit(25);
    }
}
Вывод
Shiro has 70 HP
Shiro has 45 HP

Player(String name) — конструктор: он выполняется, когда пишешь new Player("Shiro"). this.name значит «name этого объекта», чтобы отличить его от параметра name.

В настоящих проектах у каждого класса обычно свой файл. Здесь он внутри Main как static class, чтобы всё поместилось в один файл.

Разбор кода

static class Player {чертёж для игроков.
Player(String name) {конструктор.
this.name = name;сохранить параметр в объект.
Player p = new Player("Shiro");создать одного настоящего игрока.

Частые ошибки

  • Забыть new: Player p = Player("Shiro"); — ошибка.

Попробуй сам

Добавь метод heal(int amount) и вылечи игрока на 10 после ударов.

Показать ответ 
public class Main {
    static class Player {
        String name;
        int hp = 100;

        Player(String name) {
            this.name = name;
        }

        void hit(int damage) {
            hp -= damage;
            System.out.println(name + " has " + hp + " HP");
        }

        void heal(int amount) {
            hp += amount;
            System.out.println(name + " has " + hp + " HP");
        }
    }

    public static void main(String[] args) {
        Player p = new Player("Shiro");
        p.hit(30);
        p.hit(25);
        p.heal(10);
    }
}
Вывод
Shiro has 70 HP
Shiro has 45 HP
Shiro has 55 HP

Тест

5 вопросов. Выбери ответ — сразу увидишь, верно ли.

1. С чего начинается программа на Java?

С метода public static void main.

2. Что выведет этот код?

int x = 7;
System.out.println(x / 2);

Оба числа int, поэтому дробная часть отбрасывается.

3. Как правильно сравнить две строки?

== сравнивает объекты, equals() — текст.

4. Что выведет этот код?

String s = "Java";
System.out.println(s.length() + 1);

length() это 4, плюс 1 — 5.

5. Какой тип подходит для списка целых чисел?

Спискам нужен объектный тип Integer, а не примитив int.
