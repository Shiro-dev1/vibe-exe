Привет, мир

Любая программа начинается в fn main(). ! в println! значит, что это макрос: особый помощник, который пишет код за тебя.

fn main() {
    println!("Hello, world!");
}
Вывод
Hello, world!

Программы на Rust собирают через cargo или rustc, а попробовать Rust можно в браузере на play.rust-lang.org. Любая программа начинается в fn main().

println! выводит строку. Восклицательный знак показывает, что это макрос, а не обычная функция: он проверяет шаблон текста ещё при компиляции.

Разбор кода

fn main() {fn — функция; main — точка старта программы.
println!("Hello, world!");вывести текст и перенос строки.

Частые ошибки

  • Забыть !: println("...") — Rust не найдёт такую функцию.

Попробуй сам

Выведи своё имя, а на следующей строке 2026.

Показать ответ 
fn main() {
    println!("Shiro");
    println!("{}", 2026);
}
Вывод
Shiro
2026

Переменные

let создаёт переменную. По умолчанию её нельзя менять; добавь mut, чтобы было можно. Переменные вставляются в текст через { }.

fn main() {
    let name = "Shiro";
    let mut age = 18; // mut = можно менять
    age += 1;
    println!("Hi, I'm {name} and I'm {age}");
}
Вывод
Hi, I'm Shiro and I'm 19

В Rust переменные по умолчанию нельзя менять. Это защищает от случайных изменений. Если значение должно меняться, это говорят словом mut.

Внутри println! запись {name} вставляет переменную напрямую; {} берёт следующее значение после текста: println!("{} + {}", a, b).

Разбор кода

let name = "Shiro";переменная, которую нельзя менять.
let mut age = 18;mut разрешает изменения.
age += 1;age становится 19.

Частые ошибки

  • Менять переменную без mut — ошибка: cannot assign twice to immutable variable.

Попробуй сам

Создай city = "Kyiv" и year = 2020, выведи: I live in Kyiv since 2020.

Показать ответ 
fn main() {
    let city = "Kyiv";
    let year = 2020;
    println!("I live in {city} since {year}");
}
Вывод
I live in Kyiv since 2020

Типы данных

Обычно Rust сам угадывает тип, но его можно написать после :. Дальше короткие примеры пишутся внутри fn main().

let count: i32 = 10;      // целое число
let price: f64 = 9.99;    // дробное число
let online: bool = true;  // true или false
let letter: char = 'S';   // один символ
let title: &str = "VIBE"; // текст

println!("{}", title.len());
Вывод
4

Числовые типы говорят свой размер: i32 — целое на 32 бита (со знаком), u8 — от 0 до 255, f64 — дробное. &str — кусок текста, String — текст, которым ты владеешь и можешь менять.

Текст в число: "5".parse::<i32>().unwrap() — unwrap значит «я уверен, что получилось».

Разбор кода

let count: i32 = 10;тип после двоеточия.
let title: &str = "VIBE";кусок текста.
title.len()длина в байтах (для латиницы = количество букв).

Частые ошибки

  • Смешивать типы: i32 + f64 не скомпилируется. Преобразуй: count as f64 + price.

Попробуй сам

Есть let a = "7". Выведи a как число плюс 3 (10).

Показать ответ 
let a = "7";
let n: i32 = a.parse().unwrap();
println!("{}", n + 3);
Вывод
10

Условия

if работает без скобок вокруг условия, но { } обязательны.

let age = 18;

if age >= 18 {
    println!("Adult");
} else if age >= 13 {
    println!("Teen");
} else {
    println!("Kid");
}
Вывод
Adult

if в Rust не требует скобок вокруг условия, но фигурные скобки обязательны. Условие должно быть bool.

if умеет возвращать значение: let label = if age >= 18 { "Adult" } else { "Kid" };.

Разбор кода

if age >= 18 {без скобок, но с фигурными скобками.
} else if age >= 13 {следующая проверка.

Частые ошибки

  • if count { } с числом — Rust хочет настоящий bool: if count > 0.

Попробуй сам

Показать ответ

if t > 25 {
    println!("Hot");

Циклы

0..3 значит 0, 1, 2. while повторяет, пока условие верно.

for i in 0..3 {
    println!("Step {i}");
}

let mut count = 3;
while count > 0 {
    println!("{count}");
    count -= 1;
}
Вывод
Step 0
Step 1
Step 2
3
2
1

for i in 0..3 проходит по диапазону: 0, 1, 2. 0..=3 включает конец: 0, 1, 2, 3. while повторяет, пока условие верно, а loop — бесконечно, пока не сделаешь break.

Разбор кода

for i in 0..3 {i = 0, 1, 2.
let mut count = 3;mut, потому что count будет меняться.
count -= 1;отнять 1.

Частые ошибки

  • Забыть mut у счётчика, который меняешь в цикле.

Попробуй сам

Выведи числа от 1 до 5.

Показать ответ 
for i in 1..=5 {
    println!("{i}");
}
Вывод
1
2
3
4

Функции

Параметрам нужны типы, -> показывает тип результата. Последняя строка без ; — это то, что функция возвращает.

fn add(a: i32, b: i32) -> i32 {
    a + b // без ; = это возвращается
}

fn main() {
    println!("{}", add(2, 3));
}
Вывод
5

У каждого параметра нужен тип, а -> показывает, что функция возвращает. В Rust удобное правило: последнее выражение без ; и есть результат, поэтому return часто не нужен.

Если поставить ; в конце этой строки, она станет обычной командой, и функция ничего не вернёт — частая ошибка.

Разбор кода

fn add(a: i32, b: i32) -> i32 {на входе два i32, на выходе один i32.
a + bбез точки с запятой: это и есть результат.

Частые ошибки

  • a + b; с точкой с запятой — ошибка: mismatched types, ожидался i32, получено ().

Попробуй сам

Напиши fn square(n: i32) -> i32 и выведи square(7).

Показать ответ 
fn square(n: i32) -> i32 {
    n * n
}

fn main() {
    println!("{}", square(7));
}
Вывод

Векторы

vec! создаёт список, который может расти. Чтобы его менять, нужен mut. &langs даёт циклу прочитать список, не забирая его.

let mut langs = vec!["Python", "C", "Rust"];
langs.push("C#");
println!("{}", langs.len());

for lang in &langs {
    println!("I like {lang}");
}
Вывод
4
I like Python
I like C
I like Rust
I like C#

Vec — растущий список; vec![...] быстро его создаёт. Чтобы добавлять элементы, нужен mut.

Rust внимательно следит, кому принадлежат данные. for lang in &langs одалживает вектор только для чтения, поэтому langs можно использовать и после цикла. Без & цикл забрал бы вектор себе.

Разбор кода

let mut langs = vec![...];вектор, который можно менять.
langs.push("C#");добавить в конец.
for lang in &langs {прочитать каждый элемент, не забирая вектор.

Частые ошибки

  • Использовать вектор после for x in v (без &) — ошибка: value used after move.

Попробуй сам

Создай vec![1, 2, 3], добавь 4 и выведи сумму через .iter().sum::<i32>().

Показать ответ 
let mut v = vec![1, 2, 3];
v.push(4);
println!("{}", v.iter().sum::<i32>());
Вывод
10

Мини-проект: герой игры

struct хранит данные, impl добавляет к ним функции. &mut self значит, что функция может менять игрока.

struct Player {
    name: String,
    hp: i32,
}

impl Player {
    fn hit(&mut self, damage: i32) {
        self.hp -= damage;
        println!("{} has {} HP", self.name, self.hp);
    }
}

fn main() {
    let mut p = Player { name: String::from("Shiro"), hp: 100 };
    p.hit(30);
    p.hit(25);
}
Вывод
Shiro has 70 HP
Shiro has 45 HP

Классов в Rust нет: struct хранит данные, а блок impl добавляет к ним методы. &mut self в методе значит «этот метод может менять объект», &self — только читает.

Игрока нужно объявить как let mut p, потому что hit его меняет.

Разбор кода

struct Player { name: String, hp: i32 }что есть у каждого игрока.
impl Player {методы игрока.
fn hit(&mut self, damage: i32)может менять игрока.
String::from("Shiro")сделать владеемую строку String из текста.

Частые ошибки

  • let p = ... без mut, потом p.hit(30) — ошибка: cannot borrow as mutable.

Попробуй сам

Добавь метод heal(&mut self, amount: i32) и вылечи игрока на 10 после ударов.

Показать ответ 
struct Player {
    name: String,
    hp: i32,
}

impl Player {
    fn hit(&mut self, damage: i32) {
        self.hp -= damage;
        println!("{} has {} HP", self.name, self.hp);
    }
    fn heal(&mut self, amount: i32) {
        self.hp += amount;
        println!("{} has {} HP", self.name, self.hp);
    }
}

fn main() {
    let mut p = Player { name: String::from("Shiro"), hp: 100 };
    p.hit(30);
    p.hit(25);
    p.heal(10);
}
Вывод
Shiro has 70 HP
Shiro has 45 HP
Shiro has 55 HP

Тест

5 вопросов. Выбери ответ — сразу увидишь, верно ли.

1. Что выведет этот код?

let mut x = 5;
x += 3;
println!("{x}");

x объявлен с mut, его можно менять: 5 + 3 = 8.

2. Что тут случится?

let x = 5;
x = 6;

Без mut переменную менять нельзя, и Rust не скомпилирует такой код.

3. Сколько раз выполнится цикл?

for i in 0..3 {
    println!("{i}");
}

0..3 — это 0, 1, 2: последнее число не входит.

4. Что выведет этот код?

fn double(n: i32) -> i32 {
    n * 2
}

fn main() {
    println!("{}", double(21));
}

Последняя строка без ; возвращается: 21 * 2 = 42.

5. Что выведет этот код?

let v = vec![1, 2, 3];
println!("{}", v.len());

len() — сколько элементов в векторе: 3.
