Основы Linux

Linux — бесплатное ядро операционной системы, его начал писать Линус Торвальдс в 1991 году. На нём работает большинство серверов в интернете, все Android-телефоны и суперкомпьютеры мира. ChromeOS тоже построена на Linux.

Что такое терминал

Терминал — это окно, где компьютером управляют текстовыми командами вместо мышки. Пишешь команду, нажимаешь Enter, и компьютер отвечает. Обычно команда выглядит так:

$ команда  опции  цель
$ ls -la /home

Файлы и папки

pwd
Показать, в какой папке ты сейчас.
ls
Список файлов в папке.ls -la — ещё и скрытые файлы с подробностями
cd папка
Зайти в папку.cd .. — на папку выше; cd ~ — в домашнюю папку
mkdir имя
Создать новую папку.
touch file.txt
Создать пустой файл.
cp a b
Скопировать файл a в b.
mv a b
Переместить или переименовать файл.
rm файл
Удалить файл.осторожно: корзины нет, файл удаляется навсегда

Чтение и поиск

cat file.txt
Вывести весь файл.
less file.txt
Читать длинный файл постранично.q — выйти
grep "слово" файл
Найти строки, где есть слово.
man ls
Открыть инструкцию к любой команде.

Система

sudo команда
Выполнить команду от имени администратора.спросит твой пароль
chmod +x script.sh
Сделать файл запускаемым.
top
Посмотреть запущенные программы и насколько они нагружают компьютер.
clear
Очистить экран терминала.

Полезные клавиши

Tab
Допишет название файла или команды за тебя.
↑ / ↓
Листать команды, которые ты вводил раньше.
Ctrl + C
Остановить работающую команду.
