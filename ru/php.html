Привет, мир

Код на PHP начинается с <?php. echo выводит текст — на страницу или в терминал.

<?php
echo "Hello, world!";
Вывод
Hello, world!

В файле PHP можно смешивать HTML и PHP. Всё после <?php — это код; сервер его выполняет и отправляет посетителю только результат, поэтому твой PHP-код никто не увидит.

Каждая команда заканчивается на ;. Попробовать PHP можно прямо в браузере на onlinephp.io или 3v4l.org.

Разбор кода

<?phpначало PHP-кода.
echo "Hello, world!";вывести текст.

Частые ошибки

  • Забыть ; — PHP покажет Parse error: syntax error.

Попробуй сам

Выведи своё имя, перенос строки и 2026.

Показать ответ 
<?php
echo "Shiro\n";
echo 2026;
Вывод
Shiro
2026

Переменные

Каждая переменная в PHP начинается с $. В двойных кавычках PHP подставляет значения переменных прямо в текст, в одинарных — нет.

<?php
$name = "Shiro";
$age = 18;
echo "Hi, I'm $name and I'm $age\n";
echo 'Single quotes: $name' . "\n";
Вывод
Hi, I'm Shiro and I'm 18
Single quotes: $name

В PHP типы не пишут: переменная принимает то, что в неё положили. Знак $ помогает сразу видеть переменные.

Точка . склеивает строки (в JavaScript это был бы +). "\n" — перенос строки, он работает только в двойных кавычках.

Разбор кода

$name = "Shiro";создать переменную $name.
"Hi, I'm $name ..."двойные кавычки: $name заменится на Shiro.
'Single quotes: $name'одинарные кавычки: выводится как есть.
. "\n"приклеить в конец перенос строки.

Частые ошибки

  • Забыть $: name = "Shiro"; — ошибка.
  • Склеивать текст через + — в PHP для этого ..

Попробуй сам

Создай $city = "Kyiv" и $year = 2020 и выведи: I live in Kyiv since 2020.

Показать ответ 
<?php
$city = "Kyiv";
$year = 2020;
echo "I live in $city since $year";
Вывод
I live in Kyiv since 2020

Типы данных

В PHP есть int, float, string, bool, array и null. gettype() показывает тип, strlen() считает символы.

<?php
$count = 10;        // int
$price = 9.99;      // float
$title = "VIBE";    // string
$online = true;     // bool
echo gettype($price) . "\n";
echo strlen($title) . "\n";
Вывод
double
4

Обрати внимание: для float функция gettype() говорит double — это старое название того же типа.

PHP сам меняет типы, когда нужно: "5" + 3 даёт 8. Чтобы преобразовать специально, пиши (int), (float) или (string) перед значением: (int)"42".

Разбор кода

$price = 9.99;дробное число (float).
gettype($price)возвращает название типа текстом.
strlen($title)длина строки: 4.

Частые ошибки

  • strlen("Привет") даёт 12, а не 6: считаются байты. Для русского текста используй mb_strlen().

Попробуй сам

Есть $a = "7". Выведи $a как число плюс 3 (10).

Показать ответ 
<?php
$a = "7";
echo (int)$a + 3;
Вывод
10

Условия

if, elseif (в PHP одним словом) и else. Условие в скобках, код — в фигурных скобках.

<?php
$age = 18;

if ($age >= 18) {
    echo "Adult\n";
} elseif ($age >= 13) {
    echo "Teen\n";
} else {
    echo "Kid\n";
}
Вывод
Adult

Сравнивай через === (равны значение и тип) и !==. Двойное == сначала меняет типы и может удивить, поэтому лучше три знака.

Условия соединяют через && (и), || (или), ! (не).

Разбор кода

if ($age >= 18) {первая проверка.
} elseif ($age >= 13) {следующая.
} else {всё остальное.

Частые ошибки

  • if ($age = 18) присваивает вместо сравнения и всегда верно.

Попробуй сам

$t = 30. Выведи "Hot", если $t > 25, иначе "OK".

Показать ответ 
<?php
$t = 30;
if ($t > 25) {
    echo "Hot";
} else {
    echo "OK";
}
Вывод
Hot

Циклы

for и while выглядят как в C и JavaScript. Для массивов в PHP есть foreach — он будет в следующих уроках.

<?php
for ($i = 0; $i < 3; $i++) {
    echo "Step $i\n";
}

$count = 3;
while ($count > 0) {
    echo "$count\n";
    $count--;
}
Вывод
Step 0
Step 1
Step 2
3
2
1

Циклы в PHP часто строят HTML: строку таблицы для каждого товара, пункт списка для каждого комментария.

break выходит из цикла, continue переходит к следующему кругу.

Разбор кода

for ($i = 0; $i < 3; $i++)счётчик $i идёт 0, 1, 2.
$count--;отнять 1.

Частые ошибки

  • Забыть $ у счётчика: for (i = 0; ...).

Попробуй сам

Выведи числа от 1 до 5, каждое на своей строке.

Показать ответ 
<?php
for ($i = 1; $i <= 5; $i++) {
    echo "$i\n";
}
Вывод
1
2
3
4
5

Функции

function создаёт функцию. Можно указать типы параметров и результата — PHP их проверит.

<?php
function greet(string $name): string {
    return "Hello, $name!";
}

echo greet("Shiro") . "\n";
Вывод
Hello, Shiro!

В PHP тысячи готовых функций: strtoupper(), date(), count(), round(). Прежде чем писать свою, проверь, нет ли уже готовой.

У параметров могут быть значения по умолчанию: function greet(string $name = "friend").

Разбор кода

function greet(string $name): stringпринимает строку, возвращает строку.
return "Hello, $name!";результат с именем внутри.

Частые ошибки

  • Использовать внутри функции переменную снаружи — функции не видят внешние переменные. Передавай их параметрами.

Попробуй сам

Напиши square(int $n): int и выведи square(7).

Показать ответ 
<?php
function square(int $n): int {
    return $n * $n;
}
echo square(7);
Вывод
49

Массивы

Массивы в PHP бывают списками (["PHP", "Go"]) или с именованными ключами (["name" => "Shiro"]). foreach проходит по ним.

<?php
$langs = ["PHP", "JS", "Go"];
$langs[] = "Rust";
echo count($langs) . "\n";

$user = ["name" => "Shiro", "age" => 18];
foreach ($user as $key => $value) {
    echo "$key: $value\n";
}
Вывод
4
name: Shiro
age: 18

Массив с именованными ключами («ассоциативный массив») похож на маленькую таблицу: слева имя, справа значение. Данные из форм и баз данных обычно приходят именно так.

$langs[] = ... добавляет в конец. count() считает элементы. $user["name"] берёт значение по ключу.

Разбор кода

$langs[] = "Rust";добавить в конец.
["name" => "Shiro", ...]=> связывает ключ со значением.
foreach ($user as $key => $value)пройти по каждому ключу и значению.

Частые ошибки

  • Читать несуществующий ключ — PHP покажет Warning: Undefined array key. Проверяй через isset($user["email"]).

Попробуй сам

Создай $nums = [1, 2, 3], добавь 4 и выведи сумму через array_sum().

Показать ответ 
<?php
$nums = [1, 2, 3];
$nums[] = 4;
echo array_sum($nums);
Вывод

Мини-проект: меню сайта

То, для чего создан PHP: собирать HTML из данных. Один массив описывает меню, а цикл превращает его в список ссылок.

<?php
$menu = ["Home" => "/", "Lessons" => "/lessons", "Contacts" => "/contacts"];

echo "<ul>\n";
foreach ($menu as $title => $link) {
    echo "  <li><a href=\"$link\">$title</a></li>\n";
}
echo "</ul>\n";
Вывод
<ul>
  <li><a href="/">Home</a></li>
  <li><a href="/lessons">Lessons</a></li>
  <li><a href="/contacts">Contacts</a></li>
</ul>

На настоящем сайте этот HTML сразу уходит в браузер, и посетитель видит обычное меню. Нужен новый пункт? Добавь одну строку в массив — обновятся все страницы, где он используется.

\" — это кавычка внутри строки в двойных кавычках; без обратного слэша PHP решил бы, что строка закончилась.

Разбор кода

$menu = [...]данные: название => ссылка.
foreach ($menu as $title => $link)для каждого пункта меню…
echo " <li><a href=\"$link\">$title</a></li>\n";…вывести одну строку HTML.

Частые ошибки

  • Вставлять текст от пользователей прямо в HTML — используй htmlspecialchars(), иначе кто-то сможет подсунуть свой код.

Попробуй сам

Добавь в меню пункт "Blog" со ссылкой /blog.

Показать ответ 
<?php
$menu = ["Home" => "/", "Lessons" => "/lessons", "Contacts" => "/contacts", "Blog" => "/blog"];

echo "<ul>\n";
foreach ($menu as $title => $link) {
    echo "  <li><a href=\"$link\">$title</a></li>\n";
}
echo "</ul>\n";
Вывод
<ul>
  <li><a href="/">Home</a></li>
  <li><a href="/lessons">Lessons</a></li>
  <li><a href="/contacts">Contacts</a></li>
  <li><a href="/blog">Blog</a></li>
</ul>

Тест

5 вопросов. Выбери ответ — сразу увидишь, верно ли.

1. С чего начинается каждая переменная в PHP?

Переменные PHP всегда начинаются с $.

2. Что выведет этот код?

<?php
$name = "Shiro";
echo 'Hi $name';

Одинарные кавычки не подставляют переменные.

3. Какой оператор склеивает строки в PHP?

В PHP это точка: "a" . "b".

4. Что выведет этот код?

<?php
$a = [10, 20, 30];
$a[] = 40;
echo count($a);

$a[] = 40 добавил ещё один элемент.

5. Где обычно выполняется код PHP?

PHP выполняется на сервере и отправляет в браузер готовый HTML.
