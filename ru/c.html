Привет, мир

C нужно компилировать: превратить в программу перед запуском. Любая программа начинается в main. \n — переход на новую строку.

#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}
Вывод
Hello, world!

Программу на C пишут в текстовом файле, а потом компилируют — превращают в исполняемый файл, понятный компьютеру. В браузере это делается в один клик на сайтах вроде onlinegdb.com.

#include <stdio.h> подключает стандартную библиотеку ввода-вывода, где живёт printf. int main(void) — точка, откуда начинается программа. return 0; сообщает системе «всё прошло хорошо».

Разбор кода

#include <stdio.h>подключить библиотеку с printf.
int main(void) {главная функция; int значит, что она возвращает целое число.
printf("Hello, world!\n");вывести текст; \n переносит на новую строку.
return 0;успешно завершить программу.

Частые ошибки

  • Забыть ; в конце строки — компилятор остановится с ошибкой.
  • Забыть \n — следующий текст приклеится к той же строке.

    printf("Shiro\n");

Переменные

В C у каждой переменной нужно указать тип. printf вставляет значения по кодам: %d — целое число, %.2f — дробное с 2 знаками после точки, %c — один символ. Дальше короткие примеры пишутся внутри main.

int age = 18;
float price = 9.99f;
char letter = 'S';

printf("Age: %d\n", age);
printf("Price: %.2f\n", price);
printf("Letter: %c\n", letter);
Вывод
Age: 18
Price: 9.99
Letter: S

В C у каждой переменной фиксированный тип, который пишут перед именем. По нему компилятор понимает, сколько памяти выделить.

printf сам не знает типов, поэтому ему подсказывают кодами: %d для int, %f для float/double, %c для char, %s для текста. Значения идут после текста в том же порядке.

Разбор кода

int age = 18;целое число.
float price = 9.99f;дробное число; f в конце означает float.
char letter = 'S';один символ, в одинарных кавычках.
printf("Price: %.2f\n", price);%.2f — число ровно с 2 знаками после точки.

Частые ошибки

  • Не тот код формата: printf("%d", price) для float выведет мусор.
  • Двойные кавычки для char: char c = "S"; — ошибка, нужно 'S'.

Попробуй сам

printf("Year: %d\n", year);
Вывод
Year: 2026

Типы данных

Текст в C — это массив символов. %s выводит текст, sizeof показывает, сколько байт что-то занимает (у текста в конце есть один скрытый лишний байт).

int whole = 42;           // целое число
double precise = 3.14159; // дробное число
char symbol = '#';        // один символ
char word[] = "VIBE";     // текст

printf("%s has %zu letters\n", word, sizeof(word) - 1);
Вывод
VIBE has 4 letters

В C нет отдельного типа для строк: текст — это массив char, который заканчивается скрытым нулевым символом '\0'. Поэтому sizeof("VIBE") равен 5, а не 4.

double похож на float, но точнее — по умолчанию используй его для дробных чисел. Для длины текста есть strlen() из <string.h>.

Разбор кода

double precise = 3.14159;точное дробное число.
char word[] = "VIBE";текст: массив из 5 символов (4 буквы + скрытый \0).
sizeof(word) - 1размер в байтах минус скрытый символ конца.

Частые ошибки

  • Сравнивать тексты через ==. В C нужно strcmp(a, b) == 0.

Попробуй сам

Условия

if выполняет код, только если условие в скобках верно.

int age = 18;

if (age >= 18) {
    printf("Adult\n");
} else if (age >= 13) {
    printf("Teen\n");
} else {
    printf("Kid\n");
}
Вывод
Adult

if в C работает как в большинстве языков: условие в скобках, блок в фигурных. В C «истина» — это любое число кроме 0, а «ложь» — это 0.

Условия соединяют через && (и), || (или) и ! (не). Например: if (age >= 13 && age < 18).

Разбор кода

if (age >= 18) {проверка: age 18 или больше.
} else if (age >= 13) {иначе проверяем следующее условие.
} else {если ничего не подошло.

Частые ошибки

  • if (x = 5) присваивает 5 и всегда истинно. Сравнивай через ==.

Попробуй сам

Циклы

У for три части: начало, условие, шаг. i++ прибавляет 1, count-- отнимает 1.

for (int i = 0; i < 3; i++) {
    printf("Step %d\n", i);
}

int count = 3;
while (count > 0) {
    printf("%d\n", count);
    count--;
}
Вывод
Step 0
Step 1
Step 2
3
2
1

Циклы в C: for (начало; условие; шаг), while (повторять, пока верно) и do ... while, который выполнится хотя бы раз. Они такие же, как в JavaScript, C++, Java и C#: выучил один раз — пользуешься везде.

break досрочно выходит из цикла, continue переходит к следующему кругу.

Разбор кода

for (int i = 0; i < 3; i++)i = 0, 1, 2; после каждого круга i растёт на 1.
while (count > 0)повторять, пока count больше нуля.
count--;отнять 1.

Частые ошибки

  • for (int i = 0; i <= 3; i++) выполнится 4 раза, а не 3 — следи за < и <=.

Функции

У функции есть тип результата, название и параметры с типами. Её нужно написать до того, как используешь.

#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main(void) {
    printf("%d\n", add(2, 3));
    return 0;
}
Вывод
5

Функция в C указывает, какой тип она возвращает, своё имя и типы параметров: int add(int a, int b). Если функция ничего не возвращает, её тип — void.

Компилятор читает сверху вниз, поэтому функцию нужно написать (или объявить) выше того места, где её вызывают.

Разбор кода

int add(int a, int b) {возвращает int, принимает два int.
return a + b;вернуть сумму.
add(2, 3)вызов функции: a = 2, b = 3.

Частые ошибки

  • Написать функцию ниже main без объявления — компилятор будет ругаться.

Массивы

Массив хранит много значений одного типа. Счёт идёт с 0. C не хранит длину массива, поэтому считаем её через sizeof.

int scores[] = {10, 20, 30, 40};
int size = sizeof(scores) / sizeof(scores[0]);
int sum = 0;

for (int i = 0; i < size; i++) {
    sum += scores[i];
}
printf("Sum: %d\n", sum);
Вывод
Sum: 100

Массив в C — это фиксированное количество значений одного типа, стоящих в памяти рядом. После создания его размер не меняется.

C не проверяет, правильный ли индекс: scores[10] в массиве из 4 элементов читает чужую память. Это классический источник ошибок, поэтому всегда следи за размером.

Разбор кода

int scores[] = {10, 20, 30, 40};массив из 4 int; размер посчитан по списку.
sizeof(scores) / sizeof(scores[0])все байты делим на байты одного элемента = количество элементов.
sum += scores[i];прибавить каждый элемент к sum.

Частые ошибки

  • Выйти на шаг дальше: i <= size вместо i < size.

Попробуй сам

Показать ответ 
int a[] = {3, 9, 4, 7};
int max = a[0];
for (int i = 1; i < 4; i++) {
    if (a[i] > max) max = a[i];
}
printf("%d\n", max);
Вывод

Мини-проект: угадай число

Всё вместе. rand() даёт случайное число, scanf читает то, что ввёл игрок. Ниже — пример одной игры.

#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void) {
    srand(time(NULL));
    int secret = rand() % 10 + 1;
    int guess = 0;

    while (guess != secret) {
        printf("Guess a number from 1 to 10: ");
        scanf("%d", &guess);
        if (guess < secret) printf("Bigger!\n");
        else if (guess > secret) printf("Smaller!\n");
    }
    printf("You got it!\n");
    return 0;
}
Вывод
Guess a number from 1 to 10: 5
Bigger!
Guess a number from 1 to 10: 8
Smaller!
Guess a number from 1 to 10: 7
You got it!

rand() даёт псевдослучайное число; % 10 оставляет остаток от 0 до 9, а + 1 делает от 1 до 10. srand(time(NULL)) перемешивает генератор текущим временем, чтобы каждая игра была разной.

scanf("%d", &guess) читает число с клавиатуры. & значит «адрес guess»: scanf должен знать, куда положить значение.

Разбор кода

srand(time(NULL));запустить генератор случайных чисел от текущего времени.
rand() % 10 + 1случайное число от 1 до 10.
scanf("%d", &guess);прочитать целое число в guess.

Частые ошибки

  • Забыть & в scanf — программа может упасть.

Попробуй сам

Добавь счётчик попыток и выведи его в конце.

Показать ответ 
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void) {
    srand(time(NULL));
    int secret = rand() % 10 + 1;
    int guess = 0, tries = 0;

    while (guess != secret) {
        printf("Guess a number from 1 to 10: ");
        scanf("%d", &guess);
        tries++;
        if (guess < secret) printf("Bigger!\n");
        else if (guess > secret) printf("Smaller!\n");
    }
    printf("You got it in %d tries!\n", tries);
    return 0;
}

Тест

5 вопросов. Выбери ответ — сразу увидишь, верно ли.

1. Что выведет этот код?

int x = 7;
printf("%d\n", x / 2);

Оба числа целые, поэтому C отбрасывает дробную часть.

2. Какой код в printf выводит целое число?

%d — целое, %s — текст, %c — символ, %f — дробное.

3. Что выведет этот код?

int a[] = {4, 8, 15};
printf("%d\n", a[2]);

Счёт идёт с 0: a[0]=4, a[1]=8, a[2]=15.

4. Что выведет этот код?

for (int i = 0; i < 3; i++) {
    printf("%d", i);
}

i идёт 0, 1, 2 и останавливается на 3.

5. С чего начинается любая программа на C?

Программа всегда начинает работу с main().
