Языки программирования

Язык программирования — это то, как ты разговариваешь с компьютером. Каждый хорош в чём-то своём. Вот двенадцать, которые встречаются чаще всего, и у каждого — классическая первая программа: вывести "Hello, world!".

Python

Год
1991
Автор
Гвидо ван Россум
Для чего
боты, скрипты, автоматизация, данные, ИИ

Простой и понятный, почти как английский текст. Отличный первый язык. Большинство Telegram-ботов написаны на Python.

Открыть уроки →
print("Hello, world!")

JavaScript

Год
1995
Автор
Брендан Эйх (Netscape)
Для чего
живые сайты, серверы (Node.js)

Язык интернета: работает в любом браузере. Глаз на главной странице — это JavaScript.

Открыть уроки →
console.log("Hello, world!");

TypeScript

Год
2012
Автор
Андерс Хейлсберг (Microsoft)
Для чего
большие сайты и веб-приложения

JavaScript с типами. Его создал тот же автор, что и C#. На нём написаны VS Code, Slack и многие большие сайты.

Открыть уроки →
console.log("Hello, world!");

HTML

Год
1991
Автор
Тим Бернерс-Ли
Для чего
структура любой веб-страницы

Не язык программирования, а язык разметки: он говорит, что есть на странице — заголовки, текст, кнопки, картинки.

Открыть уроки →
<h1>Hello, world!</h1>

CSS

Год
1996
Автор
Хокон Виум Ли
Для чего
цвета, шрифты, расположение, анимации

HTML говорит, что есть на странице, CSS — как это выглядит. Этот чёрно-белый стиль — CSS.

Открыть уроки →
h1 { color: white; background: black; }

PHP

Год
1995
Автор
Расмус Лердорф
Для чего
сайты, блоги, интернет-магазины

Работает на сервере и собирает страницы. На PHP сделаны WordPress, Википедия и первая версия Facebook.

Открыть уроки →
<?php
echo "Hello, world!";

Java

Год
1995
Автор
Джеймс Гослинг (Sun Microsystems)
Для чего
Android-приложения, серверы, системы больших компаний

Строгий и надёжный, работает почти на любом устройстве. На Java написаны Android-приложения и Minecraft.

Открыть уроки →
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, world!");
    }
}

C

Год
1972
Автор
Деннис Ритчи (Bell Labs)
Для чего
операционные системы, драйверы, быстрые программы

Старый, быстрый и близкий к «железу». Ядро Linux написано на C.

Открыть уроки →
#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}

C++

Год
1985
Автор
Бьёрн Страуструп (Bell Labs)
Для чего
игры, игровые движки, браузеры, быстрые программы

C с классами и множеством инструментов сверху. Unreal Engine и Chrome написаны на C++.

Открыть уроки →
#include <iostream>

int main() {
    std::cout << "Hello, world!" << std::endl;
    return 0;
}

C#

Год
2000
Автор
Андерс Хейлсберг (Microsoft)
Для чего
игры в Unity, программы для Windows, сайты

Язык от Microsoft, похож на Java и C++, но проще. Большинство игр в Unity написаны на C#.

Открыть уроки →
Console.WriteLine("Hello, world!");

Go

Год
2009
Автор
Роберт Гризмер, Роб Пайк, Кен Томпсон (Google)
Для чего
серверы, облачные сервисы, утилиты для терминала

Простой, быстрый и умеет делать много дел одновременно. На Go написаны Docker и Kubernetes.

Открыть уроки →
package main

import "fmt"

func main() {
	fmt.Println("Hello, world!")
}

Rust

Год
2015 (версия 1.0)
Автор
Грейдон Хоар, Mozilla
Для чего
быстрые и надёжные системные программы

Такой же быстрый, как C, но компилятор ловит многие ошибки с памятью ещё до запуска программы.

Открыть уроки →
fn main() {
    println!("Hello, world!");
}
