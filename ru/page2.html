ЯЗЫКИ.DOC

Язык программирования — это то, как ты разговариваешь с компьютером. Каждый хорош в чём-то своём. Вот восемь, которые встречаются чаще всего, и у каждого — классическая первая программа: вывести "Hello, world!".

Хочешь выучить какой-то? Напиши его название в терминале, например python, и откроются уроки: от самой первой строчки до мини-проекта.

PYTHON01
ГОД
1991
АВТОР
Guido van Rossum
ДЛЯ ЧЕГО
боты, скрипты, автоматизация, данные, ИИ

Простой и понятный, почти как английский текст. Отличный первый язык. Большинство Telegram-ботов написаны на Python.

print("Hello, world!")

> введи python, чтобы открыть уроки

JAVASCRIPT02
ГОД
1995
АВТОР
Brendan Eich (Netscape)
ДЛЯ ЧЕГО
живые сайты, серверы (Node.js)

Язык интернета: работает в любом браузере. Все движущиеся точки на странице 1 — это JavaScript.

console.log("Hello, world!");

> введи js, чтобы открыть уроки

HTML03
ГОД
1991
АВТОР
Tim Berners-Lee
ДЛЯ ЧЕГО
структура любой веб-страницы

Не язык программирования, а язык разметки: он говорит, что есть на странице — заголовки, текст, кнопки, картинки.

<h1>Hello, world!</h1>

> введи html, чтобы открыть уроки

CSS04
ГОД
1996
АВТОР
Håkon Wium Lie
ДЛЯ ЧЕГО
цвета, шрифты, расположение, анимации

HTML говорит, что есть на странице, CSS — как это выглядит. Этот чёрно-белый стиль — CSS.

h1 { color: white; background: black; }

> введи css, чтобы открыть уроки

C05
ГОД
1972
АВТОР
Dennis Ritchie (Bell Labs)
ДЛЯ ЧЕГО
операционные системы, драйверы, быстрые программы

Старый, быстрый и близкий к «железу». Ядро Linux написано на C.

#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}

> введи c, чтобы открыть уроки
