Подключение CSS

Стили пишут в файле style.css и подключают внутри <head>. Правило выглядит так: кого стилизуем, потом { свойство: значение; }.

<!-- index.html, внутри <head> -->
<link rel="stylesheet" href="style.css">

/* style.css */
body {
  background: black;
  color: white;
}
02 / 08

Селекторы

Селектор выбирает, какие элементы стилизовать. Класс (.) можно использовать много раз, id (#) — только один раз на странице.

p { color: gray; }            /* все <p> */
.card { border: 2px solid; }  /* class="card" */
#logo { font-size: 32px; }    /* id="logo" */
a:hover { color: white; }     /* ссылка под мышкой */
03 / 08

Цвета и шрифты

Цвет можно задать словом, кодом #hex или rgb(). Шрифты перечисляются по порядку: если первого нет, берётся следующий.

h1 {
  color: #ffffff;
  background: rgb(0, 0, 0);
  font-family: Arial, sans-serif;
  font-size: 48px;
  font-weight: bold;
  text-align: center;
}
04 / 08

Отступы и рамки

Каждый элемент — это коробка. padding — отступ внутри рамки, margin — снаружи.

.card {
  width: 300px;
  padding: 16px;          /* внутри */
  border: 2px solid white;
  margin: 24px;           /* снаружи */
  border-radius: 8px;     /* круглые углы */
}
05 / 08

Flexbox

Flexbox ставит элементы в ряд (или в колонку) и распределяет их. Идеально для меню и шапок.

.menu {
  display: flex;
  justify-content: space-between; /* вдоль ряда */
  align-items: center;            /* поперёк ряда */
  gap: 16px;
}
06 / 08

Grid

Grid раскладывает элементы по строкам и колонкам. 1fr — «одна равная часть», так что здесь 3 одинаковые колонки.

.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}
07 / 08

Анимации

transition делает изменение плавным. @keyframes описывает анимацию по шагам. Так работает мигающий курсор на этом сайте.

.button {
  transition: transform 0.2s;
}
.button:hover {
  transform: scale(1.1);
}

.cursor {
  animation: blink 1s infinite;
}
@keyframes blink {
  50% { opacity: 0; }
}
08 / 08

Телефоны

@media применяет стили только на некоторых экранах. Здесь галерея на узких телефонах становится одной колонкой.

@media (max-width: 600px) {
  .gallery {
    grid-template-columns: 1fr;
  }
}

Тест

5 вопросов. Выбери ответ — сразу увидишь, верно ли.

1. Какой селектор выбирает элементы с class="card"?

Точка — класс, # — id.

2. Какое свойство — отступ ВНУТРИ рамки?

padding — внутри, margin — снаружи.

3. Что это сделает?

.box {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

1fr — одна равная часть, повторённая 3 раза: три одинаковые колонки.

4. Какое свойство меняет цвет текста?

color — цвет текста, background — цвет фона.

5. Когда сработают эти стили?

@media (max-width: 600px) {
  .menu { display: none; }
}

max-width: 600px значит «до 600 пикселей в ширину» — это телефоны.
