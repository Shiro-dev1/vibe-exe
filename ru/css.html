Подключение CSS

Стили пишут в файле style.css и подключают внутри <head>. Правило выглядит так: кого стилизуем, потом { свойство: значение; }.

<!-- index.html, внутри <head> -->
<link rel="stylesheet" href="style.css">

/* style.css */
body {
  background: black;
  color: white;
}

CSS — это «каскадные таблицы стилей». Один CSS-файл может оформлять весь сайт: меняешь цвет один раз — и обновляются все страницы.

Правило состоит из селектора (кого) и объявлений (что): body { color: white; }. Каждое объявление — свойство: значение;. Не забывай двоеточие и точку с запятой.

Разбор кода

<link rel="stylesheet" href="style.css">подключить файл style.css к странице.
body {селектор: оформляем всё тело страницы.
background: black;цвет фона.
color: white;цвет текста.

Частые ошибки

  • Неверный путь в href — стили молча не подключаются. Проверь имя файла и папку.

Попробуй сам

Сделай всю страницу тёмно-синей с жёлтым текстом.

Показать ответ 
body {
  background: navy;
  color: yellow;
}

Селекторы

Селектор выбирает, какие элементы стилизовать. Класс (.) можно использовать много раз, id (#) — только один раз на странице.

p { color: gray; }            /* все <p> */
.card { border: 2px solid; }  /* class="card" */
#logo { font-size: 32px; }    /* id="logo" */
a:hover { color: white; }     /* ссылка под мышкой */

Селекторы — это то, как CSS находит элементы. Селектор тега (p) оформляет все такие теги. Класс (.card) — любой элемент с class="card". id (#logo) — один уникальный элемент.

Если два правила спорят, побеждает более конкретное: id сильнее класса, класс сильнее тега. Если они равны, побеждает то, что ниже, — это и есть «каскад».

Разбор кода

p { ... }все абзацы.
.card { ... }каждый элемент с class="card".
#logo { ... }единственный элемент с id="logo".
a:hover { ... }:hover — это состояние: ссылка, пока на неё наведена мышь.

Частые ошибки

  • Забыть точку: card { } ищет тег <card>, а не класс.

Попробуй сам

Сделай так, чтобы у всех кнопок с классом "big" размер шрифта был 24px.

Показать ответ 
.big {
  font-size: 24px;
}

Цвета и шрифты

Цвет можно задать словом, кодом #hex или rgb(). Шрифты перечисляются по порядку: если первого нет, берётся следующий.

h1 {
  color: #ffffff;
  background: rgb(0, 0, 0);
  font-family: Arial, sans-serif;
  font-size: 48px;
  font-weight: bold;
  text-align: center;
}

Цвета записывают по-разному: словами (white), hex-кодом (#ff8800 — красный, зелёный, синий от 00 до ff) или rgb(255, 136, 0). Прозрачность: rgba(0, 0, 0, 0.5).

font-family перечисляет шрифты по приоритету; в конце всегда пиши общий вариант, например sans-serif. font-size — размер, font-weight — толщина (400 обычный, 700 жирный).

Разбор кода

color: #ffffff;белый текст в hex.
font-family: Arial, sans-serif;использовать Arial; если его нет — любой шрифт без засечек.
text-align: center;выровнять текст по центру элемента.

Частые ошибки

  • Забыть # в hex: color: ffffff; не работает.

Попробуй сам

Сделай заголовки h2 оранжевыми (#ff8800), жирными и 32px.

Показать ответ 
h2 {
  color: #ff8800;
  font-weight: bold;
  font-size: 32px;
}

Отступы и рамки

Каждый элемент — это коробка. padding — отступ внутри рамки, margin — снаружи.

.card {
  width: 300px;
  padding: 16px;          /* внутри */
  border: 2px solid white;
  margin: 24px;           /* снаружи */
  border-radius: 8px;     /* круглые углы */
}

Каждый элемент — прямоугольник («коробка»). Изнутри наружу: содержимое, потом padding, потом border, потом margin. Фон закрашивает содержимое и padding, но не margin.

Совет: добавь box-sizing: border-box;, чтобы ширина включала padding и рамку. Тогда карточка 300px так и останется шириной 300px.

Разбор кода

width: 300px;ширина коробки.
padding: 16px;отступ между содержимым и рамкой.
border: 2px solid white;толщина, стиль и цвет рамки.
margin: 24px;отступ снаружи, между этой коробкой и соседями.

Частые ошибки

  • Путать padding и margin. Запомни: padding — внутри, margin — снаружи.

Попробуй сам

Сделай блок .note: padding 20px, серая пунктирная рамка 1px и скругление 12px.

Показать ответ 
.note {
  padding: 20px;
  border: 1px dashed grey;
  border-radius: 12px;
}
05 / 08

Flexbox

Flexbox ставит элементы в ряд (или в колонку) и распределяет их. Идеально для меню и шапок.

.menu {
  display: flex;
  justify-content: space-between; /* вдоль ряда */
  align-items: center;            /* поперёк ряда */
  gap: 16px;
}

Flexbox выстраивает дочерние элементы в одну линию. Ставишь display: flex родителю — и дети выстраиваются в ряд.

justify-content двигает элементы вдоль линии (в начало, по центру, равномерно), align-items — поперёк (вверх, по центру, вниз). gap — промежуток между элементами. flex-direction: column превращает ряд в колонку.

Разбор кода

display: flex;включить flexbox для детей этого элемента.
justify-content: space-between;первый в начале, последний в конце, остальные равномерно.
align-items: center;выровнять по центру по вертикали.
gap: 16px;16px между элементами.

Частые ошибки

  • Ставить display: flex детям вместо родителя.

Попробуй сам

Поставь один элемент ровно по центру .box с помощью flexbox.

Показать ответ 
.box {
  display: flex;
  justify-content: center;
  align-items: center;
}

Grid

Grid раскладывает элементы по строкам и колонкам. 1fr — «одна равная часть», так что здесь 3 одинаковые колонки.

.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}

Grid — для двух измерений: строки и колонки сразу, как таблица для раскладки. Описываешь колонки у родителя, и дети заполняют клетки по порядку.

repeat(3, 1fr) — три равные колонки. 200px 1fr — фиксированная боковая колонка и всё остальное место. gap работает и здесь.

Разбор кода

display: grid;включить grid.
grid-template-columns: repeat(3, 1fr);три колонки одинаковой ширины.
gap: 12px;промежуток между клетками.

Частые ошибки

  • Использовать grid для одного ряда кнопок — для одной линии проще flexbox.

Попробуй сам

Сделай раскладку: боковая колонка 250px и основная часть на всё остальное место.

Показать ответ 
.layout {
  display: grid;
  grid-template-columns: 250px 1fr;
}

Анимации

transition делает изменение плавным. @keyframes описывает анимацию по шагам. Так работает мигающий курсор на этом сайте.

.button {
  transition: transform 0.2s;
}
.button:hover {
  transform: scale(1.1);
}

.cursor {
  animation: blink 1s infinite;
}
@keyframes blink {
  50% { opacity: 0; }
}

transition анимирует переход между двумя состояниями, например при наведении. Указываешь, какое свойство и как долго: transition: transform 0.2s.

@keyframes описывает полную анимацию по процентам времени. Потом animation: имя 1s infinite её проигрывает: имя, длительность и сколько раз.

Разбор кода

transition: transform 0.2s;изменения transform длятся 0.2 секунды.
transform: scale(1.1);увеличить элемент на 10%.
@keyframes blink { 50% { opacity: 0; } }на середине времени элемент невидим.
animation: blink 1s infinite;проигрывать blink по 1 секунде, бесконечно.

Частые ошибки

  • Разные имена в @keyframes и animation — ничего не двигается.

Попробуй сам

Сделай так, чтобы .card плавно поднималась на 4px при наведении.

Показать ответ 
.card {
  transition: transform 0.2s;
}
.card:hover {
  transform: translateY(-4px);
}

Телефоны

@media применяет стили только на некоторых экранах. Здесь галерея на узких телефонах становится одной колонкой.

@media (max-width: 600px) {
  .gallery {
    grid-template-columns: 1fr;
  }
}

Большинство посетителей сидят с телефонов, поэтому сайт должен работать на узких экранах. @media применяет правила только при условии — обычно это ширина экрана.

Чтобы это работало, в head нужна строка <meta name="viewport" content="width=device-width, initial-scale=1">. Без неё телефон притворяется широким и уменьшает страницу.

Разбор кода

@media (max-width: 600px) {правила внутри работают только на экранах до 600px.
grid-template-columns: 1fr;одна колонка вместо трёх.

Частые ошибки

  • Забыть meta viewport — медиа-запросы как будто не работают на телефоне.

Попробуй сам

Спрячь .sidebar на экранах уже 700px.

Показать ответ 
@media (max-width: 700px) {
  .sidebar {
    display: none;
  }
}

Тест

5 вопросов. Выбери ответ — сразу увидишь, верно ли.

1. Какой селектор выбирает элементы с class="card"?

Точка — класс, # — id.

2. Какое свойство — отступ ВНУТРИ рамки?

padding — внутри, margin — снаружи.

3. Что это сделает?

.box {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

1fr — одна равная часть, повторённая 3 раза: три одинаковые колонки.

4. Какое свойство меняет цвет текста?

color — цвет текста, background — цвет фона.

5. Когда сработают эти стили?

@media (max-width: 600px) {
  .menu { display: none; }
}

max-width: 600px значит «до 600 пикселей в ширину» — это телефоны.
