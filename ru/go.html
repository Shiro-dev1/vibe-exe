Привет, мир

Каждая программа на Go начинается с package main, подключает нужное и выполняет func main(). fmt.Println выводит строку.

package main

import "fmt"

func main() {
	fmt.Println("Hello, world!")
}
Вывод
Hello, world!

package main говорит «это программа, которую можно запустить». import "fmt" подключает пакет для форматированного вывода. Заметь: в Go в конце строк нет точек с запятой — компилятор ставит их сам.

Запуск: go run main.go, а в браузере можно попробовать на go.dev/play.

Разбор кода

package mainэтот файл — запускаемая программа.
import "fmt"подключить пакет fmt.
func main() {программа начинается здесь.
fmt.Println("Hello, world!")вывести текст и перенос строки.

Частые ошибки

  • Перенести открывающую скобку на новую строку: func main()\n{ — в Go это ошибка.
  • Подключить пакет и не использовать его — Go не скомпилирует: imported and not used.

Попробуй сам

Выведи своё имя, а на следующей строке 2026.

Показать ответ 
package main

import "fmt"

func main() {
	fmt.Println("Shiro")
	fmt.Println(2026)
}
Вывод
Shiro
2026

Переменные

:= создаёт переменную и угадывает её тип. var создаёт переменную с явным типом. Дальше короткие примеры пишутся внутри func main().

name := "Shiro"
var age int = 18
age = age + 1
fmt.Println("Hi, I'm", name, "and I'm", age)
Вывод
Hi, I'm Shiro and I'm 19

:= используют только в первый раз, когда переменная создаётся. Чтобы потом изменить её, пиши обычное =.

fmt.Println ставит пробел между значениями. Для шаблона, как в других языках, есть fmt.Printf("%s is %d\n", name, age): %s — текст, %d — целое число.

Разбор кода

name := "Shiro"создать name; Go видит текст и делает string.
var age int = 18создать age с типом int.
age = age + 1изменить через = (не :=).

Частые ошибки

  • Переменная создана, но не используется — Go остановится с ошибкой declared and not used. Используй её или удали.
  • := дважды для одного имени в одном блоке — no new variables on left side of :=.

Попробуй сам

Создай city := "Kyiv" и year := 2020 и выведи: I live in Kyiv since 2020.

Показать ответ 
city := "Kyiv"
year := 2020
fmt.Printf("I live in %s since %d\n", city, year)
Вывод
I live in Kyiv since 2020

Типы данных

Основные типы: int, float64, bool, string. %T в Printf показывает тип, len() — длину.

count := 10        // int
price := 9.99      // float64
online := true     // bool
title := "VIBE"    // string
fmt.Println(len(title))
fmt.Printf("%T %T %T\n", count, price, online)
Вывод
4
int float64 bool

Go никогда не меняет типы сам: count + price (int + float64) — ошибка. Преобразуй сам: float64(count) + price.

Текст в число: strconv.Atoi("5") из пакета strconv. Она возвращает две вещи — число и ошибку; такой стиль в Go повсюду.

Разбор кода

price := 9.99дробные числа — это float64.
len(title)длина строки.
fmt.Printf("%T ...", ...)%T выводит тип каждого значения.

Частые ошибки

  • Смешивать int и float64 в одном выражении — mismatched types.

Попробуй сам

Есть a := 7 и b := 2.5. Выведи их сумму (9.5).

Показать ответ 
a := 7
b := 2.5
fmt.Println(float64(a) + b)
Вывод
9.5

Условия

if без скобок вокруг условия, но с фигурными скобками. else должен стоять на той же строке, что и закрывающая скобка.

age := 18

if age >= 18 {
	fmt.Println("Adult")
} else if age >= 13 {
	fmt.Println("Teen")
} else {
	fmt.Println("Kid")
}
Вывод
Adult

if в Go может начинаться с короткой команды: if n := len(s); n > 3 { ... } — n существует только внутри if. Так часто проверяют ошибки: if err != nil { ... }.

Есть и switch, и в Go ему не нужен break.

Разбор кода

if age >= 18 {скобки не нужны.
} else if age >= 13 {else на той же строке, что и }.

Частые ошибки

  • } на одной строке, а else на следующей — синтаксическая ошибка.

Попробуй сам

t := 30. Выведи "Hot", если t > 25, иначе "OK".

Показать ответ 
t := 30
if t > 25 {
	fmt.Println("Hot")
} else {
	fmt.Println("OK")
}
Вывод
Hot

Циклы

В Go только один цикл — for. С тремя частями это счётчик, только с условием он работает как while.

for i := 0; i < 3; i++ {
	fmt.Println("Step", i)
}

count := 3
for count > 0 {
	fmt.Println(count)
	count--
}
Вывод
Step 0
Step 1
Step 2
3
2
1

Одно слово для всех циклов делает Go простым. for { } без всего — бесконечный цикл, его останавливают через break.

Чтобы пройти по списку или тексту, используют for i, value := range list — это будет в уроке про срезы.

Разбор кода

for i := 0; i < 3; i++ {цикл-счётчик, без скобок.
for count > 0 {это while в Go.

Частые ошибки

  • Писать while — такого слова в Go нет, используй for.

Попробуй сам

Выведи числа от 1 до 5.

Показать ответ 
for i := 1; i <= 5; i++ {
	fmt.Println(i)
}
Вывод

Функции

func создаёт функцию. Типы пишут после имён. Функция в Go может вернуть сразу несколько значений.

package main

import "fmt"

func divide(a, b int) (int, int) {
	return a / b, a % b
}

func main() {
	q, r := divide(17, 5)
	fmt.Println(q, r)
}
Вывод
3 2

(a, b int) значит, что и a, и b — int. (int, int) после скобок — два результата. Здесь: 17 / 5 = 3 и остаток 17 % 5 = 2.

Многие функции в Go возвращают результат и ошибку: n, err := strconv.Atoi("42"). Если значение не нужно, пиши _: q, _ := divide(17, 5).

Разбор кода

func divide(a, b int) (int, int) {на входе два int, на выходе два int.
return a / b, a % bчастное и остаток.
q, r := divide(17, 5)забрать оба результата.

Частые ошибки

  • Забрать одно значение у функции, которая возвращает два: q := divide(17, 5) — ошибка.

Попробуй сам

Напиши func square(n int) int и выведи square(7).

Показать ответ

	return n * n

	fmt.Println(square(7))
}
Вывод

Срезы

Срез (slice) — список в Go, который может расти. append добавляет элементы, len считает их, range проходит по ним.

langs := []string{"Go", "Rust", "C"}
langs = append(langs, "Java")
fmt.Println(len(langs))

for i, lang := range langs {
	fmt.Println(i, lang)
}
Вывод
4
0 Go
1 Rust
2 C
3 Java

[]string — «срез строк». append возвращает новый срез, поэтому всегда пишут langs = append(langs, ...).

range даёт две вещи: индекс и значение. Если нужно только значение, пиши for _, lang := range langs. Есть в Go и словари: ages := map[string]int{"Shiro": 18}.

Разбор кода

[]string{"Go", "Rust", "C"}срез из трёх строк.
langs = append(langs, "Java")добавить один и сохранить результат.
for i, lang := range langs {i — номер, lang — значение.

Частые ошибки

  • append(langs, "Java") без langs = — результат теряется (и Go сообщит об этом).

Попробуй сам

Создай []int{1, 2, 3}, добавь 4 и выведи сумму с помощью цикла range.

Показать ответ 
nums := []int{1, 2, 3}
nums = append(nums, 4)
sum := 0
for _, n := range nums {
	sum += n
}
fmt.Println(sum)
Вывод
10

Мини-проект: герой игры

Классов в Go нет. struct хранит данные, а методы прикрепляют к ней через получателя: func (p *Player) Hit(...).

package main

import "fmt"

type Player struct {
	Name string
	HP   int
}

func (p *Player) Hit(damage int) {
	p.HP -= damage
	fmt.Printf("%s has %d HP\n", p.Name, p.HP)
}

func main() {
	p := Player{Name: "Shiro", HP: 100}
	p.Hit(30)
	p.Hit(25)
}
Вывод
Shiro has 70 HP
Shiro has 45 HP

*Player (со звёздочкой) значит, что метод получает указатель на настоящего игрока и может его менять. Без звёздочки он получил бы копию, и HP снаружи не изменился бы.

Имена с большой буквы (Name, Hit) видны из других пакетов — так Go помечает публичные вещи.

Разбор кода

type Player struct { ... }что есть у каждого игрока.
func (p *Player) Hit(damage int)метод Player, который может его менять.
p := Player{Name: "Shiro", HP: 100}создать игрока.

Частые ошибки

  • Написать func (p Player) Hit без * — HP меняется только в копии.

Попробуй сам

Добавь метод Heal(amount int) и вылечи игрока на 10 после ударов.

Показать ответ 
package main

import "fmt"

type Player struct {
	Name string
	HP   int
}

func (p *Player) Hit(damage int) {
	p.HP -= damage
	fmt.Printf("%s has %d HP\n", p.Name, p.HP)
}

func (p *Player) Heal(amount int) {
	p.HP += amount
	fmt.Printf("%s has %d HP\n", p.Name, p.HP)
}

func main() {
	p := Player{Name: "Shiro", HP: 100}
	p.Hit(30)
	p.Hit(25)
	p.Heal(10)
}
Вывод
Shiro has 70 HP
Shiro has 45 HP
Shiro has 55 HP

Тест

5 вопросов. Выбери ответ — сразу увидишь, верно ли.

1. Сколько видов циклов в Go?

В Go только for; он же работает как while.

2. Что выведет этот код?

x := 17
fmt.Println(x % 5)

% — остаток от деления: 17 = 5 * 3 + 2.

3. Что будет, если создать переменную и не использовать её?

Go не скомпилирует: declared and not used.

4. Что выведет этот код?

s := []int{1, 2}
s = append(s, 3)
fmt.Println(len(s))

append добавил один элемент.

5. Какой знак создаёт новую переменную и угадывает её тип?

:= создаёт; = только меняет существующую переменную.
