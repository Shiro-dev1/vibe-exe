Привет, мир

console.log() выводит текст в консоль браузера. В Chrome её можно открыть клавишами Ctrl + Shift + J и писать код прямо там. А здесь можно просто нажать Запустить.

Вывод
Hello, world!

JavaScript создали для веб-страниц, и он работает в любом браузере. console.log() пишет сообщение в консоль — скрытую панель для разработчиков. Программисты постоянно пользуются ею, чтобы проверить, что делает код.

Каждая команда обычно заканчивается точкой с запятой ;. JavaScript часто прощает, если её нет, но писать её — хорошая привычка.

Разбор кода

consoleконсоль браузера — объект с полезными командами.
.log(...)команда «записать в журнал». Точка значит «взять log у console».
"Hello, world!"текст в кавычках, он называется строкой.

Частые ошибки

  • Писать console.Log — регистр важен, нужно log.

Попробуй сам

Выведи своё имя, а на следующей строке число 2026.

Показать ответ 
console.log("Shiro");
console.log(2026);
Вывод
Shiro
2026

Переменные

let создаёт переменную, которую можно менять, const — которую нельзя. В обратных кавычках ` ` переменные вставляются через ${ }.

Вывод
Shiro 19
Hi, I'm Shiro

По умолчанию используй const — для значений, которые не будут меняться. let — когда значение должно меняться, например счётчик. В старом коде встречается var; сейчас его лучше не использовать.

Шаблонные строки в обратных кавычках `...` могут содержать ${...}: всё внутри вычисляется и вставляется в текст.

Разбор кода

const name = "Shiro";константа: name потом нельзя присвоить новое значение.
let age = 18;переменная, которую можно менять.
age = age + 1;берём старое значение, прибавляем 1, сохраняем. Теперь age = 19.
`Hi, I'm ${name}`обратные кавычки + ${} вставляют значение name в текст.

Частые ошибки

  • Менять const: TypeError: Assignment to constant variable. Используй let.
  • Писать ${} в обычных кавычках — это работает только в обратных.

Попробуй сам

Создай let score = 0, дважды прибавь 10 и выведи "Score: 20" через шаблонную строку.

Показать ответ 
let score = 0;
score += 10;
score += 10;
console.log(`Score: ${score}`);
Вывод
Score: 20

Типы данных

// начинает комментарий. typeof показывает тип значения.

Вывод
number
string

В JavaScript несколько основных типов: number (любые числа — целые и дробные), string (текст), boolean (true/false), а ещё null и undefined для «нет значения».

JavaScript старается помочь и сам меняет типы, иногда неожиданно: "5" + 2 даёт "52" (текст), а "5" * 2 даёт 10. Чтобы специально превратить текст в число, используй Number("5").

Разбор кода

let count = 10;number — целые и дробные числа здесь один тип.
let nothing = null;null: мы сами решили, что здесь ничего нет.
let user;значение не задано, поэтому undefined.
typeof countвозвращает название типа текстом: "number".

Частые ошибки

  • Сложить числа из полей ввода и получить "12" вместо 3 — они были текстом. Преобразуй через Number().

Попробуй сам

Есть a = "7" (текст). Выведи a + 3 так, чтобы получилось 10.

Показать ответ 
const a = "7";
console.log(Number(a) + 3);
Вывод
10

Условия

if выполняет код, только если условие в скобках верно. Блоки кода пишутся внутри { }.

Вывод
Adult

if проверяет условие в скобках. Если оно верно, выполняется блок в { }. else if проверяет следующее условие, else ловит всё остальное.

В JavaScript сравнивают тремя знаками равенства === (и !== для «не равно»). Два знака == меняют типы и могут дать странный результат: например, "5" == 5 — это true.

Разбор кода

if (age >= 18) {условие в круглых скобках, код — в фигурных.
} else if (age >= 13) {следующая проверка, только если первая не прошла.
} else {всё остальное.

Частые ошибки

  • Писать = в if: if (age = 18) присваивает 18 вместо сравнения.

Попробуй сам

const t = 30. Выведи "Hot", если t больше 25, иначе "OK".

Показать ответ 
const t = 30;
if (t > 25) {
  console.log("Hot");
} else {
  console.log("OK");
}
Вывод
Hot

Циклы

У for три части: начало, условие, шаг. i++ прибавляет 1, count-- отнимает 1.

Вывод
Step 0
Step 1
Step 2
3
2
1

У классического цикла for три части через ;: начало (let i = 0), условие продолжения (i < 3) и шаг после каждого круга (i++).

while проще: повторяет, пока условие верно. Для массивов есть ещё for (const item of array), он проходит по каждому элементу.

Разбор кода

for (let i = 0; i < 3; i++)i начинается с 0, цикл идёт, пока i < 3, после каждого круга i растёт на 1.
while (count > 0)повторять, пока count больше 0.
count--;отнять 1, иначе цикл не закончится.

Частые ошибки

  • Писать запятые вместо точек с запятой в for: for (let i = 0, i < 3, i++).

Попробуй сам

Выведи числа от 1 до 5.

Показать ответ 
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
Вывод
1
2
3
4
5

Функции

Функция — это код с названием, который можно запускать много раз. Стрелка => — короткий способ записать функцию.

Вывод
Hello, Shiro!
VIBE

Функция объединяет код под одним именем. Параметры в скобках — это входные данные, return — результат. Без return функция вернёт undefined.

Стрелочные функции (x) => x * 2 — короткая запись. Если тело — одно выражение, его результат возвращается сам.

Разбор кода

function greet(name) {функция greet с параметром name.
return "Hello, " + name + "!";собираем текст и возвращаем его.
const shout = (text) => text.toUpperCase();стрелочная функция: берёт текст и возвращает его заглавными буквами.

Частые ошибки

  • Забыть скобки при вызове: greet вместо greet("Shiro") — функция не выполнится.

Попробуй сам

Напиши стрелочную функцию square, которая возвращает n * n. Выведи square(7).

Показать ответ 
const square = (n) => n * n;
console.log(square(7));
Вывод
49

Массивы

Массив хранит много значений по порядку. Счёт идёт с 0. push добавляет элемент в конец, length — сколько их.

Вывод
Python
4
I like Python
I like JavaScript
I like C
I like Rust

Массив — упорядоченный список значений. До элемента добираются по индексу (номеру), начиная с 0. Массивы могут расти и уменьшаться.

Удобные методы: push добавляет в конец, pop убирает последний элемент, includes(x) проверяет, есть ли x внутри, forEach вызывает функцию для каждого элемента.

Разбор кода

const langs = [...]массив в квадратных скобках. const запрещает заменить переменную, но не содержимое.
langs.push("Rust");добавить в конец.
langs.lengthсколько всего элементов.
langs.forEach((lang) => ...)выполнить стрелочную функцию для каждого элемента.

Частые ошибки

  • Брать langs.length как последний индекс — последний элемент это langs[langs.length - 1].

Попробуй сам

Создай массив из 3 чисел, добавь ещё одно через push и выведи, сколько стало элементов.

Показать ответ 
const nums = [1, 2, 3];
nums.push(4);
console.log(nums.length);
Вывод
4

Мини-проект: счётчик кликов

JavaScript умеет менять страницу. Эта кнопка считает клики: нажми «Запустить» и покликай по ней.

Вывод
[ Clicks: 0 ]  -> клик ->  [ Clicks: 1 ]  -> клик ->  [ Clicks: 2 ]

Здесь JavaScript показывает свою силу: он меняет страницу прямо у тебя на глазах. document — это вся страница; getElementById находит элемент с нужным id.

addEventListener("click", ...) говорит: «когда кликнут — выполни эту функцию». Функция прибавляет 1 к счётчику и пишет новый текст в кнопку.

Разбор кода

<button id="btn">HTML-кнопка с id btn, чтобы JavaScript мог её найти.
document.getElementById("btn")найти эту кнопку на странице.
btn.addEventListener("click", ...)слушать клики по кнопке.
btn.textContent = ...заменить текст внутри кнопки.

Частые ошибки

  • Запускать скрипт до того, как появилась кнопка, — тогда getElementById вернёт null. Ставь скрипт после HTML.

Попробуй сам

Измени счётчик так, чтобы каждый клик прибавлял 5, а не 1. Проверь кнопкой «Запустить».

Показать ответ 
<button id="btn">Clicks: 0</button>

<script>
  const btn = document.getElementById("btn");
  let clicks = 0;

  btn.addEventListener("click", () => {
    clicks += 5;
    btn.textContent = "Clicks: " + clicks;
  });
</script>

Тест

5 вопросов. Выбери ответ — сразу увидишь, верно ли.

1. Что выведет этот код?

let x = 5;
x = x + 2;
console.log(x);

x было 5, потом прибавили 2, стало 7.

2. Что выведет этот код?

console.log("5" + 2);

"5" — это текст, поэтому + приклеивает 2, а не складывает.

3. Какое слово создаёт переменную, которую нельзя менять?

const — константа: её нельзя присвоить заново.

4. Что выведет этот код?

const a = [10, 20, 30];
console.log(a.length);

length — сколько элементов в массиве: 3.

5. Что выведет этот код?

const shout = (t) => t.toUpperCase();
console.log(shout("hi"));

toUpperCase() делает все буквы заглавными.
