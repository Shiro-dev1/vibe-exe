Как это работает

  1. Выбери язык

    Двенадцать языков: от Python и JavaScript до Java и Go. Каждый начинается с Hello, world.

  2. Читай и пробуй

    Каждый урок объясняет идею, разбирает код по строчкам, показывает частые ошибки и даёт задание.

  3. Проверь себя

    Отмечай пройденные уроки и пройди тест из 5 вопросов. Прогресс виден на каждой карточке.
