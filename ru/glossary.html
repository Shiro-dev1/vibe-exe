Словарь

Главные слова программирования простыми словами. Не понял слово в уроке — ищи здесь.

Баг Bug

Ошибка в программе, из-за которой она работает не так, как задумано.

Слово пошло от настоящего жука, которого в 1947 году нашли внутри компьютера.

База данных Database

Упорядоченное хранилище данных, где их легко искать, добавлять и менять: пользователи, заказы, сообщения.

Огромная картотека, где всё разложено по полочкам.

Библиотека Library

Готовый код, написанный другими людьми, который можно использовать в своей программе.

Набор готовых деталей LEGO вместо того, чтобы вырезать каждый кубик самому.
import random
В уроках: Python

Браузер Browser

Программа, которая открывает сайты: Chrome, Firefox, Safari. Она же выполняет JavaScript.

Окно в интернет.
В уроках: JavaScript, HTML

Булево значение Boolean

Значение, которое может быть только true (правда) или false (ложь). С ним работают условия.

Как выключатель: либо включено, либо выключено, третьего нет.
online = True
В уроках: Python, Java, C#

Бэкенд Backend

Часть, которая работает на сервере: данные, аккаунты, оплата.

Склад и офис за магазином.
В уроках: PHP, Go, Java

Возвращаемое значение Return value

Результат, который функция отдаёт обратно через return.

Готовый кофе, который отдаёт кофемашина.
return a + b
В уроках: Python, Rust

Домен Domain

Имя сайта в адресной строке, например github.io.

Адрес дома, только для сайта.

Интерпретатор Interpreter

Программа, которая читает код и выполняет его строку за строкой, без отдельной компиляции.

Синхронный переводчик, который переводит речь фразу за фразой.
В уроках: Python, JavaScript, PHP

Класс Class

Чертёж для объектов. Описывает, что есть у каждого такого объекта и что он умеет.

Формочка для печенья: одна форма — много печенек.
class Player:
В уроках: C++, C#, Java

Клиент Client

Сторона, которая что-то просит у сервера, — обычно твой браузер или приложение.

Гость в ресторане, который делает заказ.

Комментарий Comment

Заметка в коде для людей. Компьютер её пропускает.

Стикер на рецепте: «в следующий раз меньше соли».
# this is a comment
В уроках: Python, C

Коммит Commit

Один сохранённый шаг в Git с короткой заметкой, что изменилось.

Фотография твоей работы в один момент.

Компилятор Compiler

Программа, которая ещё до запуска переводит твой код на язык, понятный компьютеру, и заодно находит ошибки.

Переводчик, который переводит всю книгу целиком, прежде чем её прочитают.
В уроках: C, C++, Rust, Go, Java

Консоль Console

Текстовое окно, куда программа выводит сообщения и ошибки.

Дневник программы: она записывает туда, что делает.
console.log("hi")
В уроках: JavaScript

Массив / список Array / list

Много значений по порядку в одной переменной. Счёт идёт с 0.

Как полка с номерами: ячейка 0, ячейка 1, ячейка 2…
langs = ["Python", "Go"]
В уроках: Python, JavaScript, Go

Метод Method

Функция, которая принадлежит объекту или классу.

Кнопка «прыжок» у игрока — действие именно этого игрока.
player.hit(30)
В уроках: Java, C#, Go

Объект Object

Вещь в программе, которая хранит вместе данные (поля) и действия (методы).

Игрок в игре: у него есть имя и здоровье, и он умеет прыгать и бить.
В уроках: JavaScript, TypeScript

Открытый код Open source

Код, который любой может бесплатно читать, использовать и улучшать.

Рецепт, который выложили для всех: готовь и улучшай.

Отладка Debugging

Поиск и исправление багов: читаешь ошибки, выводишь значения, проверяешь по шагам.

Как работа детектива, который ищет улики.

Параметр Parameter

Значение, которое передают функции, чтобы она сделала работу. Пишется в скобках.

Как сказать бариста «большой, без сахара» — детали заказа.
greet("Shiro")
В уроках: Python, TypeScript

Переменная Variable

Коробка с названием, в которой лежит значение: число, текст, список. Его можно достать по имени или заменить.

Как подпись на банке: «сахар». Содержимое можно поменять, а подпись остаётся.
age = 18
В уроках: Python, JavaScript, C

Репозиторий Repository

Папка проекта, за которой следит Git, обычно на GitHub.

Дом проекта со всей его историей внутри.

Сервер Server

Компьютер, который всегда включён и отвечает на запросы: отдаёт страницы, хранит данные.

Кухня, которая принимает заказы и готовит.
В уроках: PHP, Go

Синтаксис Syntax

Правила написания в языке: где ставить скобки, двоеточия и кавычки.

Как грамматика и знаки препинания в обычном языке.

Строка String

Текст в программе. Его пишут в кавычках.

Как бусы из букв: каждая буква — бусина.
"Hello, world!"
В уроках: Python, JavaScript

Терминал Terminal

Окно, где компьютером управляют текстовыми командами вместо мышки.

Разговор с компьютером текстом вместо кликов.
ls -la

Тип данных Data type

Какого рода значение: целое число, дробное, текст, true/false. От типа зависит, что с ним можно делать.

Числа можно складывать, а слова — нет: «кот» плюс 5 не сложишь.
В уроках: Python, TypeScript, Java

Условие Condition

Проверка, от которой зависит, какой код выполнится: если верно — делаем одно, иначе — другое.

«Если идёт дождь — бери зонт, иначе — очки».
if age >= 18:
    print("Adult")
В уроках: Python, JavaScript, Go

Фреймворк Framework

Большой набор готового кода и правил для определённых программ, например сайтов или игр.

Готовый дом-конструктор: стены и комнаты уже есть, ты добавляешь остальное.

Фронтенд Frontend

Часть приложения, которую видят и нажимают люди: страница в браузере.

Витрина и торговый зал магазина.
В уроках: HTML, CSS, JavaScript

Функция Function

Кусок кода с названием, который делает одну задачу. Пишешь один раз — вызываешь сколько угодно.

Как кнопка на кофемашине: нажал «латте» — получил латте, не думая, как он готовится.
def greet(name):
    return "Hello, " + name
В уроках: Python, JavaScript, Rust

Хостинг Hosting

Сервис, который держит твой сайт на сервере, чтобы его можно было открыть в интернете. Этот сайт на GitHub Pages.

Аренда места под магазин на людной улице.

Цикл Loop

Повторение одного и того же кода несколько раз или пока условие верно.

Как «сделай 10 приседаний»: одно движение повторяется 10 раз.
for i in range(10):
В уроках: Python, C, Go

API

Способ, которым одна программа просит другую что-то сделать или дать данные. Например, бот спрашивает у Telegram новые сообщения.

Меню в кафе: ты не идёшь на кухню, а заказываешь по меню — и получаешь блюдо.

CSS

Язык, который говорит, как выглядит страница: цвета, шрифты, расположение, анимации.

Покраска и мебель в доме.
h1 { color: white; }
В уроках: CSS

Git

Программа, которая запоминает каждую версию кода, чтобы можно было вернуться назад и работать вместе.

«Сохранения» в игре, только для кода.
git commit -m "fix"

HTML

Язык разметки, который говорит, что есть на странице: заголовки, текст, ссылки, картинки.

Каркас дома.
<h1>Hello</h1>
В уроках: HTML
