Привет, мир

C++ — это C с кучей дополнений. std::cout << отправляет текст на экран, std::endl заканчивает строку.

#include <iostream>

int main() {
    std::cout << "Hello, world!" << std::endl;
    return 0;
}
Вывод
Hello, world!

C++ вырос из C, поэтому многое знакомо, но у него большая стандартная библиотека. #include <iostream> подключает её часть для ввода и вывода. std:: значит «из стандартной библиотеки».

std::cout — это экран («вывод символов»), а << отправляет в него значения одно за другим.

Разбор кода

#include <iostream>подключить ввод и вывод.
std::cout << "Hello, world!"отправить текст на экран.
<< std::endl;закончить строку.

Частые ошибки

  • Писать cout без std:: — компилятор его не знает. (В некотором коде пишут using namespace std;, чтобы не повторять.)

Попробуй сам

Выведи своё имя, а на следующей строке 2026.

Показать ответ 
#include <iostream>

int main() {
    std::cout << "Shiro" << "\n";
    std::cout << 2026 << "\n";
}
Вывод
Shiro
2026

Переменные

Как и в C, у каждой переменной есть тип. std::string хранит текст. Через << можно выводить много значений подряд.

#include <iostream>
#include <string>

int main() {
    std::string name = "Shiro";
    int age = 18;
    std::cout << "Hi, I'm " << name << " and I'm " << age << "\n";
}
Вывод
Hi, I'm Shiro and I'm 18

Переменные в C++ имеют типы, как в C. Большой помощник — std::string: настоящий текст, который знает свою длину, склеивается через + и сравнивается через ==.

"\n" и std::endl оба заканчивают строку; "\n" чуть быстрее.

Разбор кода

#include <string>подключить std::string.
std::string name = "Shiro";текстовая переменная.
std::cout << "Hi, I'm " << name << ...несколько значений в одной строке подряд.

Частые ошибки

  • Использовать std::string без #include <string> — иногда работает случайно, иногда нет. Всегда подключай.

Попробуй сам

Создай std::string city = "Kyiv" и int year = 2020, выведи: I live in Kyiv since 2020.

Показать ответ 
std::string city = "Kyiv";
int year = 2020;
std::cout << "I live in " << city << " since " << year << "\n";
Вывод
I live in Kyiv since 2020

Типы данных

auto позволяет компилятору самому выбрать тип. Дальше короткие примеры пишутся внутри main.

int count = 10;              // целое число
double price = 9.99;         // дробное число
bool online = true;          // true или false
char letter = 'S';           // один символ
std::string title = "VIBE";  // текст
auto half = 3.5;             // компилятор выберет double

std::cout << title.length() << "\n";
Вывод
4

Основные типы: int, double, bool (true/false), char, std::string. auto позволяет компилятору самому понять тип по значению — удобно для длинных названий типов.

Текст в число: std::stoi("5"), число в текст: std::to_string(5).

Разбор кода

bool online = true;true или false.
auto half = 3.5;компилятор видит 3.5 и делает double.
title.length()сколько символов в тексте.

Частые ошибки

  • auto x; без значения — компилятор не сможет угадать тип.

Попробуй сам

Есть std::string a = "7". Выведи a как число плюс 3 (10).

Показать ответ 
std::string a = "7";
std::cout << std::stoi(a) + 3 << "\n";
Вывод
10

Условия

if выполняет код, только если условие в скобках верно.

int age = 18;

if (age >= 18) {
    std::cout << "Adult\n";
} else if (age >= 13) {
    std::cout << "Teen\n";
} else {
    std::cout << "Kid\n";
}
Вывод
Adult

Условия в C++ такие же, как в C, но есть настоящий тип bool. Вместо &&, ||, ! можно писать and, or, not, хотя чаще пишут символы.

Для множества фиксированных вариантов есть switch, но чаще хватает if / else if.

Разбор кода

if (age >= 18) {условие в скобках.
std::cout << "Adult\n";выполняется, только если условие верно.

Частые ошибки

  • Точка с запятой сразу после if: if (x > 5); — тогда блок ниже выполнится всегда.

Попробуй сам

int t = 30. Выведи "Hot", если t > 25, иначе "OK".

Показать ответ 
int t = 30;
if (t > 25) {
    std::cout << "Hot\n";
} else {
    std::cout << "OK\n";
}
Вывод
Hot

Циклы

У for три части: начало, условие, шаг. while повторяет, пока условие верно.

for (int i = 0; i < 3; i++) {
    std::cout << "Step " << i << "\n";
}

int count = 3;
while (count > 0) {
    std::cout << count << "\n";
    count--;
}
Вывод
Step 0
Step 1
Step 2
3
2
1

for и while работают как в C. В C++ есть ещё for по диапазону: for (int x : numbers) — «для каждого x из numbers». Он короче, и с ним нельзя случайно выйти за границы.

Разбор кода

for (int i = 0; i < 3; i++)счётчик от 0 до 2.
while (count > 0)повторять, пока count больше нуля.

Частые ошибки

  • Случайно менять счётчик внутри for — цикл перескакивает или не заканчивается.

Попробуй сам

Выведи числа от 1 до 5.

Показать ответ 
for (int i = 1; i <= 5; i++) {
    std::cout << i << "\n";
}
Вывод
1
2
3
4
5

Функции

У функции есть тип результата, название и параметры. const std::string& значит «прочитать этот текст, не копируя его».

#include <iostream>
#include <string>

std::string greet(const std::string& name) {
    return "Hello, " + name + "!";
}

int main() {
    std::cout << greet("Shiro") << "\n";
}
Вывод
Hello, Shiro!

Функция в C++ похожа на функцию в C. Когда передаёшь большой объект, например строку, пиши const std::string&: & значит «не копируй, используй оригинал», const — «и не меняй его». Так быстрее и безопасно.

Функции могут называться одинаково, но иметь разные параметры — это называется перегрузкой.

Разбор кода

std::string greet(const std::string& name)возвращает текст, читает name без копирования.
return "Hello, " + name + "!";склеить кусочки в новую строку.

Частые ошибки

  • Забыть вернуть значение в функции не-void — результат непредсказуем.

Попробуй сам

Напиши int square(int n) и выведи square(7).

Показать ответ 
#include <iostream>

int square(int n) {
    return n * n;
}

int main() {
    std::cout << square(7) << "\n";
}
Вывод
49

Векторы

std::vector — список, который может расти. push_back добавляет элемент, size() — сколько их. for (... : langs) проходит по каждому элементу.

#include <iostream>
#include <string>
#include <vector>

int main() {
    std::vector<std::string> langs = {"Python", "C++", "Rust"};
    langs.push_back("C#");
    std::cout << langs.size() << "\n";

    for (const auto& lang : langs) {
        std::cout << "I like " << lang << "\n";
    }
}
Вывод
4
I like Python
I like C++
I like Rust
I like C#

std::vector — самый популярный контейнер в C++: массив, который сам растёт. push_back добавляет в конец, pop_back удаляет последний, size() говорит, сколько элементов, v[i] даёт элемент.

В угловых скобках указывают, что хранится: std::vector<int> — целые числа, std::vector<std::string> — текст.

Разбор кода

std::vector<std::string> langs = {...};вектор текстов из 3 элементов.
langs.push_back("C#");добавить ещё один.
for (const auto& lang : langs)пройти по каждому элементу без копирования.

Частые ошибки

  • Забыть #include <vector>.

Попробуй сам

Создай вектор {1, 2, 3}, добавь 4 и выведи сумму всех элементов.

Показать ответ 
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {1, 2, 3};
    v.push_back(4);
    int sum = 0;
    for (int x : v) sum += x;
    std::cout << sum << "\n";
}
Вывод
10

Мини-проект: герой игры

Класс объединяет данные и функции в одно целое. Так в играх описывают игроков, врагов и предметы.

#include <iostream>
#include <string>

class Player {
public:
    std::string name;
    int hp = 100;

    void hit(int damage) {
        hp -= damage;
        std::cout << name << " has " << hp << " HP\n";
    }
};

int main() {
    Player p;
    p.name = "Shiro";
    p.hit(30);
    p.hit(25);
}
Вывод
Shiro has 70 HP
Shiro has 45 HP

Класс — это чертёж, а объекты — вещи, построенные по нему. Player описывает, что есть у каждого игрока (name, hp) и что он умеет (hit). Player p; создаёт одного настоящего игрока.

public: значит, что эти части доступны снаружи класса. Идея объединять данные и действия называется объектно-ориентированным программированием.

Разбор кода

class Player {начало чертежа.
int hp = 100;каждый новый игрок начинает со 100 HP.
void hit(int damage)действие игрока; void — ничего не возвращает.
p.hit(30);вызвать действие у этого игрока.

Частые ошибки

  • Забыть ; после закрывающей скобки класса: };.

Попробуй сам

Добавь метод heal(int amount), который прибавляет HP и выводит его. Вылечи игрока на 10 после ударов.

Показать ответ 
#include <iostream>
#include <string>

class Player {
public:
    std::string name;
    int hp = 100;

    void hit(int damage) {
        hp -= damage;
        std::cout << name << " has " << hp << " HP\n";
    }
    void heal(int amount) {
        hp += amount;
        std::cout << name << " has " << hp << " HP\n";
    }
};

int main() {
    Player p;
    p.name = "Shiro";
    p.hit(30);
    p.hit(25);
    p.heal(10);
}
Вывод
Shiro has 70 HP
Shiro has 45 HP
Shiro has 55 HP

Тест

5 вопросов. Выбери ответ — сразу увидишь, верно ли.

1. Что выведет этот код?

std::string s = "VIBE";
std::cout << s.length() << "\n";

В слове "VIBE" 4 буквы.

2. Что выводит текст на экран?

cout << — вывод, cin >> — ввод.

3. Что выведет этот код?

std::vector<int> v = {1, 2};
v.push_back(3);
std::cout << v.size() << "\n";

push_back добавил ещё один элемент — их стало 3.

4. Что выведет этот код?

int hp = 100;
hp -= 30;
hp -= 25;
std::cout << hp << "\n";

100 - 30 = 70, потом 70 - 25 = 45.

5. Что объединяет данные и функции в одно целое?

У класса есть данные (name, hp) и функции (hit).
