HTML.LESSONS

HTML says what is on a page: headings, text, links, images, buttons. Save the code in a file that ends with .html and open it in the browser.

01 PAGE SKELETON 02 HEADINGS AND TEXT 03 LINKS AND IMAGES 04 LISTS 05 BUTTONS AND FORMS 06 PAGE LAYOUT
01_PAGE_SKELETON01/06

Every page starts like this. <head> holds settings and the tab title, <body> holds what you see. Tags come in pairs: <tag> opens, </tag> closes.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My first page</title>
</head>
<body>
  Hello, world!
</body>
</html>
OUTPUT
A tab called "My first page" with the text: Hello, world!
02_HEADINGS_AND_TEXT02/06

<h1> is the biggest heading, <h6> the smallest. <p> is a paragraph.

<h1>Big heading</h1>
<h2>Smaller heading</h2>
<p>A paragraph of text with <b>bold</b> and <i>italic</i> words.</p>
03_LINKS_AND_IMAGES03/06

href is where the link goes. src is the image file. alt describes the image for people who can't see it.

<a href="https://shiro-dev1.github.io">My portfolio</a>
<a href="page2.html">Go to page 2</a>

<img src="cat.jpg" alt="A sleeping cat" width="300">
04_LISTS04/06

<ul> is a list with dots, <ol> a list with numbers. Each item is <li>.

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<ol>
  <li>Learn HTML</li>
  <li>Learn CSS</li>
  <li>Build a site</li>
</ol>
OUTPUT
• HTML
• CSS

1. Learn HTML
2. Learn CSS
3. Build a site
05_BUTTONS_AND_FORMS05/06

A form collects what the user types. <label> is the caption, for links it to the field with the same id.

<form>
  <label for="name">Your name</label>
  <input id="name" type="text" placeholder="Shiro">

  <label for="email">Email</label>
  <input id="email" type="email">

  <button type="submit">Send</button>
</form>
06_PAGE_LAYOUT06/06

These tags name the parts of a page: top, main content, bottom. A link to #about jumps to the element with id="about".

<header>
  <nav><a href="#about">About</a></nav>
</header>

<main>
  <section id="about">
    <h2>About me</h2>
    <p>I build websites.</p>
  </section>
</main>

<footer>(c) 2026</footer>
