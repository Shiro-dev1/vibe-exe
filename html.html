Page skeleton

Every page starts like this. <head> holds settings and the tab title, <body> holds what you see. Tags come in pairs: <tag> opens, </tag> closes.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My first page</title>
</head>
<body>
  Hello, world!
</body>
</html>
Output
A tab called "My first page" with the text: Hello, world!

HTML is not a programming language — it describes what is on a page. It is made of tags: words in angle brackets. Most tags come in pairs and wrap content: <title>My page</title>.

<!DOCTYPE html> tells the browser "this is modern HTML". <meta charset="UTF-8"> makes any letters, including Russian, show correctly.

Line by line

<html lang="en">the root of the page; lang says which language the text is in.
<head>settings: title, encoding, links to styles. Not shown on the page.
<title>the text on the browser tab.
<body>everything the visitor sees.

Common mistakes

  • Forgetting to close a tag: <body> without </body>. Browsers often forgive it, but the page can break in strange ways.

Try it yourself

Make a page with the tab title "Shiro" and the text "My first site".

Headings and text

<h1> is the biggest heading, <h6> the smallest. <p> is a paragraph.

<h1>Big heading</h1>
<h2>Smaller heading</h2>
<p>A paragraph of text with <b>bold</b> and <i>italic</i> words.</p>

Headings make a page easy to scan. Use <h1> once per page for the main title, <h2> for sections, <h3> for smaller parts. Search engines and screen readers rely on this order.

<b> makes text bold and <i> italic. For important words there are also <strong> and <em>.

Line by line

<h1>Big heading</h1>the main title of the page.
<p>...</p>a paragraph: a block of text with space around it.
<b>bold</b>a tag inside a tag: only this word is bold.

Common mistakes

  • Choosing headings by size ("h4 looks nicer"). Pick by meaning, change the size with CSS.

Try it yourself

Make a heading "About me" and a paragraph with one bold word.

Show answer 
<h2>About me</h2>
<p>I am learning <b>HTML</b> right now.</p>
03 / 06

Links and images

href is where the link goes. src is the image file. alt describes the image for people who can't see it.

<a href="https://shiro-dev1.github.io">My portfolio</a>
<a href="page2.html">Go to page 2</a>

<img src="cat.jpg" alt="A sleeping cat" width="300">

Links connect pages: <a href="...">. The address can be another site (https://...) or a file next to yours (page2.html). Add target="_blank" to open it in a new tab.

<img> has no closing tag. src is the file, alt is the description. Set only width or only height, otherwise the picture may stretch.

Line by line

<a href="https://...">My portfolio</a>the visitor sees "My portfolio"; a click opens the address.
<img src="cat.jpg" ...>show the file cat.jpg from the same folder.
alt="A sleeping cat"text for screen readers and if the picture doesn't load.

Common mistakes

  • A wrong file name or folder in src — the picture shows as a broken icon. Names are case-sensitive on servers: Cat.jpg ≠ cat.jpg.

Try it yourself

Make a link to github.com that opens in a new tab.

Show answer 
<a href="https://github.com" target="_blank">My GitHub</a>
04 / 06

Lists

<ul> is a list with dots, <ol> a list with numbers. Each item is <li>.

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<ol>
  <li>Learn HTML</li>
  <li>Learn CSS</li>
  <li>Build a site</li>
</ol>
Output
• HTML
• CSS

1. Learn HTML
2. Learn CSS
3. Build a site

Lists are everywhere: menus, steps of a recipe, features of a product. A list is a parent tag (ul or ol) with li items inside.

Lists can be nested: put a new ul inside an li to make a sub-list. Most site menus are actually lists styled with CSS.

Line by line

<ul>unordered list: dots.
<ol>ordered list: numbers appear automatically.
<li>...</li>one item of the list.

Common mistakes

  • Putting text straight into ul without li — every item must be inside <li>.

Try it yourself

Make a numbered list of 3 things you want to learn.

Show answer 
<ol>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ol>

Buttons and forms

A form collects what the user types. <label> is the caption, for links it to the field with the same id.

<form>
  <label for="name">Your name</label>
  <input id="name" type="text" placeholder="Shiro">

  <label for="email">Email</label>
  <input id="email" type="email">

  <button type="submit">Send</button>
</form>

Forms are how a site gets information from people: sign-up, search, comments. <input> is a field; its type changes how it works: text, email, password, number, checkbox.

A <label> linked with for makes the caption clickable and helps screen readers. The placeholder is a grey hint that disappears when you type.

Line by line

<label for="name">the caption for the field with id="name".
<input id="name" type="text">a one-line text field.
type="email"the browser checks that it looks like an email.
<button type="submit">the button that sends the form.

Common mistakes

  • Different values in for and id — then clicking the label does nothing.

Try it yourself

Add a password field with a label to the form.

Show answer 
<label for="pass">Password</label>
<input id="pass" type="password">

Page layout

These tags name the parts of a page: top, main content, bottom. A link to #about jumps to the element with id="about".

<header>
  <nav><a href="#about">About</a></nav>
</header>

<main>
  <section id="about">
    <h2>About me</h2>
    <p>I build websites.</p>
  </section>
</main>

<footer>(c) 2026</footer>

Semantic tags name the parts of a page: header (top), nav (menu), main (main content, one per page), section (a part with its own heading), footer (bottom).

They look the same as plain div, but they tell browsers, search engines and screen readers what each part is. That makes the site easier to use and to find.

Line by line

<header>the top of the page, usually with a logo and menu.
<nav>a block of navigation links.
<section id="about">a section; the id lets a link jump to it.
<footer>the bottom: contacts, copyright.

Common mistakes

  • Two elements with the same id. An id must be unique on a page.

Try it yourself

Add a second section "Contacts" and a link to it in the nav.

Show answer 
<nav>
  <a href="#about">About</a>
  <a href="#contacts">Contacts</a>
</nav>

<section id="contacts">
  <h2>Contacts</h2>
  <p>github.com/Shiro-dev1</p>
</section>

Quiz

5 questions. Pick an answer to see if it is right.

1. Which tag is the biggest heading?

<h1> is the biggest, <h6> the smallest.

2. Where does the visible content of a page go?

<head> holds settings, <body> holds what you see.

3. Which attribute says where a link goes?

<a ___="page2.html">Next</a>

Links use href. Images use src.

4. Which tag makes a numbered list?

<ol> is an ordered (numbered) list, <ul> has dots.

5. What is the alt attribute for?

<img src="cat.jpg" alt="A sleeping cat">

alt describes the image for people who can't see it and when it doesn't load.
