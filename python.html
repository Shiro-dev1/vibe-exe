02_VARIABLES02/08

A variable is a box with a name that stores a value. Put f before quotes and you can insert variables into text with { }.

name = "Shiro"
age = 18

print(name, age)
print(f"Hi, I'm {name} and I'm {age}")
OUTPUT
Shiro 18
Hi, I'm Shiro and I'm 18
03_DATA_TYPES03/08

Every value has a type. # starts a comment: Python ignores everything after it. type() tells you the type.

count = 10          # int: whole number
price = 9.99        # float: number with a dot
title = "VIBE.EXE"  # str: text
online = True       # bool: True or False

print(type(price))
OUTPUT
<class 'float'>
04_CONDITIONS04/08

if runs code only when something is true. elif means "else if". Spaces at the start of a line (indent) matter in Python: they show which code belongs to the if.

age = 18

if age >= 18:
    print("Adult")
elif age >= 13:
    print("Teen")
else:
    print("Kid")
OUTPUT
Adult
05_LOOPS05/08

for repeats code a set number of times. while repeats while a condition is true. range(3) gives 0, 1, 2.

for i in range(3):
    print("Step", i)

count = 3
while count > 0:
    print(count)
    count -= 1
OUTPUT
Step 0
Step 1
Step 2
3
2
1
06_FUNCTIONS06/08

A function is a piece of code with a name that you can run many times. def creates it, return gives the result back.

def greet(name):
    return "Hello, " + name + "!"

print(greet("Shiro"))
print(greet("world"))
OUTPUT
Hello, Shiro!
Hello, world!
07_LISTS07/08

A list stores many values in order. Counting starts from 0, so langs[0] is the first item. len() gives the length.

langs = ["Python", "JavaScript", "C"]
langs.append("Rust")

print(langs[0])
print(len(langs))

for lang in langs:
    print("I like", lang)
OUTPUT
Python
4
I like Python
I like JavaScript
I like C
I like Rust
08_MINI_PROJECT_GUESS_THE_NUMBER08/08

Everything together: a random number, a loop, conditions and input(), which reads what the player types. The output below is an example game.

import random

secret = random.randint(1, 10)
guess = 0

while guess != secret:
    guess = int(input("Guess a number from 1 to 10: "))
    if guess < secret:
        print("Bigger!")
    elif guess > secret:
        print("Smaller!")

print("You got it!")
OUTPUT
Guess a number from 1 to 10: 5
Bigger!
Guess a number from 1 to 10: 8
Smaller!
Guess a number from 1 to 10: 7
You got it!
