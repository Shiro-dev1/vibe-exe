Hello, world

print() shows text on the screen. Text in quotes is called a string.

print("Hello, world!")
Output
Hello, world!

A program is a list of instructions that the computer runs from top to bottom. The very first instruction most people learn is "show some text". In Python that is print().

Whatever you put inside the brackets appears on the screen. Text must be in quotes, single '...' or double "..." — both work. Numbers don't need quotes.

Line by line

printthe name of the command: "print" = show.
( ... )brackets hold what we give to the command.
"Hello, world!"the text itself. The quotes are not shown on the screen.

Common mistakes

  • Forgetting the quotes: print(Hello) — Python thinks Hello is a variable and shows an error.
  • Writing Print with a capital letter. Python cares about big and small letters.

Try it yourself

Print two lines: your name, and then the number 2026.

Show answer 
print("Shiro")
print(2026)
Output
Shiro
2026

Variables

A variable is a box with a name that stores a value. Put f before quotes and you can insert variables into text with { }.

name = "Shiro"
age = 18

print(name, age)
print(f"Hi, I'm {name} and I'm {age}")
Output
Shiro 18
Hi, I'm Shiro and I'm 18

A variable is a name for a value. Instead of writing the same value again and again, you save it once and use the name. If the value changes, you change it in one place.

The = sign means "put the value on the right into the name on the left". It is not "equals" from math. An f-string (f"...") lets you put variables right inside text.

Line by line

name = "Shiro"create a variable name and put the text Shiro in it.
age = 18a variable with a number. No quotes — it is a number, not text.
print(name, age)print can show several values; it puts a space between them.
f"... {name} ..."inside an f-string, {name} is replaced by the value of name.

Common mistakes

  • Using a variable before creating it — Python says NameError.
  • Forgetting the f before the quotes: then {name} is printed as is.

Try it yourself

Create variables city and year, then print: I live in city since year.

Show answer 
city = "Kyiv"
year = 2020
print(f"I live in {city} since {year}")
Output
I live in Kyiv since 2020

Data types

Every value has a type. # starts a comment: Python ignores everything after it. type() tells you the type.

count = 10          # int: whole number
price = 9.99        # float: number with a dot
title = "VIBE.EXE"  # str: text
online = True       # bool: True or False

print(type(price))
Output
<class 'float'>

The type tells Python what kind of value it is and what you can do with it. Numbers can be added, text can be glued together, True/False is used in conditions.

You can change the type: int("5") turns text into a number, str(5) turns a number into text. This is needed often, for example when the user types a number — Python receives it as text.

Line by line

count = 10int — a whole number.
price = 9.99float — a number with a dot. In code we always use a dot, not a comma.
online = Truebool — only True or False, always with a capital letter.
type(price)asks Python: what is the type of this value?

Common mistakes

  • "5" + 5 — you can't add text and a number. Convert first: int("5") + 5.
  • Writing true in small letters — in Python it must be True.

Try it yourself

You have a = "7" (text). Print a + 3 so the answer is 10.

Show answer 
a = "7"
print(int(a) + 3)
Output
10

Conditions

if runs code only when something is true. elif means "else if". Spaces at the start of a line (indent) matter in Python: they show which code belongs to the if.

age = 18

if age >= 18:
    print("Adult")
elif age >= 13:
    print("Teen")
else:
    print("Kid")
Output
Adult

Conditions let a program make decisions: do one thing if something is true, another thing if not. The computer checks conditions from top to bottom and runs only the first block that fits.

Comparisons: == equal, != not equal, > < >= <=. You can join them with and (both true) and or (at least one true).

Line by line

if age >= 18:if age is 18 or more… The colon at the end is required.
print("Adult")4 spaces at the start: this line belongs to the if.
elif age >= 13:checked only if the first condition was false.
else:runs when nothing above was true.

Common mistakes

  • Using = instead of == in a comparison: if age = 18 is an error.
  • Forgetting the colon or the indent — Python shows SyntaxError or IndentationError.

Try it yourself

Variable t = 30. Print "Hot" if t is more than 25, otherwise print "OK".

Show answer 
t = 30
if t > 25:
    print("Hot")
else:
    print("OK")
Output

Loops

for repeats code a set number of times. while repeats while a condition is true. range(3) gives 0, 1, 2.

for i in range(3):
    print("Step", i)

count = 3
while count > 0:
    print(count)
    count -= 1
Output
Step 0
Step 1
Step 2
3
2
1

A loop repeats code so you don't have to copy it. for is used when you know how many times to repeat or want to go through every item. while repeats while a condition stays true.

range(3) makes the numbers 0, 1, 2 — it starts from 0 and stops before 3. range(1, 4) gives 1, 2, 3.

Line by line

for i in range(3):i takes the values 0, 1, 2 one by one.
while count > 0:repeat while count is more than 0.
count -= 1the same as count = count - 1. Without it the loop would never stop.

Common mistakes

  • An endless while loop: the condition never becomes false. Always change the variable inside the loop.
  • Expecting range(5) to include 5. It stops at 4.

Try it yourself

Print the numbers from 1 to 5 using a for loop.

Show answer 
for i in range(1, 6):
    print(i)
Output
1
2
3
4
5

Functions

A function is a piece of code with a name that you can run many times. def creates it, return gives the result back.

def greet(name):
    return "Hello, " + name + "!"

print(greet("Shiro"))
print(greet("world"))
Output
Hello, Shiro!
Hello, world!

A function is a small machine: you give it values (parameters), it does work and gives back a result (return). You write it once and use it as many times as you need.

Functions make code shorter and easier to read: instead of 10 lines in five places, you write one name. Code inside the function runs only when you call it: greet("Shiro").

Line by line

def greet(name):def creates a function called greet with one parameter, name.
return "Hello, " + name + "!"+ glues text together; return gives the result back.
print(greet("Shiro"))call the function with "Shiro" and print what it returned.

Common mistakes

  • Forgetting return: then the function gives back None.
  • Calling a function before it is defined (above the def). Define first, call after.

Try it yourself

Write a function square(n) that returns n * n. Print square(7).

Show answer 
def square(n):
    return n * n

print(square(7))
Output
49

Lists

A list stores many values in order. Counting starts from 0, so langs[0] is the first item. len() gives the length.

langs = ["Python", "JavaScript", "C"]
langs.append("Rust")

print(langs[0])
print(len(langs))

for lang in langs:
    print("I like", lang)
Output
Python
4
I like Python
I like JavaScript
I like C
I like Rust

A list keeps many values in one variable, in order. It is like a numbered shelf: you can take an item by its number, add new items, remove them and go through all of them with a loop.

Useful commands: append(x) adds to the end, remove(x) deletes an item, len(list) counts items, list[-1] is the last item.

Line by line

langs = ["Python", "JavaScript", "C"]a list in square brackets, items separated by commas.
langs.append("Rust")add Rust to the end. Now there are 4 items.
langs[0]the first item. Counting starts from 0.
for lang in langs:lang becomes each item in turn.

Common mistakes

  • langs[4] when there are only 4 items — the last one is langs[3]. Error: IndexError.

Try it yourself

Make a list of 3 numbers, add one more with append and print the sum using sum().

Show answer

Mini project: guess the number

Everything together: a random number, a loop, conditions and input(), which reads what the player types. The output below is an example game.

import random

secret = random.randint(1, 10)
guess = 0

while guess != secret:
    guess = int(input("Guess a number from 1 to 10: "))
    if guess < secret:
        print("Bigger!")
    elif guess > secret:
        print("Smaller!")

print("You got it!")
Output
Guess a number from 1 to 10: 5
Bigger!
Guess a number from 1 to 10: 8
Smaller!
Guess a number from 1 to 10: 7
You got it!

A mini project joins everything you learned. Read it from top to bottom: first we prepare data (a secret number), then a loop asks the player again and again, conditions give hints, and when the guess is right the loop ends.

import random connects a ready-made module with random numbers. input() waits for the player to type something and press Enter; int() turns that text into a number.

Line by line

secret = random.randint(1, 10)a random whole number from 1 to 10.
while guess != secret:repeat until the guess is right.
int(input("..."))show a question, read the answer, turn it into a number.

Common mistakes

  • Forgetting int(): then the guess is text and never equals the number.

Try it yourself

Add a counter: after the game print how many tries the player needed.

Show answer 
import random

secret = random.randint(1, 10)
guess = 0
tries = 0

while guess != secret:
    guess = int(input("Guess a number from 1 to 10: "))
    tries += 1
    if guess < secret:
        print("Bigger!")
    elif guess > secret:
        print("Smaller!")

print("You got it in", tries, "tries!")
