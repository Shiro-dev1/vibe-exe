Go lessons

Go is a simple and fast language from Google. It is made for servers, cloud services and command line tools: Docker and Kubernetes are written in Go. It has few rules, so it is quick to learn.

Hello, world

Every Go program starts with package main, imports what it needs and runs func main(). fmt.Println prints a line.

package main

import "fmt"

func main() {
	fmt.Println("Hello, world!")
}
Output
Hello, world!

package main says "this is a program you can run". import "fmt" connects the package for formatted output. Note: in Go there are no semicolons at line ends — the compiler adds them itself.

Run it with go run main.go, or try it in the browser at go.dev/play.

Line by line

package mainthis file is a runnable program.
import "fmt"connect the fmt package.
func main() {the program starts here.
fmt.Println("Hello, world!")print the text and a new line.

Common mistakes

  • Putting the opening brace on a new line: func main()\n{ — in Go this is an error.
  • Importing a package and not using it — Go refuses to compile: imported and not used.

Try it yourself

Print your name and on the next line 2026.

Show answer 
package main

import "fmt"

func main() {
	fmt.Println("Shiro")
	fmt.Println(2026)
}
Output
Shiro
2026

Variables

:= creates a variable and guesses its type. var creates one with an explicit type. From here on, short examples go inside func main().

name := "Shiro"
var age int = 18
age = age + 1
fmt.Println("Hi, I'm", name, "and I'm", age)
Output
Hi, I'm Shiro and I'm 19

:= is used only the first time, when the variable is created. To change it later use plain =.

fmt.Println puts a space between its values. For a template like in other languages use fmt.Printf("%s is %d\n", name, age): %s is text, %d a whole number.

Line by line

name := "Shiro"create name; Go sees text and makes it a string.
var age int = 18create age with the type int.
age = age + 1change it with = (not :=).

Common mistakes

  • A variable that is created but never used — Go stops with declared and not used. Use it or delete it.
  • := twice for the same name in one block — no new variables on left side of :=.

Try it yourself

Create city := "Kyiv" and year := 2020 and print: I live in Kyiv since 2020.

Show answer 
city := "Kyiv"
year := 2020
fmt.Printf("I live in %s since %d\n", city, year)
Output
I live in Kyiv since 2020

Data types

Main types: int, float64, bool, string. %T in Printf shows the type, len() the length.

count := 10        // int
price := 9.99      // float64
online := true     // bool
title := "VIBE"    // string
fmt.Println(len(title))
fmt.Printf("%T %T %T\n", count, price, online)
Output
4
int float64 bool

Go never converts types by itself: count + price (int + float64) is an error. Convert yourself: float64(count) + price.

Text to number: strconv.Atoi("5") from the strconv package. It returns two things — the number and an error — you'll see this style everywhere in Go.

Line by line

price := 9.99numbers with a dot are float64.
len(title)length of the string.
fmt.Printf("%T ...", ...)%T prints the type of each value.

Common mistakes

  • Mixing int and float64 in one expression — mismatched types.

Try it yourself

You have a := 7 and b := 2.5. Print their sum (9.5).

Show answer 
a := 7
b := 2.5
fmt.Println(float64(a) + b)
Output
9.5

Conditions

if without brackets around the condition, but with braces. else must be on the same line as the closing brace.

age := 18

if age >= 18 {
	fmt.Println("Adult")
} else if age >= 13 {
	fmt.Println("Teen")
} else {
	fmt.Println("Kid")
}
Output
Adult

Go's if can start with a short statement: if n := len(s); n > 3 { ... } — n exists only inside the if. This is used a lot for errors: if err != nil { ... }.

There is also switch, and in Go it doesn't need break.

Line by line

if age >= 18 {no brackets needed.
} else if age >= 13 {else on the same line as }.

Common mistakes

  • } on one line and else on the next — syntax error.

Try it yourself

t := 30. Print "Hot" if t > 25, otherwise "OK".

Show answer

if t > 25 {
	fmt.Println("Hot")
} else {
	fmt.Println("OK")
}
Output
Hot

Loops

Go has only one loop: for. With three parts it is a counter, with just a condition it works like while.

for i := 0; i < 3; i++ {
	fmt.Println("Step", i)
}

count := 3
for count > 0 {
	fmt.Println(count)
	count--
}
Output
Step 0
Step 1
Step 2
3
2
1

One loop keyword for everything keeps Go simple. for { } with nothing is an endless loop, stopped with break.

To go through a list or text use for i, value := range list — you'll see it in the lesson about slices.

Line by line

for i := 0; i < 3; i++ {a counter loop, no brackets.
for count > 0 {this is Go's while.

Common mistakes

  • Writing while — Go has no such word, use for.

Try it yourself

Print the numbers from 1 to 5.

Show answer 
for i := 1; i <= 5; i++ {
	fmt.Println(i)
}
Output
1
2
3
4
5

Functions

func creates a function. Types go after names. A Go function can return several values at once.

package main

import "fmt"

func divide(a, b int) (int, int) {
	return a / b, a % b
}

func main() {
	q, r := divide(17, 5)
	fmt.Println(q, r)
}
Output
3 2

(a, b int) means both a and b are int. (int, int) after the brackets means two results. Here: 17 / 5 = 3 and the remainder 17 % 5 = 2.

Many Go functions return a result and an error: n, err := strconv.Atoi("42"). If you don't need a value, write _: q, _ := divide(17, 5).

Line by line

func divide(a, b int) (int, int) {two ints in, two ints out.
return a / b, a % bthe result and the remainder.
q, r := divide(17, 5)take both results.

Common mistakes

  • Taking only one value from a function that returns two: q := divide(17, 5) — error.

Try it yourself

Show answer

import "fmt"

	return n * n
}

func main() {
	fmt.Println(square(7))
}
Output

Slices

A slice is Go's list that can grow. append adds items, len counts them, range goes through them.

langs := []string{"Go", "Rust", "C"}
langs = append(langs, "Java")
fmt.Println(len(langs))

for i, lang := range langs {
	fmt.Println(i, lang)
}
Output
4
0 Go
1 Rust
2 C
3 Java

[]string means "a slice of strings". append returns a new slice, so you always write langs = append(langs, ...).

range gives two things: the index and the value. If you need only the value, write for _, lang := range langs. Go also has maps: ages := map[string]int{"Shiro": 18}.

Line by line

[]string{"Go", "Rust", "C"}a slice of three strings.
langs = append(langs, "Java")add one and save the result back.
for i, lang := range langs {i is the number, lang the value.

Common mistakes

  • append(langs, "Java") without langs = — the result is lost (and Go reports it).

Try it yourself

Make []int{1, 2, 3}, append 4 and print the sum using a range loop.

Show answer 
nums := []int{1, 2, 3}
nums = append(nums, 4)
sum := 0
for _, n := range nums {
	sum += n
}
fmt.Println(sum)
Output
10

Mini project: a game hero

Go has no classes. A struct holds data, and methods are attached to it with a receiver: func (p *Player) Hit(...).

package main

import "fmt"

type Player struct {
	Name string
	HP   int
}

func (p *Player) Hit(damage int) {
	p.HP -= damage
	fmt.Printf("%s has %d HP\n", p.Name, p.HP)
}

func main() {
	p := Player{Name: "Shiro", HP: 100}
	p.Hit(30)
	p.Hit(25)
}
Output
Shiro has 70 HP
Shiro has 45 HP

*Player (with a star) means the method gets a pointer to the real player and can change it. Without the star it would get a copy, and the HP would not change outside.

Names that start with a capital letter (Name, Hit) are visible from other packages — that's how Go marks things as public.

Line by line

type Player struct { ... }what every player has.
func (p *Player) Hit(damage int)a method of Player that can change it.
p := Player{Name: "Shiro", HP: 100}create a player.

Common mistakes

  • Writing func (p Player) Hit without * — the HP changes only in a copy.

Try it yourself

Add a Heal(amount int) method and heal the player by 10 after the hits.

Show answer 
package main

import "fmt"

type Player struct {
	Name string
	HP   int
}

func (p *Player) Hit(damage int) {
	p.HP -= damage
	fmt.Printf("%s has %d HP\n", p.Name, p.HP)
}

func (p *Player) Heal(amount int) {
	p.HP += amount
	fmt.Printf("%s has %d HP\n", p.Name, p.HP)
}

func main() {
	p := Player{Name: "Shiro", HP: 100}
	p.Hit(30)
	p.Hit(25)
	p.Heal(10)
}
Output
Shiro has 70 HP
Shiro has 45 HP
Shiro has 55 HP

Quiz

5 questions. Pick an answer to see if it is right.

1. How many kinds of loops does Go have?

Go has only for; it also works as while.

2. What will this code print?

x := 17
fmt.Println(x % 5)

% is the remainder: 17 = 5 * 3 + 2.

3. What happens if you create a variable and never use it?

Go refuses to compile: declared and not used.

4. What will this code print?

s := []int{1, 2}
s = append(s, 3)
fmt.Println(len(s))

append added one item.

5. Which sign creates a new variable and guesses its type?

:= creates; = only changes an existing variable.
