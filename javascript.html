02_VARIABLES02/08

let creates a variable that can change, const one that can't. In backticks ` ` you can insert variables with ${ }.

const name = "Shiro";
let age = 18;
age = age + 1;

console.log(name, age);
console.log(`Hi, I'm ${name}`);
OUTPUT
Shiro 19
Hi, I'm Shiro

04_CONDITIONS04/08

if runs code only when the condition in brackets is true. Code blocks live inside { }.

const age = 18;

if (age >= 18) {
  console.log("Adult");
} else if (age >= 13) {
  console.log("Teen");
} else {
  console.log("Kid");
}
OUTPUT
Adult
05_LOOPS05/08

for has three parts: start, condition, step. i++ adds 1, count-- takes 1 away.

for (let i = 0; i < 3; i++) {
  console.log("Step", i);
}

let count = 3;
while (count > 0) {
  console.log(count);
  count--;
}
OUTPUT
Step 0
Step 1
Step 2
3
2
1
06_FUNCTIONS06/08

A function is code with a name that you can run many times. The arrow => is a short way to write a function.

function greet(name) {
  return "Hello, " + name + "!";
}

const shout = (text) => text.toUpperCase();

console.log(greet("Shiro"));
console.log(shout("vibe"));
OUTPUT
Hello, Shiro!
VIBE
07_ARRAYS07/08

An array stores many values in order. Counting starts from 0. push adds an item to the end, length is how many there are.

const langs = ["Python", "JavaScript", "C"];
langs.push("Rust");

console.log(langs[0]);
console.log(langs.length);

langs.forEach((lang) => console.log("I like " + lang));
OUTPUT
Python
4
I like Python
I like JavaScript
I like C
I like Rust
08_MINI_PROJECT_CLICK_COUNTER08/08

JavaScript can change the page. This button counts clicks: put the code in an HTML file and open it in the browser.

<button id="btn">Clicks: 0</button>

<script>
  const btn = document.getElementById("btn");
  let clicks = 0;

  btn.addEventListener("click", () => {
    clicks++;
    btn.textContent = "Clicks: " + clicks;
  });
</script>
OUTPUT
[ Clicks: 0 ]  -> click ->  [ Clicks: 1 ]  -> click ->  [ Clicks: 2 ]
