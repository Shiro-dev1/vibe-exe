Hello, world

console.log() prints text to the browser console. You can open the console in Chrome with Ctrl + Shift + J and type code right there. Or just press Run here.

Output
Hello, world!

JavaScript was made for web pages and runs in every browser. console.log() writes a message to the console — a hidden panel for developers. Programmers use it all the time to check what their code is doing.

Each command usually ends with a semicolon ;. JavaScript often forgives a missing one, but it is a good habit to write it.

Line by line

consolethe browser console, an object with useful commands.
.log(...)the command "write to the log". The dot means "take log from console".
"Hello, world!"the text in quotes, called a string.

Common mistakes

  • Writing console.Log — case matters, it must be log.

Try it yourself

Print your name and on the next line the number 2026.

Show answer 
console.log("Shiro");
console.log(2026);
Output
Shiro
2026

Variables

let creates a variable that can change, const one that can't. In backticks ` ` you can insert variables with ${ }.

Output
Shiro 19
Hi, I'm Shiro

Use const by default — for values that won't be reassigned. Use let when the value must change, like a counter. You may also meet var in old code; today it is better not to use it.

Template strings in backticks `...` can contain ${...}: anything inside is calculated and put into the text.

Line by line

const name = "Shiro";a constant: name can't be given a new value later.
let age = 18;a variable that can change.
age = age + 1;take the old value, add 1, save it back. Now age is 19.
`Hi, I'm ${name}`backticks + ${} put the value of name into the text.

Common mistakes

  • Changing a const: TypeError: Assignment to constant variable. Use let instead.
  • Using normal quotes with ${} — it only works inside backticks.

Try it yourself

Create let score = 0, add 10 to it twice and print "Score: 20" with a template string.

Show answer 
let score = 0;
score += 10;
score += 10;
console.log(`Score: ${score}`);
Output
Score: 20

Data types

// starts a comment. typeof tells you the type of a value.

Output
number
string

JavaScript has a few basic types: number (all numbers, whole or with a dot), string (text), boolean (true/false), plus null and undefined for "no value".

JavaScript tries to be helpful and converts types by itself, which sometimes surprises: "5" + 2 gives "52" (text), but "5" * 2 gives 10. Use Number("5") to turn text into a number on purpose.

Line by line

let count = 10;number — whole numbers and numbers with a dot are the same type.
let nothing = null;null: we decided there is nothing here.
let user;no value given, so it is undefined.
typeof countreturns the type name as text: "number".

Common mistakes

  • Adding numbers from inputs and getting "12" instead of 3 — they were text. Convert with Number().

Try it yourself

You have a = "7" (text). Print a + 3 so that the answer is 10.

Show answer 
const a = "7";
console.log(Number(a) + 3);
Output
10

Conditions

if runs code only when the condition in brackets is true. Code blocks live inside { }.

Output
Adult

if checks a condition in brackets. If it is true, the block in { } runs. else if checks the next condition, else catches everything else.

In JavaScript compare with three equals signs === (and !== for "not equal"). Two equals == converts types and can give strange results, like "5" == 5 being true.

Line by line

if (age >= 18) {the condition goes in round brackets, the code in curly ones.
} else if (age >= 13) {the next check, only if the first was false.
} else {everything else.

Common mistakes

  • Using = inside if: if (age = 18) assigns 18 instead of comparing.

Try it yourself

const t = 30. Print "Hot" if t is more than 25, otherwise "OK".

Show answer 
const t = 30;
if (t > 25) {
  console.log("Hot");
} else {
  console.log("OK");
}
Output
Hot

Loops

for has three parts: start, condition, step. i++ adds 1, count-- takes 1 away.

Output
Step 0
Step 1
Step 2
3
2
1

The classic for loop has three parts separated by ;: start (let i = 0), condition to keep going (i < 3) and step after each round (i++).

while is simpler: it repeats while the condition is true. For arrays there is also for (const item of array) that goes through every item.

Line by line

for (let i = 0; i < 3; i++)i starts at 0, the loop runs while i < 3, after each round i grows by 1.
while (count > 0)repeat while count is more than 0.
count--;take 1 away, otherwise the loop never ends.

Common mistakes

  • Writing commas instead of semicolons in for: for (let i = 0, i < 3, i++).

Try it yourself

Print the numbers from 1 to 5.

Show answer 
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
Output
1
2
3
4
5

Functions

A function is code with a name that you can run many times. The arrow => is a short way to write a function.

Output
Hello, Shiro!
VIBE

A function groups code under a name. Parameters in brackets are inputs, return is the output. Without return the function gives back undefined.

Arrow functions (x) => x * 2 are a short form. If the body is one expression, its result is returned automatically.

Line by line

function greet(name) {a function greet with the parameter name.
return "Hello, " + name + "!";build the text and give it back.
const shout = (text) => text.toUpperCase();an arrow function: takes text, returns it in capital letters.

Common mistakes

  • Forgetting the brackets when calling: greet instead of greet("Shiro") — the function doesn't run.

Try it yourself

Write an arrow function square that returns n * n. Print square(7).

Show answer 
const square = (n) => n * n;
console.log(square(7));
Output
49

Arrays

An array stores many values in order. Counting starts from 0. push adds an item to the end, length is how many there are.

Output
Python
4

An array is an ordered list of values. You reach an item by its index (number), starting from 0. Arrays can grow and shrink.

Handy methods: push adds to the end, pop removes the last item, includes(x) checks if x is inside, forEach runs a function for every item.

Line by line

const langs = [...]an array in square brackets. const means the variable, not the content, can't be replaced.
langs.push("Rust");add to the end.
langs.lengthhow many items there are.
langs.forEach((lang) => ...)run the arrow function for each item.

Common mistakes

  • Using langs.length as the last index — the last item is langs[langs.length - 1].

Try it yourself

Make an array of 3 numbers, push one more and print how many items there are.

Show answer 
const nums = [1, 2, 3];
nums.push(4);
console.log(nums.length);
Output
4

Mini project: click counter

JavaScript can change the page. This button counts clicks: press Run and click it.

Output
[ Clicks: 0 ]  -> click ->  [ Clicks: 1 ]  -> click ->  [ Clicks: 2 ]

This is where JavaScript shines: it changes the page while you look at it. document is the whole page; getElementById finds the element with that id.

addEventListener("click", ...) says: "when someone clicks, run this function". The function adds 1 to the counter and writes the new text into the button.

Line by line

<button id="btn">an HTML button with the id btn so JavaScript can find it.
document.getElementById("btn")find that button on the page.
btn.addEventListener("click", ...)listen for clicks on the button.
btn.textContent = ...replace the text inside the button.

Common mistakes

  • Running the script before the button exists — then getElementById returns null. Put the script after the HTML.

Try it yourself

Change the counter so that each click adds 5 instead of 1. Try it with Run.

Show answer 
<button id="btn">Clicks: 0</button>

<script>
  const btn = document.getElementById("btn");
  let clicks = 0;

  btn.addEventListener("click", () => {
    clicks += 5;
    btn.textContent = "Clicks: " + clicks;
  });
</script>

Quiz

5 questions. Pick an answer to see if it is right.

1. What will this code print?

let x = 5;
x = x + 2;
console.log(x);

x was 5, then we add 2, so x becomes 7.

2. What will this code print?

console.log("5" + 2);

"5" is text, so + glues the 2 to it instead of adding.

3. Which keyword creates a variable that can't be changed?

const means constant: you can't assign it again.

4. What will this code print?

const a = [10, 20, 30];
console.log(a.length);

length is how many items are in the array: 3.

5. What will this code print?

const shout = (t) => t.toUpperCase();
console.log(shout("hi"));

toUpperCase() makes all letters big.
