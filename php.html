Hello, world

PHP code starts with <?php. echo sends text out — to the page or to the terminal.

<?php
echo "Hello, world!";
Output
Hello, world!

A PHP file can mix HTML and PHP. Everything after <?php is code; the server runs it and sends only the result to the visitor, so nobody sees your PHP code.

Every command ends with ;. You can try PHP online at onlinephp.io or 3v4l.org right in the browser.

Line by line

<?phpstart of PHP code.
echo "Hello, world!";output the text.

Common mistakes

  • Forgetting ; — PHP shows Parse error: syntax error.

Try it yourself

Print your name, a new line, and 2026.

Show answer 
<?php
echo "Shiro\n";
echo 2026;
Output
Shiro
2026

Variables

Every variable in PHP starts with $. In double quotes PHP puts variable values right into the text; in single quotes it doesn't.

<?php
$name = "Shiro";
$age = 18;
echo "Hi, I'm $name and I'm $age\n";
echo 'Single quotes: $name' . "\n";
Output
Hi, I'm Shiro and I'm 18
Single quotes: $name

You don't write types in PHP: a variable takes whatever you put in it. The $ sign makes variables easy to spot.

The dot . glues strings together (in JavaScript it would be +). "\n" is a new line — it works only inside double quotes.

Line by line

$name = "Shiro";create the variable $name.
"Hi, I'm $name ..."double quotes: $name is replaced by Shiro.
'Single quotes: $name'single quotes: printed as is.
. "\n"glue a new line to the end.

Common mistakes

  • Forgetting $: name = "Shiro"; is an error.
  • Using + to join text — in PHP it is ..

Try it yourself

Create $city = "Kyiv" and $year = 2020 and print: I live in Kyiv since 2020.

Show answer 
<?php
$city = "Kyiv";
$year = 2020;
echo "I live in $city since $year";
Output
I live in Kyiv since 2020

Data types

PHP has int, float, string, bool, array and null. gettype() shows the type, strlen() counts characters.

<?php
$count = 10;        // int
$price = 9.99;      // float
$title = "VIBE";    // string
$online = true;     // bool
echo gettype($price) . "\n";
echo strlen($title) . "\n";
Output
double
4

Notice: for a float gettype() says double — that's an old name for the same thing.

PHP converts types by itself when needed: "5" + 3 gives 8. To convert on purpose use (int), (float) or (string) before the value: (int)"42".

Line by line

$price = 9.99;a number with a dot (float).
gettype($price)returns the type name as text.
strlen($title)length of the string: 4.

Common mistakes

  • strlen("Привет") gives 12, not 6: it counts bytes. For Russian text use mb_strlen().

Try it yourself

You have $a = "7". Print $a as a number plus 3 (10).

Show answer 
<?php
$a = "7";
echo (int)$a + 3;
Output
10

Conditions

if, elseif (one word in PHP) and else. The condition goes in brackets, the code in braces.

<?php
$age = 18;

if ($age >= 18) {
    echo "Adult\n";
} elseif ($age >= 13) {
    echo "Teen\n";
} else {
    echo "Kid\n";
}
Output
Adult

Compare with === (equal value and type) and !==. Double == converts types first and can surprise you, so prefer three.

Combine conditions with && (and), || (or), ! (not).

Line by line

if ($age >= 18) {the first check.
} elseif ($age >= 13) {the next one.
} else {everything else.

Common mistakes

  • if ($age = 18) assigns instead of comparing and is always true.

Try it yourself

$t = 30. Print "Hot" if $t > 25, otherwise "OK".

Show answer 
<?php
$t = 30;
if ($t > 25) {
    echo "Hot";
} else {
    echo "OK";
}
Output
Hot

Loops

for and while look like in C and JavaScript. For arrays PHP has foreach — you will see it in the next lessons.

<?php
for ($i = 0; $i < 3; $i++) {
    echo "Step $i\n";
}

$count = 3;
while ($count > 0) {
    echo "$count\n";
    $count--;
}
Output
Step 0
Step 1
Step 2
3
2
1

Loops in PHP are often used to build HTML: a table row for every product, a list item for every comment.

break leaves a loop, continue jumps to the next round.

Line by line

for ($i = 0; $i < 3; $i++)the counter $i goes 0, 1, 2.
$count--;take 1 away.

Common mistakes

  • Forgetting $ on the counter: for (i = 0; ...).

Try it yourself

Print the numbers from 1 to 5, each on its own line.

Show answer 
<?php
for ($i = 1; $i <= 5; $i++) {
    echo "$i\n";
}
Output
1
2
3
4
5

Functions

function creates a function. You can write types of parameters and of the result — PHP will check them.

<?php
function greet(string $name): string {
    return "Hello, $name!";
}

echo greet("Shiro") . "\n";
Output
Hello, Shiro!

PHP has thousands of ready-made functions: strtoupper(), date(), count(), round(). Before writing your own, check if PHP already has one.

Parameters can have default values: function greet(string $name = "friend").

Line by line

function greet(string $name): stringtakes a string, returns a string.
return "Hello, $name!";the result with the name inside.

Common mistakes

  • Using a variable from outside inside a function — functions don't see outer variables. Pass them as parameters.

Try it yourself

Write square(int $n): int and print square(7).

Show answer 
<?php
function square(int $n): int {
    return $n * $n;
}
echo square(7);
Output
49

Arrays

PHP arrays can be lists (["PHP", "Go"]) or have named keys (["name" => "Shiro"]). foreach goes through them.

<?php
$langs = ["PHP", "JS", "Go"];
$langs[] = "Rust";
echo count($langs) . "\n";

$user = ["name" => "Shiro", "age" => 18];
foreach ($user as $key => $value) {
    echo "$key: $value\n";
}
Output
4
name: Shiro
age: 18

An array with named keys (an "associative array") is like a small table: on the left the name, on the right the value. Data from forms and databases usually comes in this shape.

$langs[] = ... adds to the end. count() counts items. $user["name"] takes a value by its key.

Line by line

$langs[] = "Rust";add to the end.
["name" => "Shiro", ...]=> links a key with a value.
foreach ($user as $key => $value)go through every key and value.

Common mistakes

  • Reading a key that doesn't exist — PHP shows Warning: Undefined array key. Check with isset($user["email"]).

Try it yourself

Make $nums = [1, 2, 3], add 4 and print the sum with array_sum().

Show answer 
<?php
$nums = [1, 2, 3];
$nums[] = 4;
echo array_sum($nums);
Output
10

Mini project: site menu

What PHP is made for: building HTML from data. One array describes the menu, a loop turns it into a list of links.

<?php
$menu = ["Home" => "/", "Lessons" => "/lessons", "Contacts" => "/contacts"];

echo "<ul>\n";
foreach ($menu as $title => $link) {
    echo "  <li><a href=\"$link\">$title</a></li>\n";
}
echo "</ul>\n";
Output
<ul>
  <li><a href="/">Home</a></li>
  <li><a href="/lessons">Lessons</a></li>
  <li><a href="/contacts">Contacts</a></li>
</ul>

On a real site this HTML goes straight to the browser, and the visitor sees a normal menu. Want a new menu item? Add one line to the array — every page that uses it updates.

\" is a quote inside a double-quoted string; without the backslash PHP would think the string ends there.

Line by line

$menu = [...]the data: title => link.
foreach ($menu as $title => $link)for every menu item…
echo " <li><a href=\"$link\">$title</a></li>\n";…print one line of HTML.

Common mistakes

  • Putting text from users straight into HTML — use htmlspecialchars(), otherwise someone can inject their own code.

Try it yourself

Show answer

echo "<ul>\n";

}

  <li><a href="/lessons">Lessons</a></li>
  <li><a href="/contacts">Contacts</a></li>
  <li><a href="/blog">Blog</a></li>
</ul>

Quiz

5 questions. Pick an answer to see if it is right.

1. What does every PHP variable start with?

PHP variables always start with $.

2. What will this code print?

<?php
$name = "Shiro";
echo 'Hi $name';

Single quotes don't replace variables.

3. Which operator glues two strings in PHP?

In PHP it's the dot: "a" . "b".

4. What will this code print?

<?php
$a = [10, 20, 30];
$a[] = 40;
echo count($a);

$a[] = 40 added one more item.

5. Where does PHP code usually run?

PHP runs on the server and sends ready HTML to the browser.
